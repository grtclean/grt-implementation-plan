# 成本预警规则导入模板说明

## 模板下载

模板文件位置: `/templates/cost-alert-rules-template.csv`

## 字段说明

| 字段名 | 必填 | 类型 | 说明 | 示例值 |
|--------|------|------|------|--------|
| 项目ID | 是 | 数字 | 关联的项目ID | 1 |
| 规则名称 | 是 | 文本 | 预警规则的名称 | 材料成本超支预警 |
| 规则类型 | 是 | 枚举 | budget_exceed / cost_increase / milestone_delay | budget_exceed |
| 阈值 | 是 | 数字 | 触发预警的阈值百分比 | 80 |
| 预警级别 | 是 | 枚举 | info / warning / critical | warning |
| 是否启用 | 是 | 是/否 | 规则是否启用 | 是 |
| 备注 | 否 | 文本 | 规则说明或备注 | 当材料成本超过预算80%时触发预警 |

## 规则类型说明

- **budget_exceed**: 预算超支预警，当实际成本超过预算的指定百分比时触发
- **cost_increase**: 成本增长预警，当成本增长率超过指定百分比时触发
- **milestone_delay**: 里程碑延迟预警，当里程碑延迟超过指定天数时触发

## 预警级别说明

- **info**: 信息级别，仅记录日志
- **warning**: 警告级别，发送通知提醒
- **critical**: 严重级别，发送紧急通知并@所有人

## 导入步骤

1. 下载模板文件
2. 按照字段说明填写数据
3. 保存为CSV格式（UTF-8编码）
4. 在成本管理页面点击"导入规则"按钮
5. 选择文件并确认导入

## 注意事项

- 请确保项目ID存在于系统中
- 规则类型和预警级别必须使用英文枚举值
- 阈值范围为0-100的整数
- 导入时会自动跳过格式错误的行
- 导入成功后会显示导入结果统计
