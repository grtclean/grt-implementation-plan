## 摘要

本文档定义了GRT智能系统的多层安全防护架构，旨在保护系统免受未授权复制、黑客攻击和数据泄露。该架构基于"纵深防御"（Defense in Depth）原则，结合工业控制系统安全标准IEC 62443和企业信息安全最佳实践，为GRT的核心知识产权（如清洗工艺配方、客户分级定价）提供全方位保护。

---

## 1. 安全威胁分析

### 1.1 主要威胁类型

| 威胁类别 | 具体威胁 | 风险等级 | 潜在影响 |
|---------|---------|---------|---------|
| **知识产权盗窃** | 系统代码被复制、核心算法泄露 | 极高 | 竞争优势丧失、商业机密外泄 |
| **数据泄露** | 客户数据、定价策略被窃取 | 高 | 客户信任损失、法律责任 |
| **系统入侵** | 黑客攻击、恶意软件植入 | 高 | 系统瘫痪、数据篡改 |
| **内部威胁** | 员工越权访问、数据滥用 | 中 | 敏感信息泄露、操作失误 |
| **供应链攻击** | 第三方组件漏洞利用 | 中 | 系统被控制、后门植入 |

### 1.2 核心资产识别

GRT系统需要保护的核心资产按敏感度分为三个级别：

**L1 - 最高机密**（仅限私有部署访问）
- 客户分级定价策略（Client Tier Prices）
- 核心清洗工艺配方（Core Process Formulas）
- 设备控制逻辑算法

**L2 - 机密**（需要凭证验证）
- 项目交付文档和技术方案
- 员工能力评估数据
- 财务报表和成本分析

**L3 - 内部**（需要身份认证）
- 客户基本信息
- 项目进度和状态
- 培训资料和知识库

## 3. 防复制保护机制

### 3.1 代码保护策略

#### 3.1.1 服务端代码保护

服务端代码采用多重保护机制：

**编译时混淆**：使用JavaScript混淆器对生产代码进行变量名混淆、控制流扁平化和字符串加密。

**运行时保护**：实现自检测机制，检测调试器附加、代码篡改和非法执行环境。

**许可证验证**：每次启动时验证硬件指纹和许可证有效性。

#### 3.1.2 前端代码保护

前端代码采用以下保护措施：

**代码分割和懒加载**：核心业务逻辑按需加载，减少一次性暴露的代码量。

**WebAssembly封装**：将敏感算法编译为WebAssembly模块，增加逆向工程难度。

**反调试技术**：检测开发者工具打开状态，触发保护机制。

### 3.2 硬件绑定与许可证系统

```typescript
// 许可证验证架构
interface LicenseConfig {
  licenseKey: string;           // 加密的许可证密钥

```

**硬件指纹生成因素**：
- CPU序列号
- 主板UUID
- 网卡MAC地址
- 磁盘序列号
- 内存配置哈希

### 3.3 数字水印与追踪

每个部署实例嵌入唯一的数字水印，用于追踪泄露源头：

**代码水印**：在编译时注入唯一标识符到代码结构中。

**数据水印**：在导出的报表和文档中嵌入隐藏的客户标识。

**日志水印**：所有操作日志包含部署实例标识，便于审计追踪。

### 3.4 AI脱敏代理层

为防止核心知识产权被公共大模型吸收，所有LLM交互必须通过脱敏代理层：

```
┌──────────────┐     ┌──────────────────┐     ┌──────────────┐
│   用户请求   │ ──► │   脱敏代理层     │ ──► │   公共LLM    │
└──────────────┘     │  ┌────────────┐  │     └──────────────┘
                     │  │ 敏感词过滤 │  │
                     │  │ 数据替换   │  │
                     │  │ 上下文清洗 │  │
                     │  └────────────┘  │
                     └──────────────────┘
```

**脱敏规则**：
- 客户名称替换为通用标识符
- 价格数据进行模糊化处理
- 工艺参数使用占位符替代
- 设备型号使用代号表示

## 4. 入侵防护系统

### 4.1 多因素认证（MFA）

系统实现分级MFA策略：

| 用户角色 | 认证要求 | 触发条件 |
|---------|---------|---------|
| 普通员工 | 密码 + 邮箱验证码 | 首次登录、新设备 |
| 主管级别 | 密码 + TOTP | 每次登录 |
| 管理员 | 密码 + TOTP + 硬件密钥 | 每次登录 |
| 系统管理 | 密码 + TOTP + 生物识别 | 每次登录 + 敏感操作 |

### 4.2 API安全防护

#### 4.2.1 速率限制策略

```typescript
// 速率限制配置
const rateLimitConfig = {
  // 全局限制
  global: {
    windowMs: 60 * 1000,  // 1分钟窗口
    maxRequests: 100,     // 最大请求数
  },
  // 登录接口限制
  auth: {
    windowMs: 15 * 60 * 1000,  // 15分钟窗口
    maxRequests: 5,            // 最大尝试次数
    blockDuration: 30 * 60 * 1000,  // 锁定30分钟
  },
  // 敏感数据接口限制
  sensitive: {
    windowMs: 60 * 1000,
    maxRequests: 10,
  },
};
```

#### 4.2.2 请求签名验证

所有API请求必须包含签名头，防止请求伪造：

```
X-Request-Signature: HMAC-SHA256(timestamp + method + path + body, secretKey)
X-Request-Timestamp: 1706612400000
X-Request-Nonce: unique-random-string
```

### 4.3 异常行为检测

系统实现基于机器学习的异常行为检测：

**检测维度**：
- 登录时间异常（非工作时间访问）
- 地理位置异常（异地登录）
- 访问模式异常（批量数据导出）
- 操作频率异常（短时间大量请求）

**响应措施**：
- 低风险：记录日志，继续监控
- 中风险：触发二次认证
- 高风险：临时锁定账户，通知管理员

## 5. 数据安全机制

### 5.1 数据加密策略

#### 5.1.1 传输层加密

所有网络通信强制使用TLS 1.3：

```typescript
const tlsConfig = {
  minVersion: 'TLSv1.3',
  cipherSuites: [
    'TLS_AES_256_GCM_SHA384',
    'TLS_CHACHA20_POLY1305_SHA256',
  ],
  certificatePinning: true,
  hsts: {
    maxAge: 31536000,
    includeSubDomains: true,
    preload: true,
  },
};
```

#### 5.1.2 存储加密

敏感数据采用分层加密存储：

| 数据类型 | 加密算法 | 密钥管理 |
|---------|---------|---------|
| 用户密码 | Argon2id | 不可逆哈希 |
| 会话令牌 | AES-256-GCM | 服务端密钥 |
| 敏感业务数据 | AES-256-GCM | 客户专属密钥 |
| 核心配方 | AES-256-GCM + RSA | HSM硬件密钥 |

### 5.2 数据脱敏规则

```typescript
// 数据脱敏配置
const dataMaskingRules = {
  // 客户信息脱敏
  customer: {
    phone: (v: string) => v.replace(/(\d{3})\d{4}(\d{4})/, '$1****$2'),
    email: (v: string) => v.replace(/(.{2}).*(@.*)/, '$1***$2'),
    idCard: (v: string) => v.replace(/(\d{6})\d{8}(\d{4})/, '$1********$2'),
  },
  // 财务数据脱敏
  financial: {
    price: (v: number) => Math.round(v / 1000) * 1000,  // 精度降低
    bankAccount: (v: string) => v.replace(/\d(?=\d{4})/g, '*'),
  },
  // 技术数据脱敏
  technical: {
    formula: (v: string) => '[PROTECTED]',
    parameter: (v: number) => v * (0.9 + Math.random() * 0.2),  // 添加噪声
  },
};
```
