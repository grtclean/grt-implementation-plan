## 一、项目编号规则

### 1.1 编号体系概述

GRT公司项目编号采用**两阶段编号制**，区分项目的商务阶段和执行阶段：

| 阶段 | 编号前缀 | 适用场景 | 说明 |
|------|----------|----------|------|
| **商务阶段** | T | 询价、报价、方案设计 | 临时编号，用于跟踪潜在项目 |
| **执行阶段** | GRT | 签订合同后 | 正式编号，用于生产和交付管理 |

### 1.2 编号结构

#### 临时项目编号（商务阶段）

```
T + XXX(X)
│   └──── 流水序号（3-4位数字）
└──────── 临时项目前缀
```

**编号规则**：
- 初始格式：T001 ~ T999（3位数字）
- 扩展格式：T1000 ~ T9999（4位数字，当3位用尽后自动升级）
- 当前进度：约T500左右

**示例**：
| 编号 | 说明 |
|------|------|
| T501 | 第501个询价/报价项目 |
| T999 | 第999个询价/报价项目 |
| T1000 | 第1000个询价/报价项目（自动升级为4位） |

#### 正式项目编号（执行阶段）

```
GRT + XXX(X)
│     └──── 流水序号（3-4位数字）
└────────── 公司标识前缀
```

**编号规则**：
- 初始格式：GRT001 ~ GRT999（3位数字）
- 扩展格式：GRT1000 ~ GRT9999（4位数字，当3位用尽后自动升级）
- 当前进度：约GRT500左右

**示例**：
| 编号 | 说明 |
|------|------|
| GRT501 | 第501个正式签约项目 |
| GRT999 | 第999个正式签约项目 |
| GRT1000 | 第1000个正式签约项目（自动升级为4位） |

### 1.3 编号转换规则

当项目从商务阶段进入执行阶段时，需要进行编号转换：

```
┌─────────────┐    签订合同    ┌─────────────┐
│   T501      │ ────────────▶ │  GRT501     │
│ （临时编号） │               │ （正式编号） │
└─────────────┘               └─────────────┘
```

**转换规则**：
1. 临时编号（T编号）与正式编号（GRT编号）**相互独立**，各自维护流水序号
2. 转换时，系统自动分配下一个可用的GRT编号
3. 原T编号保留在系统中，标记为"已转换"，并关联对应的GRT编号
4. 报价单、方案文档等历史资料保持原T编号不变，但需标注对应的GRT编号

### 1.4 编号自动升级机制

系统应实现以下自动升级逻辑：

```python
def get_next_project_number(prefix: str, current_max: int) -> str:
    """
    获取下一个项目编号
    - 当流水号 <= 999 时，使用3位格式
    - 当流水号 > 999 时，自动升级为4位格式
    """
    next_num = current_max + 1
    if next_num <= 999:
        return f"{prefix}{next_num:03d}"  # T001, GRT001
    else:
        return f"{prefix}{next_num:04d}"  # T1000, GRT1000
```

### 1.5 项目编号在报价单中的应用

| 文档类型 | 编号格式 | 示例 |
|----------|----------|------|
| 询价登记 | T编号 | T501 |
| 技术方案 | T编号-FA-版本 | T501-FA-V1.0 |
| 商务报价 | T编号-QT-版本 | T501-QT-V1.0 |
| 合同 | GRT编号-CT | GRT501-CT |
| 生产订单 | GRT编号-PO-序号 | GRT501-PO-001 |

## 二、设备产品命名规则

### 2.1 命名体系概述

参照国际知名工业清洗设备制造商Ecoclean的命名体系 [1]，结合GRT公司的业务特点和市场定位，设计以下设备命名规则。

#### Ecoclean命名特点分析

Ecoclean采用"品牌前缀 + 产品特性"的命名模式：

| 系列 | 命名示例 | 命名含义 |
|------|----------|----------|
| EcoC系列 | EcoCvario, EcoCcore, EcoCcompact | Eco（环保）+ C（Cleaning）+ 特性词 |
| UCM系列 | UCMSmartLine, UCMWatchLine | UCM（超声波清洗机）+ 应用场景 |
| 独立命名 | Mega 86W, Minio 85C | 产品特性 + 规格代码 |

### 2.2 GRT设备命名结构（建议方案）

#### 方案A：品牌前缀式（推荐）

```
GRT + [产品系列] + [特性/规格]
│     │            └──── 产品特性或规格标识
│     └─────────────── 产品系列代码
└────────────────────── 公司品牌前缀
```

**产品系列代码**：

| 系列代码 | 系列名称 | 说明 |
|----------|----------|------|
| **U** | Ultrasonic | 超声波清洗系列 |
| **S** | Spray | 喷淋清洗系列 |
| **V** | Vacuum | 真空清洗/干燥系列 |
| **P** | Pass-through | 通过式清洗线 |
| **C** | Combo | 组合式清洗系列 |
| **X** | Custom | 定制解决方案 |

**特性/规格标识**：

| 标识 | 含义 | 示例 |
|------|------|------|
| **Core** | 核心/标准型 | GRT-UCore |
| **Pro** | 专业/高配型 | GRT-UPro |
| **Compact** | 紧凑型 | GRT-UCompact |
| **Max** | 大容量型 | GRT-SMax |
| **Line** | 生产线型 | GRT-PLine |
| **Smart** | 智能型 | GRT-USmart |
| **数字** | 规格参数 | GRT-U28（28kHz） |

**命名示例**：

| 设备名称 | 产品类型 | 说明 |
|----------|----------|------|
| **GRT-UCore** | 超声波清洗机标准型 | 单槽/多槽超声波清洗机基础款 |
| **GRT-UPro** | 超声波清洗机专业型 | 高配置超声波清洗机 |
| **GRT-UCompact** | 超声波清洗机紧凑型 | 小型超声波清洗机 |
| **GRT-U28** | 28kHz超声波清洗机 | 标注频率的超声波清洗机 |
| **GRT-U40** | 40kHz超声波清洗机 | 标注频率的超声波清洗机 |
| **GRT-SCore** | 喷淋清洗机标准型 | 标准喷淋清洗设备 |
| **GRT-SMax** | 喷淋清洗机大容量型 | 大型喷淋清洗设备 |
| **GRT-VDry** | 真空干燥机 | 真空干燥设备 |
| **GRT-PLine** | 通过式清洗线 | 连续式清洗生产线 |
| **GRT-CSmart** | 组合式智能清洗机 | 多功能组合清洗设备 |
| **GRT-XCustom** | 定制清洗设备 | 非标定制解决方案 |

#### 方案B：功能描述式（备选）

```
GRT + [清洗方式] + [槽数/规格] + [特性]
```

**命名示例**：

| 设备名称 | 产品类型 | 说明 |
|----------|----------|------|
| **GRT-US3** | 超声波清洗机3槽 | 3槽超声波清洗机 |
| **GRT-US5-Pro** | 超声波清洗机5槽专业型 | 5槽高配超声波清洗机 |
| **GRT-SP-H100** | 高压喷淋清洗机100bar | 100bar高压喷淋设备 |
| **GRT-VD-500** | 真空干燥机500L | 500升真空干燥设备 |

### 2.3 设备型号完整编码

设备型号完整编码用于内部管理和技术文档：

```
[设备名称] - [年份] - [序号]
```

**示例**：
| 完整型号 | 说明 |
|----------|------|
| GRT-UCore-26-001 | 2026年第1台UCore超声波清洗机 |
| GRT-SMax-26-015 | 2026年第15台SMax喷淋清洗机 |

## 三、物料编号规则

> 详细内容请参见 [物料编号规则文档](./material-numbering-rules.md)

### 3.1 编码结构概要

GRT公司物料编号采用**15位混合编码法**：

```
AA - BB - CC - DDDD - EEE
│    │    │    │      └── 流水序号（3位）
│    │    │    └───────── 规格代码（4位）
│    │    └────────────── 小类代码（2位）
│    └─────────────────── 中类代码（2位）
└──────────────────────── 大类代码（2位）
```

### 3.2 主要大类

| 代码 | 名称 | 代码 | 名称 |
|------|------|------|------|
| CL | 清洗设备 | US | 超声波系统 |
| SM | 半成品 | CT | 控制系统 |
| ST | 结构件 | RM | 原材料 |
| EL | 电气件 | PK | 包装材料 |
| PV | 泵阀管路 | AX | 辅助材料 |
| PN | 气动液压 | TL | 工具模具 |
| FT | 标准紧固件 | NZ | 喷淋系统 |
| HT | 加热系统 | | |

## 四、编号体系关联

### 4.1 项目-设备-物料关联

```
项目编号（GRT501）
    │
    ├── 设备型号（GRT-UCore-26-001）
    │       │
    │       └── 物料编号（BOM清单）
    │               ├── CL-01-01-28K5-001（成品）
    │               ├── ST-02-01-L080-001（结构件）
    │               ├── US-01-01-28K3-001（超声波系统）
    │               └── ...
    │
    └── 设备型号（GRT-SCore-26-002）
            │
            └── 物料编号（BOM清单）
                    └── ...
```

### 4.2 编号使用场景

| 场景 | 使用的编号 | 示例 |
|------|------------|------|
| 客户询价 | T编号 | T501 |
| 技术方案 | T编号 + 设备名称 | T501 / GRT-UCore |
| 商务报价 | T编号 | T501-QT-V1.0 |
| 合同签订 | GRT编号 | GRT501 |
| 生产计划 | GRT编号 + 设备型号 | GRT501 / GRT-UCore-26-001 |
| BOM管理 | 物料编号 | CL-01-01-28K5-001 |
| 采购订单 | 物料编号 | ST-02-01-L080-001 |
| 仓库管理 | 物料编号 | EL-01-01-075K-001 |

### 4.3 系统集成要求

在ERP/BOM系统中，需要建立以下编号关联：

| 数据表 | 主键 | 关联字段 |
|--------|------|----------|
| projects | project_id (GRT编号) | temp_project_id (T编号) |
| equipment | equipment_model | project_id |
| materials | material_code | - |
| bom | bom_id | equipment_model, material_code |
