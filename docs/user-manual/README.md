## 5. 常见问题解答

### 5.1 登录问题

**Q: 无法登录系统怎么办？**

A: 请检查以下几点：
1. 确认网络连接正常
2. 清除浏览器缓存后重试
3. 检查是否使用了正确的企业账号
4. 联系IT管理员确认账号权限

### 5.2 数据问题

**Q: 数据没有保存成功？**

A: 请检查：
1. 必填字段是否已填写
2. 网络连接是否正常
3. 查看是否有错误提示信息

### 5.3 性能问题

**Q: 系统响应很慢？**

A: 可以尝试：
1. 刷新页面
2. 清除浏览器缓存
3. 检查网络连接
4. 避免同时打开过多标签页
