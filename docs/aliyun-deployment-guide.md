## 4. 配置详细说明

### 4.1 ECS云服务器配置

**实例规格**: ecs.c7.xlarge（计算型第7代）

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| CPU | 4核 | Intel Xeon(Ice Lake) |
| 内存 | 8GB | DDR4 |
| 系统盘 | 50GB ESSD PL0 | 系统+应用 |
| 操作系统 | Ubuntu 22.04 LTS | 长期支持版 |
| 安全组 | 仅开放80/443/22 | 最小权限原则 |

**部署建议**:
- 两台ECS部署相同应用，通过SLB实现负载均衡和高可用
- 使用Docker容器化部署，便于扩展和维护
- 配置自动快照策略，每日备份

### 4.2 RDS MySQL配置

**实例规格**: mysql.n4.medium.1（通用型）

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| 版本 | MySQL 8.0 | 最新稳定版 |
| CPU | 4核 | 独享型 |
| 内存 | 16GB | 支持复杂查询 |
| 存储 | 200GB ESSD PL1 | 高性能SSD |
| 架构 | 高可用版 | 主备自动切换 |
| 备份 | 7天自动备份 | 数据安全 |

**性能参数调优**:
```sql
-- 推荐参数设置
innodb_buffer_pool_size = 12G  -- 内存的75%
max_connections = 500
innodb_flush_log_at_trx_commit = 2  -- 性能优先
slow_query_log = ON
long_query_time = 1
```

### 4.3 Redis配置

**实例规格**: redis.master.small.default

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| 版本 | Redis 7.0 | 最新稳定版 |
| 内存 | 2GB | 缓存+会话 |
| 架构 | 标准版-单副本 | 成本优化 |
| 持久化 | AOF | 数据安全 |

**使用场景**:
- 用户会话存储（Session）
- 热点数据缓存（项目列表、配置信息）
- 分布式锁（防止并发冲突）
- 消息队列（Webhook重试队列）

### 4.4 OSS对象存储配置

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| 存储类型 | 标准存储 | 频繁访问 |
| 读写权限 | 私有 | 通过签名URL访问 |
| 跨域设置 | 允许前端域名 | CORS配置 |
| 生命周期 | 90天转低频 | 成本优化 |

**Bucket规划**:
```
grt-production/
├── cases/          # 历史案例资料
├── bom/            # BOM设计图纸
├── quotations/     # 报价单附件
├── documents/      # 项目文档
└── temp/           # 临时文件（7天自动清理）
```

## 5. 网络与安全配置

### 5.1 VPC网络规划

| 网段 | 用途 | CIDR |
|------|------|------|
| VPC | 整体网络 | 172.16.0.0/16 |
| 应用子网 | ECS服务器 | 172.16.1.0/24 |
| 数据子网 | RDS/Redis | 172.16.2.0/24 |
| 管理子网 | 堡垒机/监控 | 172.16.3.0/24 |

### 5.2 安全组规则

**应用服务器安全组**:

| 方向 | 协议 | 端口 | 源地址 | 说明 |
|------|------|------|--------|------|
| 入 | TCP | 80 | SLB内网IP | HTTP |
| 入 | TCP | 443 | SLB内网IP | HTTPS |
| 入 | TCP | 22 | 堡垒机IP | SSH管理 |
| 出 | ALL | ALL | 0.0.0.0/0 | 出站不限 |

**数据库安全组**:

| 方向 | 协议 | 端口 | 源地址 | 说明 |
|------|------|------|--------|------|
| 入 | TCP | 3306 | 172.16.1.0/24 | MySQL |
| 入 | TCP | 6379 | 172.16.1.0/24 | Redis |

### 5.3 SSL证书配置

建议申请**阿里云免费DV证书**或购买**企业级OV证书**：

| 证书类型 | 价格 | 验证方式 | 适用场景 |

| 免费DV | 0元 | 域名验证 | 内部系统 |

## 10. 注意事项

### 10.1 合规要求

- **ICP备案**: 域名需完成ICP备案才能在国内访问
- **等保合规**: 如涉及敏感数据，需考虑等保2.0要求
- **数据安全**: 确保用户数据存储在国内节点

### 10.2 成本优化建议

1. **预留实例**: 对于稳定负载，购买预留实例可节省30-50%
2. **竞价实例**: 开发测试环境可使用竞价实例，节省70-90%
3. **存储分层**: 冷数据转低频存储，节省50%存储成本
4. **带宽共享**: 多ECS共享带宽包，降低网络成本

### 10.3 技术支持

- **阿里云工单**: 7×24小时技术支持
- **架构师咨询**: 可申请阿里云架构师免费咨询
- **培训认证**: 建议运维人员参加ACA/ACP认证
