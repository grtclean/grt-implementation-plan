## 一、物料编号的意义与目标

物料编号是以简短的文字、符号或数字来代表物料、品名、规格或类别的一种管理工具。对于GRT这样的工业清洗设备制造企业，建立科学的物料编号体系具有以下重要意义：

1. **增强物料数据的准确性**：避免一物多名、一名多物的混乱现象，确保研发、采购、生产、仓库各部门对物料的理解一致。

2. **提高物料管理效率**：以编码代替冗长的文字描述，简化物料的领发、验收、请购、跟催、盘点、储存等工作。

3. **支撑ERP/BOM系统运行**：物料编码是BOM物料管理系统的基础，科学的编码体系便于系统查询、统计和分析。

4. **降低库存成本**：有利于库存控制和呆料防止，减少资金积压。

5. **便于物料追溯**：支持产品质量追溯和售后服务。

## 二、物料编号设计原则

GRT公司物料编号遵循以下核心原则：

| 原则 | 说明 |
|------|------|
| **单一性** | 一个编码只能代表一种物料，同一物料只有一个编码 |
| **简单性** | 编码长度适中（15位），便于记录和识别 |
| **分类性** | 体现物料的类别属性，便于分类管理 |
| **扩展性** | 预留足够的编码空间，适应未来业务发展 |
| **稳定性** | 编码一经确定，原则上不再更改 |
| **系统性** | 适应ERP/BOM系统的处理要求 |

## 三、物料编号结构

### 3.1 编码总体结构

GRT公司采用**15位混合编码法**，结构如下：

```
AA - BB - CC - DDDD - EEE
│    │    │    │      └── 第5段：流水序号（3位数字）
│    │    │    └───────── 第4段：规格代码（4位字母数字）
│    │    └────────────── 第3段：小类代码（2位数字）
│    └─────────────────── 第2段：中类代码（2位数字）
└──────────────────────── 第1段：大类代码（2位字母）
```

**示例**：`CL-01-03-DN50-001`
- CL = 清洗设备（大类）
- 01 = 超声波清洗机（中类）
- 03 = 清洗槽体（小类）
- DN50 = 规格代码（DN50尺寸）
- 001 = 流水序号

### 3.2 编码段说明

| 段位 | 名称 | 位数 | 类型 | 说明 |
|------|------|------|------|------|
| 第1段 | 大类代码 | 2位 | 字母 | 物料的一级分类 |
| 第2段 | 中类代码 | 2位 | 数字 | 物料的二级分类 |
| 第3段 | 小类代码 | 2位 | 数字 | 物料的三级分类 |
| 第4段 | 规格代码 | 4位 | 字母+数字 | 物料的关键规格参数 |
| 第5段 | 流水序号 | 3位 | 数字 | 同规格物料的顺序号 |

### 4.4 规格代码（第4段）

规格代码为4位字母数字组合，用于标识物料的关键规格参数。编码规则如下：

| 物料类型 | 规格代码格式 | 示例 |
|----------|--------------|------|
| 槽体类 | DN+尺寸 | DN50（DN50规格）、L120（1200mm长） |
| 电机类 | 功率+电压 | 075K（0.75kW）、22KW（22kW） |
| 泵类 | 流量+扬程 | 10M3（10m³/h）、25MH（25m扬程） |
| 管道类 | 管径+壁厚 | D50T（DN50）、D100（DN100） |
| 超声波 | 频率+功率 | 28K1（28kHz 1kW）、40K5（40kHz 5kW） |
| 板材类 | 厚度+材质 | T2SS（2mm不锈钢）、T3AL（3mm铝板） |
| 通用 | 型号简写 | A001、B002 |

### 4.5 流水序号（第5段）

流水序号为3位数字（001-999），用于区分同一规格下的不同物料。

- 新物料从001开始顺序编号
- 同规格不同供应商的物料使用不同序号
- 物料变更后使用新序号，原序号作废

## 六、编码管理规范

### 6.1 编码申请流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  研发/采购  │───▶│  填写申请表 │───▶│  物料管理员 │───▶│  分配编码   │
│  提出需求   │    │  提交审批   │    │  审核分类   │    │  录入系统   │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

### 6.2 编码申请表

| 字段 | 必填 | 说明 |
|------|------|------|
| 物料名称 | 是 | 物料的标准名称 |
| 物料描述 | 是 | 详细的规格参数描述 |
| 建议分类 | 是 | 建议的大类/中类/小类 |
| 规格参数 | 是 | 关键规格参数 |
| 供应商 | 否 | 主要供应商信息 |
| 替代物料 | 否 | 可替代的物料编号 |
| 申请人 | 是 | 申请人姓名和部门 |
| 申请日期 | 是 | 申请日期 |

### 6.3 编码变更规则

1. **物料编码一经确定，原则上不得更改**
2. 以下情况需要申请新编码：
   - 物料的物理或化学性质发生变化
   - 物料的关键规格参数变化
   - 物料的供应商变更导致质量差异
3. 原编码作废后，需在系统中标记为"停用"，不得删除
4. 新旧编码的对应关系需要记录存档

### 6.4 编码维护职责

| 角色 | 职责 |
|------|------|
| 物料管理员 | 负责编码的分配、审核和维护 |
| 研发工程师 | 负责新产品物料的编码申请 |
| 采购专员 | 负责外购件物料的编码申请 |
| 仓库管理员 | 负责物料编码的日常使用和反馈 |
| IT管理员 | 负责编码系统的技术支持 |

## 七、与BOM系统的集成

### 7.1 BOM层级结构

GRT公司BOM采用多层级结构，物料编号在各层级的应用如下：

```
成品（CL-XX-XX-XXXX-XXX）
├── 半成品（SM-XX-XX-XXXX-XXX）
│   ├── 结构件（ST-XX-XX-XXXX-XXX）
│   ├── 电气件（EL-XX-XX-XXXX-XXX）
│   └── 泵阀管路（PV-XX-XX-XXXX-XXX）
├── 超声波系统（US-XX-XX-XXXX-XXX）
├── 控制系统（CT-XX-XX-XXXX-XXX）
└── 标准紧固件（FT-XX-XX-XXXX-XXX）
```

### 7.2 BOM数据字段

| 字段名 | 数据类型 | 说明 |
|--------|----------|------|
| material_code | VARCHAR(20) | 物料编号（主键） |
| material_name | VARCHAR(100) | 物料名称 |
| category_l1 | VARCHAR(2) | 大类代码 |
| category_l2 | VARCHAR(2) | 中类代码 |
| category_l3 | VARCHAR(2) | 小类代码 |
| spec_code | VARCHAR(4) | 规格代码 |
| serial_no | VARCHAR(3) | 流水序号 |
| unit | VARCHAR(10) | 计量单位 |
| description | TEXT | 物料描述 |
| status | ENUM | 状态（启用/停用） |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### 7.3 编码校验规则

系统应实现以下编码校验：

1. **格式校验**：编码必须符合15位格式要求
2. **唯一性校验**：同一编码不能重复使用
3. **分类校验**：大类/中类/小类代码必须在预定义范围内
4. **连续性校验**：流水序号应连续分配

## 八、实施建议

### 8.1 实施步骤

1. **第一阶段：规则确认**（1周）
   - 与研发、采购、仓库团队确认分类体系
   - 收集现有物料清单，确认覆盖范围
   - 确定规格代码的编码规则

2. **第二阶段：历史数据整理**（2周）
   - 整理现有物料清单
   - 按新规则进行编码转换
   - 建立新旧编码对照表

3. **第三阶段：系统配置**（1周）
   - 在BOM系统中配置编码规则
   - 导入物料主数据
   - 配置编码校验规则

4. **第四阶段：培训推广**（1周）
   - 编写操作手册
   - 组织各部门培训
   - 试运行并收集反馈

### 8.2 注意事项

1. **与团队充分沟通**：编码规则需要研发、采购、生产、仓库等多部门认可
2. **预留扩展空间**：分类体系应考虑未来业务发展需要
3. **保持规则一致**：所有部门必须严格按照统一规则执行
4. **定期维护更新**：随着业务发展，定期评估和优化编码规则
