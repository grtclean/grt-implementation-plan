# GRT智能系统菜单导航架构 v2.6.0

## 概述

本文档定义GRT智能系统的菜单导航结构，包括左侧边栏、顶部导航和面包屑导航的完整设计。

---

## 第一部分：导航结构概览

### 导航层级

```
顶级导航（Top Navigation）
├── Logo/品牌
├── 主菜单（Primary Menu）
├── 搜索框
├── 通知
└── 用户菜单

左侧边栏（Sidebar）
├── 主菜单项（一级）
│   ├── 子菜单项（二级）
│   │   ├── 功能项（三级）
│   │   └── ...
│   └── ...
└── 收起/展开控制

面包屑导航（Breadcrumb）
└── 首页 > 一级菜单 > 二级菜单 > 当前页面

底部导航（Footer）
└── 帮助 | 关于 | 反馈 | 设置
```

## 第五部分：菜单权限控制

### 权限规则

```typescript
// 菜单项权限检查
interface MenuItem {
  id: string;
  label: string;
  icon: string;
  path: string;
  requiredRoles?: string[];      // 所需角色
  requiredPermissions?: string[]; // 所需权限
  dataScope?: DataScope;          // 数据范围
  children?: MenuItem[];
}

// 权限检查函数
function isMenuItemVisible(
  item: MenuItem,
  user: User
): boolean {
  // 检查角色
  if (item.requiredRoles && !item.requiredRoles.includes(user.role)) {
    return false;
  }
  
  // 检查权限
  if (item.requiredPermissions) {
    const hasAllPermissions = item.requiredPermissions.every(
      perm => user.permissions.includes(perm)
    );
    if (!hasAllPermissions) return false;
  }
  
  // 检查数据范围
  if (item.dataScope && !checkDataScope(user, item.dataScope)) {
    return false;
  }
  
  return true;
}
```
