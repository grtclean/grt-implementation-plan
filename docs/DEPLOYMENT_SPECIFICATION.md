### 2.3 AI销售方法论

#### 2.3.1 ZOPA计算

```
ZOPA (Zone of Possible Agreement) = 客户预算上限 - 我方底价

若 ZOPA > 0，则存在成交可能
目标价 = 底价 + ZOPA × 期望系数
```

#### 2.3.2 谈判策略矩阵

| 客户情绪 | 推荐策略 | 行动建议 |

| 消极 | 让步策略 | 适度调整报价 |

## 4. 设计与规范标准

### 4.1 数据库设计规范

#### 4.1.1 命名规范

- 表名：小写下划线，如 `grt_projects`
- 字段名：小写下划线，如 `created_at`
- 索引名：`idx_表名_字段名`
- 外键名：`fk_表名_关联表名`

#### 4.1.2 必需字段

```sql
-- 每张业务表必须包含
id          VARCHAR(36) PRIMARY KEY,  -- UUID
created_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
updated_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
created_by  VARCHAR(36),              -- 创建人ID
```
