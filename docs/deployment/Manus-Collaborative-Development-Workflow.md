## 1. 概述

### 1.1 文档目的

本文档定义了GRT智能系统在Manus云端平台与Windows 11本地服务器之间的协同开发工作流程。该流程确保开发、测试、部署各环节有序进行，同时充分利用多种AI工具的优势，实现高效、可靠的系统迭代。

### 1.2 适用范围

本工作流程适用于以下场景：

- 新功能开发与实现
- 现有功能优化与重构
- Bug修复与问题处理
- 系统配置与环境变更
- 数据库Schema更新
- 第三方服务集成

### 1.3 核心原则

| 原则 | 说明 |
|-----|-----|
| **云边协同** | Manus云端负责开发，本地服务器负责生产运行 |
| **版本可追溯** | 所有变更通过Checkpoint和Git记录 |
| **测试先行** | 变更必须先在测试环境验证 |
| **自动化优先** | 尽可能使用脚本自动化重复操作 |
| **文档同步** | 代码变更必须同步更新相关文档 |

### 4.2 Phase 1: 需求分析

**4.2.1 需求收集**

在Manus平台创建新任务，描述功能需求。需求描述应包含：

- 功能目标和业务价值
- 用户故事或使用场景
- 验收标准
- 优先级和时间要求

**4.2.2 需求评审**

Manus分析需求可行性，评估：

- 技术复杂度
- 影响范围
- 资源需求
- 风险评估

**4.2.3 任务分解**

将需求分解为可执行的开发任务，更新 `todo.md`：

```markdown
## v1.3.23 新功能开发
- [ ] **功能A实现**
    - [ ] 数据库Schema设计
    - [ ] 后端API开发
    - [ ] 前端界面实现
    - [ ] 单元测试编写
```

## 5. 代码同步机制

### 5.1 同步流程

```
Manus开发完成 ──► 保存Checkpoint ──► 导出到GitHub ──► 本地git pull
                                                        │
                                                        ▼
                                                  安装依赖
                                                        │
                                                        ▼
                                                  数据库迁移
                                                        │
                                                        ▼
                                                  重启服务
```

### 5.2 自动同步脚本

**sync-from-manus.ps1**：

```powershell
# 完整同步流程
param(
    [switch]$SkipMigration,
    [switch]$SkipRestart,
    [string]$Environment = "test"
)

# 1. 备份当前版本
$timestamp = Get-Date -Format "yyyyMMdd-HHmmss"
$backupDir = "C:\Backups\grt-system\$timestamp"
Copy-Item -Path "." -Destination $backupDir -Recurse -Exclude "node_modules"

# 2. 拉取最新代码
git fetch origin
git pull origin main

# 3. 安装依赖
pnpm install

# 4. 数据库迁移
if (-not $SkipMigration) {
    pnpm db:push
}

# 5. 重启服务
if (-not $SkipRestart) {
    pm2 restart grt-$Environment
}
```

### 8.1 故障分级

|-----|-----|---------|---------|

### 8.2 回滚流程

```powershell
# rollback.ps1 - 回滚脚本

param(
    [Parameter(Mandatory=$true)]
    [string]$BackupTimestamp,
    
    [Parameter(Mandatory=$false)]
    [string]$Environment = "production"
)

Write-Host "开始回滚到版本: $BackupTimestamp" -ForegroundColor Yellow

# 1. 停止服务
pm2 stop grt-$Environment

# 2. 备份当前版本
$currentBackup = "C:\Backups\grt-system\rollback-$(Get-Date -Format 'yyyyMMdd-HHmmss')"
Copy-Item -Path "." -Destination $currentBackup -Recurse -Exclude "node_modules"

# 3. 恢复备份版本
$backupPath = "C:\Backups\grt-system\$BackupTimestamp"
if (Test-Path $backupPath) {
    # 恢复代码
    Copy-Item -Path "$backupPath\*" -Destination "." -Recurse -Force
    
    # 重新安装依赖
    pnpm install
    
    # 启动服务
    pm2 start grt-$Environment
    
    Write-Host "回滚完成" -ForegroundColor Green
} else {
    Write-Host "备份不存在: $backupPath" -ForegroundColor Red
    exit 1
}
```
