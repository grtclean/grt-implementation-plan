## 一、命名体系概述

### 1.1 设计原则

GRT设备命名采用**英文功能名 + 数字代码**的组合方式，不使用GRT前缀，以实现：

1. **唯一性**：每个数字代码对应唯一的设备类型、配置和特征
2. **系统性**：数字代码按设备大类、结构形式、配置等级有规律编排
3. **国际化**：英文功能名便于全球市场推广
4. **可扩展**：预留足够的编码空间适应未来产品发展

### 1.2 命名结构

```
[英文功能名] + [数字代码]
     │              │
     │              └── 3-4位数字，标识设备类型、结构、配置
     └───────────────── 清洗工艺/功能的英文缩写
```

**示例**：`Ultrasonic 801` = 超声波清洗机，腔体式，1个腔体

## 三、数字代码体系

### 3.1 代码结构

数字代码采用**3-4位数字**，结构如下：

```
X X X (X)
│ │ │  └── 第4位（可选）：细分配置/特殊功能
│ │ └──── 第3位：腔体数量/工位数/配置等级
│ └────── 第2位：系列变体/工艺特征
└──────── 第1位：设备大类
```

## 七、系统集成要求

### 7.1 数据库字段设计

| 字段名 | 数据类型 | 说明 |
|--------|----------|------|
| equipment_code | VARCHAR(20) | 设备型号（如 Ultrasonic 801） |
| function_name | VARCHAR(50) | 英文功能名（如 Ultrasonic） |
| numeric_code | VARCHAR(10) | 数字代码（如 801） |
| category_code | CHAR(1) | 大类代码（1-9） |
| series_code | CHAR(1) | 系列代码 |
| config_code | CHAR(1) | 配置代码 |
| suffix_code | CHAR(1) | 后缀代码（可选） |
| chinese_name | VARCHAR(100) | 中文名称 |
| description | TEXT | 设备描述 |

### 7.2 编码校验规则

系统应实现以下校验：

1. **格式校验**：数字代码必须为3-4位数字
2. **范围校验**：第1位必须在1-9范围内
3. **唯一性校验**：同一数字代码不能重复使用
4. **组合校验**：英文功能名与数字代码的组合必须合理
