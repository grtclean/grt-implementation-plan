## 十、资质管理系统集成

### 10.1 系统功能需求

1. **资质档案管理** - 管理所有认证证书、有效期、审核记录
2. **到期提醒** - 自动提醒证书到期、年审时间
3. **客户要求映射** - 将客户资质要求与GRT现有资质对比
4. **差距分析** - 自动分析与目标客户的资质差距
5. **建设计划跟踪** - 跟踪资质建设进度

### 10.2 数据库表设计

```sql
-- 资质证书表
CREATE TABLE certifications (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,           -- 证书名称
    cert_number VARCHAR(50),              -- 证书编号
    issuing_body VARCHAR(100),            -- 发证机构
    issue_date DATE,                      -- 发证日期
    expiry_date DATE,                     -- 到期日期
    status ENUM('valid', 'expired', 'pending', 'planned'),
    file_url VARCHAR(255),                -- 证书文件URL
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 客户资质要求表
CREATE TABLE customer_cert_requirements (
    id INT PRIMARY KEY AUTO_INCREMENT,
    customer_name VARCHAR(100) NOT NULL,  -- 客户名称
    customer_type ENUM('oem', 'tier1', 'tier2'),
    certification_id INT,                 -- 关联资质
    is_mandatory BOOLEAN DEFAULT TRUE,    -- 是否必须
    notes TEXT,
    FOREIGN KEY (certification_id) REFERENCES certifications(id)
);

-- 资质建设计划表
CREATE TABLE cert_building_plans (
    id INT PRIMARY KEY AUTO_INCREMENT,
    certification_name VARCHAR(100) NOT NULL,
    responsible_dept VARCHAR(50),         -- 负责部门
    budget DECIMAL(10,2),                 -- 预算
    target_date DATE,                     -- 目标日期
    status ENUM('planned', 'in_progress', 'completed', 'delayed'),
    progress INT DEFAULT 0,               -- 进度百分比
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
