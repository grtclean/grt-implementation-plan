## 1. 需求概述

基于v2.5.0版本，进行架构级优化与逻辑对齐，确保后续Claude Code实施的严谨性。主要包含五大核心升级：

1. **工业安全拦截器中间件**：双层校验机制，确保AI建议参数在安全阈值内
2. **数据模型扩展**：工业参数精细度提升，字段类型标准化
3. **影子执行模式**：新增AI学习模式，用于后台比对人工操作与AI预测偏差
4. **流程笔记多模态深化**：增强工业OCR识别和跨流程溯源能力
5. **工程实施约束**：UI/UX准则和错误处理升级

## 2. 技术方案

### 2.1 工业安全拦截器中间件

**架构设计**：

```
AI建议生成 → 安全拦截器 → 静态规则库校验 → grt_ai_process_suggestions
                ↓
           校验失败 → 返回 AI_003 错误码
```

**核心组件**：

| 组件 | 说明 |
|------|------|
| safety_threshold_check | 功能型AI助手配置属性，启用安全校验 |
| IndustrialSafetyMiddleware | 中间件，拦截AI建议进行校验 |
| SafetyRuleEngine | 静态规则库引擎，定义材质/机型安全阈值 |

**安全规则库结构**：

```typescript
interface SafetyRule {
  id: string;
  material_type: string;      // 材质类型
  equipment_model: string;    // 设备型号
  parameter_name: string;     // 参数名称
  min_value: number;          // 最小安全值
  max_value: number;          // 最大安全值
  unit_type: string;          // 单位类型
  severity: 'warning' | 'critical' | 'fatal';
}
```

### 2.2 数据模型扩展

**字段类型标准化**：

| 原类型 | 新类型 | 说明 |
|--------|--------|------|
| float | decimal(10,2) | 所有物理量字段 |
| varchar | enum | unit_type字段 |

**新增字段**：

```typescript
// FunctionalAiAssistant 接口扩展
interface FunctionalAiAssistant {
  // ... 现有字段
  iot_linkage_map: {
    parameter_name: string;
    plc_register_address: string;
    data_type: 'int16' | 'int32' | 'float32' | 'float64';
    read_write: 'read' | 'write' | 'read_write';
  }[];
}
```

**grt_ai_solutions表扩展**：

```sql
ALTER TABLE grt_ai_solutions
  MODIFY target_temp DECIMAL(10,2),
  MODIFY pressure DECIMAL(10,2),
  ADD COLUMN unit_type ENUM('bar', 'MPa', '°C', 'mm', 'kg', 's') NOT NULL DEFAULT 'bar';
```

### 2.3 影子执行模式

**执行模式扩展**：

| 模式 | 代码 | 说明 |
|------|------|------|
| 系统内AI | internal | 基于案例库，快速响应 |
| 泛互式AI | generative | 深度推理，复杂场景 |
| 影子模式 | shadow | 仅记录，不触发确认按钮 |

**学习记录表结构**：

```sql
CREATE TABLE grt_ai_learning_records (
  id VARCHAR(36) PRIMARY KEY,
  suggestion_id VARCHAR(36) NOT NULL,
  ai_predicted_value JSON NOT NULL,
  human_actual_value JSON,
  deviation_score DECIMAL(5,2),
  deviation_analysis TEXT,
  learning_status ENUM('pending', 'analyzed', 'applied') DEFAULT 'pending',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  analyzed_at TIMESTAMP,
  FOREIGN KEY (suggestion_id) REFERENCES grt_ai_process_suggestions(id)
);
```

### 2.5 工程实施约束

**UI/UX准则**：

1. AI建议面板必须保留"一键回滚"按钮
2. 修改前后快照完整记录在grt_ai_communication_logs

**错误码扩展**：

| 错误码 | 名称 | 说明 |
|--------|------|------|
| AI_003 | 数据验证失败 | AI建议参数超出安全阈值 |
| AI_009 | 安全规则冲突 | 违反工业安全规则 |
| AI_010 | 物联网指令超时 | IoT设备通信超时 |
