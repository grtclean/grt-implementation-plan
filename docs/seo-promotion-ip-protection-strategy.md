## 1. 战略概述

### 1.1 双重目标平衡

GRT智能系统的数字营销战略需要在两个看似矛盾的目标之间取得平衡：一方面，通过SEO优化提升品牌曝光度和潜在客户获取能力；另一方面，严格保护核心工艺参数、化学配方、成本模型等知识产权资产。

本规范采用**分层透明度模型**，将信息按敏感程度分为四个层级，每个层级有明确的公开范围和访问控制机制。这种设计确保GRT能够向市场展示足够的技术实力和成功案例，同时将核心竞争力牢牢掌握在自己手中。

### 1.2 核心设计原则

**展示能力而非方法**：公开内容聚焦于GRT能够实现的结果（如"VDA 19.1 Class A清洁度"），而非实现这些结果的具体方法（如温度曲线、化学配方）。

**验证而非披露**：对于客户需要确认的合规性信息，通过零知识证明（ZKP）接口提供验证能力，客户可以确认"GRT符合标准"，但无法获取具体参数。

**价值引导而非信息倾泻**：SEO内容设计为引导潜在客户进入销售漏斗，而非提供足以让竞争对手复制的详细技术资料。

## 4. 核心资产保护策略

### 4.1 核心资产分类

GRT的核心资产按敏感程度分为三个等级：

| 资产等级 | 资产类型 | 保护措施 | 泄露影响 |
|---------|---------|---------|---------|
| 最高机密 | 化学配方、工艺参数曲线 | AES-256加密+TEE执行 | 核心竞争力丧失 |
| 高度机密 | 成本模型、定价算法 | AES-256加密+访问控制 | 商业利益受损 |
| 内部机密 | 客户名单、项目详情 | 访问控制+审计日志 | 客户关系受损 |

### 4.2 技术保护措施

**数据加密**：所有核心资产在数据库中采用AES-256-GCM加密存储，密钥由独立的密钥管理服务（KMS）管理，与数据库物理隔离。

**可信执行环境（TEE）**：涉及核心资产的计算（如成本估算、工艺仿真）在AWS Nitro Enclaves或Intel SGX环境中执行，确保即使云服务商也无法访问运行时数据。

**零知识证明（ZKP）**：对于需要向客户证明但不能披露的信息，通过ZKP接口提供验证能力。客户可以验证"GRT的工艺参数符合VDA 19.1标准"，但无法获取具体参数值。

### 4.3 访问控制矩阵

| 角色 | L0公开 | L1注册 | L2客户 | L3核心 |
|-----|-------|-------|-------|-------|
| 匿名访客 | 读取 | × | × | × |
| 注册用户 | 读取 | 读取 | × | × |
| 授权客户 | 读取 | 读取 | 读取（限项目） | × |
| 内部员工 | 读取 | 读取 | 读取 | 按角色 |
| 技术管理员 | 读取 | 读取 | 读取 | 读取（审计） |

### 4.4 内容脱敏规则

在生成公开内容时，系统自动应用以下脱敏规则：

| 原始信息 | 脱敏后 | 适用场景 |
|---------|-------|---------|
| Tesla Model Y项目 | 某美系新能源品牌项目 | 案例展示 |
| 温度62.5°C | 温度范围60-65°C | 技术描述 |
| 化学剂配方A-2026 | 专有清洗剂 | 工艺介绍 |
| 成本￥1,234,567 | 成本范围100-150万 | 报价参考 |
| 节拍45秒 | 节拍<60秒 | 能力介绍 |

## 5. 客户门户入口设计

### 5.1 门户功能架构

客户门户允许授权客户查询其项目状态，但严格限制信息范围：

```
客户门户
├── 项目概览
│   ├── 项目基本信息
│   ├── 当前里程碑状态
│   └── 关键日期
├── 进度追踪
│   ├── M0-M12阶段状态
│   ├── 里程碑完成情况
│   └── 下一步计划
├── 质量报告
│   ├── ZKP验证结果
│   ├── 检测报告摘要
│   └── 合规证书
└── 文档下载
    ├── 合同文件
    ├── 技术规格书（脱敏版）
    └── 验收报告
```

### 5.2 访问控制机制

**令牌认证**：每个客户项目生成唯一的访问令牌，令牌绑定特定项目和权限范围。

**权限粒度**：

| 权限类型 | 描述 | 默认授予 |
|---------|------|---------|
| view_project_status | 查看项目状态 | ✓ |
| view_quality_reports | 查看质量报告 | ✓ |
| request_zkp_verification | 请求ZKP验证 | × |
| download_documents | 下载文档 | × |

**审计日志**：所有客户门户访问记录完整的审计日志，包括访问时间、访问内容、IP地址等。

### 5.3 信息展示规则

| 信息类型 | 客户可见 | 不可见 |
|---------|---------|-------|
| 项目进度 | M0-M12阶段状态 | 内部任务分解 |
| 质量数据 | ZKP验证结果（通过/未通过） | 实际工艺参数 |
| 交付计划 | 里程碑日期 | 内部资源调度 |
| 成本信息 | 合同金额、已付款 | 成本构成明细 |
| 技术规格 | 设备型号、主要参数 | 核心工艺配置 |

```json

  "description": "适用于汽车零部件的高压喷淋清洗设备，支持VDA 19.1全等级认证",
  "brand": {
    "@type": "Brand",
    "name": "GRT"
  },
  "offers": {
    "@type": "Offer",
    "availability": "https://schema.org/InStock"
  }
}
```

| 指标 | 目标值 | 优化措施 |
