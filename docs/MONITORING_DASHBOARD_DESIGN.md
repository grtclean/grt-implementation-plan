## 概述

**监控仪表板** 是GRT智能系统的核心运维工具，提供实时的系统监控、告警规则执行情况、历史趋势分析和关键指标展示。

### 核心目标

- **实时监控**: 显示系统当前状态和关键指标
- **历史分析**: 追踪资源使用趋势，识别异常模式
- **告警管理**: 展示告警规则执行情况和有效性
- **优化建议**: 基于数据提供告警规则优化建议
- **决策支持**: 帮助运维人员做出数据驱动的决策

### 主要特性

| 特性 | 说明 |
|------|------|
| **实时仪表板** | 显示CPU、内存、磁盘、应用、数据库的实时状态 |
| **历史趋势** | 支持7天、30天、90天、1年的历史数据查看 |
| **告警统计** | 显示告警规则执行次数、成功率、失败率 |
| **热力图** | 显示告警触发频率的时间分布（热力图） |
| **优化建议** | 基于数据自动生成告警规则优化建议 |
| **导出报告** | 支持PDF、Excel格式的监控报告导出 |

## 仪表板组件

### 1. 实时监控面板

**位置**: 仪表板顶部  
**更新频率**: 每5秒更新一次  
**显示内容**:

| 指标 | 说明 | 告警阈值 |
|------|------|--------|
| **CPU使用率** | 当前CPU使用百分比 | 80%/95% |
| **内存使用率** | 当前内存使用百分比 | 85%/95% |
| **磁盘使用率** | 当前磁盘使用百分比 | 80%/95% |
| **应用状态** | 应用进程运行状态 | 停止/错误 |
| **数据库连接** | 数据库连接数 | >100 |
| **网络流量** | 网络入出流量 | >1Gbps |

**设计要点**:
- 使用卡片布局，每个指标一个卡片
- 使用进度条显示百分比
- 使用颜色编码：绿色(正常) / 黄色(警告) / 红色(严重)
- 显示趋势箭头（↑/↓/→）

### 2. 历史趋势图表

**位置**: 仪表板中部  
**时间范围**: 7天、30天、90天、1年可选  
**显示内容**:

| 图表类型 | 指标 | 说明 |
|---------|------|------|
| **折线图** | CPU/内存/磁盘 | 显示使用率随时间的变化 |
| **柱状图** | 告警次数 | 显示每天的告警触发次数 |
| **热力图** | 告警时间分布 | 显示告警在一周内的分布 |

**设计要点**:
- 支持时间范围选择（7天/30天/90天/1年）
- 支持多指标对比
- 支持鼠标悬停查看具体数值
- 支持导出为图片

### 3. 告警统计分析

**位置**: 仪表板下部左侧  
**显示内容**:

```
告警统计
├─ 总告警次数: 1,234
├─ 今日告警: 45
├─ 本周告警: 312
├─ 本月告警: 1,234
├─ 告警成功率: 92.3%
├─ 平均响应时间: 2.5分钟
└─ 虚假告警率: 7.7%
```

**设计要点**:
- 使用大数字显示总数
- 使用小卡片显示各类统计
- 支持时间范围筛选
- 支持按告警级别筛选

### 4. 优化建议展示

**位置**: 仪表板下部右侧  
**显示内容**:

```
优化建议
├─ 建议1: CPU告警阈值过低
│  ├─ 当前: 80%
│  ├─ 建议: 85%
│  └─ 理由: 历史数据显示正常波动范围为75-88%
├─ 建议2: 内存告警频繁
│  ├─ 当前: 85%
│  ├─ 建议: 90%
│  └─ 理由: 虚假告警率达12%，建议提高阈值
└─ 建议3: 添加磁盘告警规则
   ├─ 建议: 创建磁盘使用率规则
   └─ 理由: 磁盘使用率上升趋势明显
```

**设计要点**:
- 按优先级排序
- 显示当前值和建议值
- 提供优化理由
- 支持一键应用建议

## 数据模型

### 监控指标表 (metrics)

```sql
CREATE TABLE metrics (
  id BIGINT PRIMARY KEY,
  metric_type VARCHAR(50),           -- cpu, memory, disk, network, db_connection
  metric_name VARCHAR(100),          -- 指标名称
  metric_value DECIMAL(10, 2),       -- 指标值
  unit VARCHAR(20),                  -- 单位 (%, MB, Gbps)
  timestamp BIGINT,                  -- 时间戳
  host_id VARCHAR(100),              -- 主机ID
  created_at BIGINT
);
```

### 告警统计表 (alert_statistics)

```sql
CREATE TABLE alert_statistics (
  id BIGINT PRIMARY KEY,
  alert_rule_id BIGINT,              -- 告警规则ID
  alert_level VARCHAR(20),           -- 低/中/高/严重
  trigger_count INT,                 -- 触发次数
  success_count INT,                 -- 成功次数
  failure_count INT,                 -- 失败次数
  false_positive_count INT,          -- 虚假告警次数
  average_response_time INT,         -- 平均响应时间(秒)
  date DATE,                         -- 统计日期
  created_at BIGINT
);
```

### 优化建议表 (optimization_suggestions)

```sql
CREATE TABLE optimization_suggestions (
  id BIGINT PRIMARY KEY,
  suggestion_type VARCHAR(50),       -- threshold_adjustment, new_rule, rule_removal
  alert_rule_id BIGINT,              -- 告警规则ID
  current_value VARCHAR(100),        -- 当前值
  suggested_value VARCHAR(100),      -- 建议值
  reason TEXT,                       -- 优化理由
  confidence DECIMAL(5, 2),          -- 置信度 (0-100)
  priority INT,                      -- 优先级 (1-5)
  status VARCHAR(20),                -- pending, applied, rejected
  applied_at BIGINT,                 -- 应用时间
  created_at BIGINT
);
```

## 实现规范

### 前端组件结构

```
MonitoringDashboard/
├─ components/
│  ├─ RealtimePanel.tsx              -- 实时监控面板
│  ├─ TrendChart.tsx                 -- 历史趋势图表
│  ├─ AlertStatistics.tsx            -- 告警统计分析
│  ├─ OptimizationSuggestions.tsx    -- 优化建议展示
│  └─ TimeRangeSelector.tsx          -- 时间范围选择器
├─ hooks/
│  ├─ useRealtimeMetrics.ts          -- 实时数据Hook
│  ├─ useHistoricalData.ts           -- 历史数据Hook
│  └─ useSuggestions.ts              -- 优化建议Hook
└─ MonitoringDashboard.tsx           -- 主组件
```

### 后端API规范

```
GET /api/monitoring/metrics/realtime
  返回: 实时监控指标

GET /api/monitoring/metrics/historical
  参数: timeRange (7d/30d/90d/1y), metricType
  返回: 历史数据

GET /api/monitoring/statistics
  参数: dateRange, alertLevel
  返回: 告警统计数据

GET /api/monitoring/suggestions
  参数: limit, priority
  返回: 优化建议列表

POST /api/monitoring/suggestions/{id}/apply
  返回: 应用结果
```

### 数据更新策略

| 数据类型 | 更新频率 | 保留周期 |
|---------|--------|--------|
| **实时指标** | 5秒 | 7天 |
| **小时统计** | 每小时 | 1年 |
| **日统计** | 每天 | 3年 |
| **优化建议** | 每小时 | 永久 |

## 用户交互

### 交互流程

```
用户打开仪表板
    ↓
加载实时数据 (5秒刷新)
    ↓
用户选择时间范围
    ↓
加载历史数据
    ↓
计算并显示统计
    ↓
生成优化建议
    ↓
用户可选择应用建议
    ↓
系统更新告警规则
    ↓
重新计算统计
```

### 关键操作

#### 1. 查看实时监控

```
步骤:
1. 打开监控仪表板
2. 查看实时监控面板
3. 观察各指标的当前值和趋势
4. 如果有红色告警，点击查看详情
```

#### 2. 分析历史趋势

```
步骤:
1. 选择时间范围（7天/30天/90天/1年）
2. 选择要查看的指标（CPU/内存/磁盘）
3. 观察趋势图表
4. 鼠标悬停查看具体数值
5. 导出图表为图片或PDF
```

#### 3. 查看告警统计

```
步骤:
1. 在仪表板下部查看告警统计
2. 点击具体统计项查看详情
3. 按告警级别或时间范围筛选
4. 查看虚假告警率和响应时间
```

#### 4. 应用优化建议

```
步骤:
1. 查看优化建议列表
2. 阅读建议理由和置信度
3. 点击"应用"按钮应用建议
4. 系统自动更新告警规则
5. 观察新的统计数据
```
