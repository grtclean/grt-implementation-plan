## 2. 社群管理模块

### 2.1 功能概述

社群管理模块实现微信技术交流群的智能化运营，通过Social Bridge监听群消息，AI自动草拟回复，人工审核后发布。

### 2.2 核心功能

#### 2.2.1 群组管理
- **添加群组**: 点击"添加群组"按钮，输入群名称和Webhook URL
- **群组状态**: 查看每个群的成员数、消息数、待审核回复数
- **群组设置**: 配置AI回复策略、审核流程、通知规则

#### 2.2.2 消息监控
- **实时消息流**: 查看所有群的消息实时流
- **消息过滤**: 按群组、时间、关键词筛选消息
- **敏感信息脱敏**: 系统自动识别并脱敏敏感信息

#### 2.2.3 AI回复审核
- **待审核队列**: 查看AI草拟的所有待审核回复
- **人工修订**: 编辑AI回复内容后批准发布
- **批量操作**: 支持批量批准或拒绝回复

#### 2.2.4 发布队列
- **发布状态追踪**: 查看已批准回复的发送状态
- **发送失败重试**: 对发送失败的消息进行重试
- **发送历史**: 查看所有已发送消息的历史记录

### 2.3 操作流程

```
1. 添加群组 → 配置Webhook
2. 消息自动采集 → 脱敏处理
3. AI分析消息 → 草拟回复
4. 人工审核 → 批准/修订/拒绝
5. 批准后自动发送 → 状态追踪
```

### 2.4 最佳实践

- 定期检查待审核队列，避免回复延迟
- 根据AI回复质量调整提示词模板
- 对高频问题建立标准回复模板

## 3. 液态用工模块

### 3.1 功能概述

液态用工模块实现技能原子化和任务竞标市场，支持技能胶囊创建、任务发布竞标、智能合约支付。

### 3.2 核心功能

#### 3.2.1 技能胶囊
- **创建胶囊**: 定义技能名称、等级、版税率
- **ZKP证明**: 生成零知识能力证明
- **调用统计**: 查看技能被调用的次数和收益

#### 3.2.2 任务竞标
- **发布任务**: 创建任务并设置预算、SLA要求
- **查看竞标**: 查看所有Agent的竞标报价和评分
- **AI评估**: 系统自动对竞标进行预评估打分
- **选择中标**: 选择最优竞标者并创建合约

#### 3.2.3 智能合约
- **合约创建**: 自动生成智能合约
- **支付类型**: 支持e-CNY、USDT、G-Token
- **条件触发**: 设置质量评分等触发条件
- **争议处理**: 合约争议的仲裁流程

### 3.3 操作流程

```
1. 创建技能胶囊 → 设置版税率
2. 发布任务 → 设置预算和SLA
3. Agent竞标 → AI预评估
4. 选择中标 → 创建智能合约
5. 任务完成 → 触发支付
```

### 3.4 最佳实践

- 技能胶囊命名应具体明确，如"高压喷嘴流体仿真 Level 5"
- 任务SLA应设置合理的交付时间和质量标准
- 定期查看技能调用统计，优化版税率

## 4. AI销售模块

### 4.1 功能概述

AI销售模块实现AI-to-AI自主谈判，支持多轮报价还价、情绪分析、ZOPA区间计算、零知识证明验证。

### 4.2 核心功能

#### 4.2.1 谈判会话
- **创建会话**: 与客户采购AI建立谈判会话
- **多轮谈判**: 查看每轮的报价、还价、情绪分析
- **ZOPA计算**: 系统自动计算协议达成区间
- **状态追踪**: 谈判中/达成交易/放弃

#### 4.2.2 谈判策略
- **底价设置**: 设置最低可接受价格
- **目标价设置**: 设置理想成交价格
- **让步策略**: 配置每轮让步幅度
- **情绪响应**: 根据客户情绪调整策略

#### 4.2.3 ZKP证明
- **能力证明**: 证明产能而不泄露具体数据
- **合规证明**: 证明符合VDA等标准
- **绿色能源证明**: 证明使用绿色能源
- **客户验证**: 客户验证证明的有效性

### 4.3 操作流程

```
1. 配置谈判策略 → 设置底价/目标价
2. 创建谈判会话 → 发送初始报价
3. 接收还价 → 分析客户情绪
4. 计算ZOPA → 决定下一轮报价
5. 达成交易 → 生成ZKP证明
```

### 4.4 最佳实践

- 根据客户类型预设不同的谈判策略
- 关注情绪分析结果，及时调整谈判节奏
- 对重要客户使用ZKP证明增强信任

## 5. 门径管理模块

### 5.1 功能概述

门径管理模块实现M3-M12阶段门禁管控和JIT/JIS生产拉动，支持检查项自动验证、一票否决、设备指令下发。

### 5.2 核心功能

#### 5.2.1 门径检查
- **阶段概览**: 查看M3/M4/M5/M7/M12各阶段状态
- **检查项列表**: 查看每个阶段的检查项
- **自动验证**: 系统自动从ERP/PLM验证检查项
- **一票否决**: 标记强制性检查项

#### 5.2.2 检查项管理
- **添加检查项**: 为特定阶段添加检查项
- **验证源配置**: 配置自动验证的数据源
- **状态更新**: 手动更新检查项状态
- **批量操作**: 批量通过或标记检查项

#### 5.2.3 生产拉动
- **信号监控**: 查看所有生产拉动信号
- **触发事件**: 查看触发信号的事件
- **设备指令**: 查看发送给AAS设备的指令
- **历史记录**: 查看拉动信号的历史

### 5.3 操作流程

```
1. 配置阶段检查项 → 设置验证源
2. 项目进入阶段 → 自动验证检查项
3. 所有检查项通过 → 阶段放行
4. 触发事件发生 → 生成拉动信号
5. 信号发送设备 → 执行生产指令
```

### 5.4 最佳实践

- 为Tier 1客户项目设置更严格的检查项
- 定期检查自动验证源的连接状态
- 对一票否决项设置多人审核

## 6. 个人智能体模块

### 6.1 功能概述

个人智能体模块实现YDW数据映射，通过行为探针采集用户行为，AI推断技能，构建个人能力画像和知识图谱。

### 6.2 核心功能

#### 6.2.1 能力画像
- **个人信息**: 查看DID身份和基本信息
- **技能等级**: 查看T/S/D/C/K/L六维能力等级
- **成长记录**: 查看最近的技能成长事件

#### 6.2.2 行为探针
- **行为日志**: 查看自动采集的行为记录
- **上下文类型**: IDE提交、CAD保存、文档编辑等
- **技能推断**: AI根据行为推断技能标签
- **数据详情**: 查看具体的操作数据

#### 6.2.3 过程笔记
- **创建笔记**: 记录项目过程中的问题和解决方案
- **AI知识提取**: AI自动提取结构化知识
- **笔记搜索**: 按关键词搜索历史笔记
- **知识复用**: 在新项目中复用历史经验

#### 6.2.4 知识图谱
- **知识节点**: 查看提取的知识节点数量
- **知识关联**: 查看节点之间的关联关系
- **技能映射**: 查看知识到技能的映射

### 6.3 操作流程

```
1. 日常工作 → 行为自动采集
2. 行为分析 → AI推断技能
3. 遇到问题 → 记录过程笔记
4. AI提取知识 → 构建知识图谱
5. 能力画像更新 → 技能等级提升
```

### 6.4 最佳实践

- 养成记录过程笔记的习惯
- 定期查看能力画像，了解成长方向
- 对AI推断的技能进行确认和补充

## 7. 常见问题

### Q1: 社群管理的Webhook如何配置？
A: 需要在微信群管理工具中获取Webhook URL，然后在社群管理模块中添加群组时填入。

### Q2: 技能胶囊的版税率如何设置？
A: 建议根据技能稀缺程度设置，通用技能5-10%，稀缺技能15-25%。

### Q3: AI谈判的底价和目标价如何确定？
A: 底价应基于成本加最低利润，目标价应参考市场价格和客户预算。

### Q4: 门径检查项的自动验证失败怎么办？
A: 检查验证源配置是否正确，确认ERP/PLM系统连接正常。

### Q5: 行为探针采集了哪些数据？
A: 仅采集工作相关的操作行为（如代码提交、文档保存），不采集个人隐私数据。
