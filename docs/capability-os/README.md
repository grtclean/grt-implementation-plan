## 核心设计原则

### 原则一：能力为核心

传统系统以项目或流程为核心，GRT能力操作系统以**能力**为核心。所有业务活动都是能力的训练场和验证场，所有数据最终都汇聚到能力体系。

### 原则二：证据驱动

能力等级不靠人工评估，而是靠**系统自动采集的证据**计算。每一次服务、每一个项目、每一次培训都产生能力证据。

### 原则三：系统约束

关键业务规则不靠人的自觉，而是**内嵌到系统中**。能力门槛、红蓝对抗、问题闭环都是系统强制执行的约束。

### 原则四：问题只发生一次

同一个问题在组织内只允许发生一次。通过系统性学习机制，将问题转化为能力，将能力固化到系统。
