# 简道云 API 权限配置指南

## 问题说明

当前API Key可以正常访问应用列表和表单数据接口，但通讯录接口返回403错误。这是因为API Key的**接口授权范围**可能未包含通讯录接口。

## 解决步骤

### 1. 登录简道云管理后台

访问 https://www.jiandaoyun.com 并登录您的账户。

### 2. 进入开放平台 → 密钥管理

在工作台顶部导航栏，点击「开放平台」，然后选择「密钥管理」→「API Key」。

### 3. 找到当前使用的API Key

在API Key列表中，找到密钥值为 `du0Hlmkgjjf4quJerQkjPftXSTfguSq0` 的API Key。

### 4. 修改接口授权范围

点击该API Key所在行，进入详情页面：

1. 找到「接口授权范围」设置项
2. 如果当前是「部分接口」，需要添加以下接口：
   - **通讯录接口** - 包括成员接口、部门接口、角色接口
3. 或者直接选择「全部接口」以授权所有API接口

### 5. 保存设置

修改完成后保存设置，新的权限将立即生效。

## 接口授权范围说明

简道云API Key支持两种接口授权范围：

| 范围类型 | 说明 |
|---------|------|
| 全部接口 | 可使用所有API接口，包括通讯录、应用、表单、数据、文件、流程等 |
| 部分接口 | 仅可使用列表中添加的接口 |

## 通讯录接口包含的功能

- **成员接口**：获取/添加/修改/删除成员信息
- **部门接口**：获取部门列表、部门成员、创建/修改/删除部门
- **角色接口**：获取角色列表、角色成员
- **角色组接口**：获取角色组信息

## 验证方法

配置完成后，可以通过以下命令测试通讯录API：

```bash
curl -X POST "https://api.jiandaoyun.com/api/v5/corp/dept/list" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"dept_no": 1}'
```

如果返回部门列表数据，说明权限配置成功。
