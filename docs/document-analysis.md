# 文档分析关键发现

## 1. 杰瑞德ERP管理系统流程图 (杰瑞德自动化-12.18.pdf)

### 系统模块架构
整个ERP系统包含以下核心模块：

| 模块 | 主要功能 |
|------|---------|
| **基础资料** | 物料档案、供应商物料价格库、物料批次号管理、物料BOM档案、工序档案、工艺路线、技术方案、员工基础信息 |
| **CRM模块** | 各部门销售目标、个人销售目标、公海池、来源标签、个人线索、商机、技术方案、商机核价、商机报价、客户档案、合同签订 |
| **项目管理** | 项目档案库、标签分类、项目目标、机械设计、电气设计、内部设计评审、客户审核、项目任务统计 |
| **研发管理** | 配制BOM清单、机加工清单、采购清单、电气BOM清单、电气图纸 |
| **生产管理** | 生产制令单、计划工时和产能、自动生成、生产调度、生产计划、委外加工单、生产入库、设备验收 |
| **委外管理** | 委外工单、委外入库、委外退货单、形态转换单 |
| **库存管理** | 二维码、其他出库、其他入库、扫码、盘点单、合格/不合格、库存调整单 |
| **采购管理** | 设备调试计划、采购申请单、采购询价、采购订单、采购入库、采购退货 |
| **售后维保管理** | 报价清单、售后服务信息、维修问题清单、保修执行、报修单 |
| **应收管理** | 应收开票、其他收款、预收款、红字开票、销售发票申请、收款发票核销、收款单 |
| **应付管理** | 应付开账、其他付款、预付款、采购发票作废、采购发票收票、行发票核销、付款单 |
| **其他费用管理** | 年度产值计划、各项目成本产值计划、项目目标、各项目工时、费用预算管控 |

### 关键审批流程
- **线索分配**: 销售尽量给 or GM
- **商机方案**: 需要GM审批
- **合同签订**: 需要技术协议确认
- **采购订单**: 需要审批流程
- **生产入库**: 需要质检确认

### 数据流转关系
1. CRM → 项目管理 → 研发管理 → 生产管理
2. 采购管理 ← 生产管理 → 库存管理
3. 应收管理 ← 销售发货 ← 生产管理
4. 应付管理 ← 采购管理

### CRM模块详细流程

#### 1.1 公海池和线索分配
- 线索来源：官网注册信息、展会记录信息、销售自拓、客户推荐
- 分配流程：销售工程师/市场营销工程师 → 公海池 → 销售经理/GM → 分配给事业部销售代表

#### 客户基本信息表（公海池）字段
| 字段名称 | 字段类型 | 申请必填 |
|---------|---------|---------|
| 客户编码 | 流水号 | 系统自动生成（唯一值） |
| 客户名称 | 单行文本 | 必填，不允许重复 |
| 合作状态 | 下拉框 | 潜在、尚未联络、跟进、合作、无效 |
| 客户来源 | 下拉框 | 展会、官网、公司转介绍、销售自拓、公司资源 |
| 客户等级 | 下拉框 | 【等级分类待确认】 |
| 客户规模 | 下拉框 | 大型、中型、小型 |
| 网站地址 | 单行文本 | - |
| 客户地址 | 地址/详细地址栏 | 海外客户地址信息直接填入详细地址栏 |
| 销售负责人 | 成员单选 | 由销售经理按照类型分配给事业部的销售代表 |
| 需求详情 | 富文本 | - |
| 财务信息 | - | - |
| 发票抬头 | 单行文本 | 企业全称（与营业执照一致，不可简称） |
| 发票税号 | 单行文本 | 纳税人识别号（即'税号'，则为营业执照上的统一社会信用代码） |
| 开户电话 | 单行文本 | - |
| 收票邮箱 | 单行文本 | - |
| 开户银行 | 单行文本 | - |
| 银行账户 | 单行文本 | - |
| 增值税税率 % | 数字 | 格式：百分比 |

#### 审批流程（审批职位）
- 线索分配：销售尽量给 or GM
- "销售负责人"字段只有销售经理和GM可以修改

#### 查看权限和划分
1. 查看并管理所有信息：GM，客户与市场经理，销售经理，事业部部长
2. 添加并管理本人数据：销售代表
3. 管理全部数据：GM，GM，客户与市场经理，销售经理

### 1.2 商机方案流程
- 销售代表 → 线索跟进 → 确认客户状态
- 通过电话/微信或Email直接联系 → 确认有明显需求 → 判定（无需求或明确无机会/会影响现有或未来商机）
- 申请线索转换 → 事业部部长 or 客户和市场经理 → 判定
- 销售代表编写技术方案 → 研发人员（历史方案）
- 判定是否为战略客户 OR 是否为新型设备 → 非特定客户或设备方案抄送GM
- GM → 事业部部长 → 审批
- 抄送GM、销售经理、客户和市场经理 → 销售代表 → 将方案发给客户 → 商机继续跟进
