# 简道云年度计划表单数据结构分析

## 表单名称
卓越文化Excellence Model

## 表单位置
应用：（搭建中）人事及OA管理系统
表单ID：694374fe24f67463c5280bbc

## 字段结构

### 基础信息
| 字段名 | 字段类型 | 说明 |
|--------|----------|------|
| 卓越文化小组 | 文本/说明 | 组长、组员信息展示 |
| 活动日/周/月名称 | 单行文本 | 活动名称 |
| 主要信息 | 多行文本 | 活动详细描述 |
| 月份记录 | 子表单 | 按月记录活动 |

### 时间字段
| 字段名 | 字段类型 | 说明 |
|--------|----------|------|
| 开始日期 | 日期 | 活动开始时间 |
| 周数 | 数字 | 活动周数 |
| 最早时间-辅助 | 日期 | 辅助计算字段 |

### 任务字段
| 字段名 | 字段类型 | 说明 |
|--------|----------|------|
| 项目负责人主要工作 | 多行文本/说明 | 固定内容：1.重新命名活动名称 2.产出活动策划方案 3.申请批准 4.做抄送和outlook会议的发送 |
| 负责人 | 成员选择 | 选择负责人员 |
| 是否完成 | 单选 | 是/否 |

## 数据特点

1. **周期性规划**：按活动日/周/月组织
2. **责任分配**：明确负责人和主要工作
3. **进度追踪**：是否完成状态
4. **时间管理**：开始日期和周数

## 系统设计建议

### 年度规划数据模型
```typescript
interface AnnualPlan {
  id: number;
  year: number;                    // 年度
  version: string;                 // 版本号 (如 "2026-v1")
  status: 'draft' | 'active' | 'archived';
  createdAt: Date;
  updatedAt: Date;
}

interface AnnualPlanItem {
  id: number;
  planId: number;                  // 关联年度计划
  category: string;                // 类别（卓越文化、培训、会议等）
  name: string;                    // 活动名称
  description: string;             // 详细描述
  startDate: Date;                 // 开始日期
  endDate: Date;                   // 结束日期
  frequency: 'daily' | 'weekly' | 'monthly' | 'quarterly' | 'yearly' | 'once';
  responsibleUserId: number;       // 负责人
  status: 'pending' | 'in_progress' | 'completed' | 'cancelled';
  tasks: string[];                 // 主要工作任务
}
```

### 年度更新机制
1. **版本控制**：每年创建新版本，保留历史版本
2. **模板复制**：基于上一年度模板创建新年度计划
3. **AI自动更新**：
   - 更新日期字段（年份+1）
   - 更新周数计算
   - 重置完成状态
   - 保留负责人和任务结构

### 更新时机
- **年度更新**：每年12月或1月初
- **触发方式**：手动触发或定时任务
- **更新范围**：全系统年度相关数据
