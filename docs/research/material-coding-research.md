# 物料编码规则研究笔记

## 一、物料编码的意义

物料编码是以简短的文字、符号或数字、号码来代表物料、品名、规格或类别及其它有关事项的一种管理工具。

### 物料编码的功能
1. **增强物料资料的正确性** - 避免一物多名、一名多物的现象
2. **提高物料管理的工作效率** - 以编码代替文字记述
3. **利于电脑的管理** - 便于ERP系统处理
4. **降低物料库存、降低成本** - 利于库存控制和呆料防止
5. **防止物料舞弊事件之发生** - 记录正确，储存有序
6. **便于物料之领用** - 统一名称和规格
7. **便于压缩物料的品种、规格** - 统一、合并和简化

## 二、物料编码的原则

1. **简单性** - 文字符号或数字应力求简单明了
2. **分类展开性** - 大分类后还要细分，细分项目以5-9个为佳
3. **完整性** - 所有物料都应有编码可归
4. **单一性** - 一个编码只能代表一种物料
5. **一贯性** - 编码规则前后一致
6. **伸缩性** - 预留扩展空间
7. **组织性** - 有逻辑的组织结构
8. **适应电脑管理** - 便于系统处理
9. **充足性** - 编码位数足够
10. **易记性** - 易于记忆（次要原则）

## 三、物料编码的方法

### 1. 阿拉伯数字法
- **连续数字编码法** - 流水号，简单但无法体现属性关联
- **分级式数字编码法** - 按大类、中类、小类分级
- **区段数字编码法** - 不同区段代表不同类别
- **国际十进制分类法** - 标准化分类

### 2. 英文字母法
- 用字母代表类别
- 26个字母提供更多分类空间

### 3. 暗示法
- 编码具有暗示意义
- 便于记忆和理解

### 4. 混合法（推荐）
- 结合数字和字母
- 兼具分类性和可读性

## 四、制造业常见编码结构

### 典型结构：大类-小类-流水号
```
XX.XX.XXXX
│  │  └── 流水号（4位）
│  └───── 小类（2位）
└──────── 大类（2位）
```

### 八位编码结构
```
X-XXXXXXX
│ └────── 7位流水码
└──────── 1位大类分类码
```

### 完整编码结构（15位）
```
XX.XX.XX.XXXXXXXXX
│  │  │  └──────── 规格型号（9位）
│  │  └─────────── 品种类型（2位）
│  └────────────── 小类别（2位）
└───────────────── 大类别（2位）
```
