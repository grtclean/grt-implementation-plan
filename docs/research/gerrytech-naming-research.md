## 典型清洗零件

从网站图片可见，杰瑞德清洗设备主要服务于以下零件类型：

1. **动力总成零件**：壳体、齿轮、轴类
2. **发动机零件**：缸体、缸盖、曲轴
3. **传动系统**：变速箱壳体、齿轮
4. **新能源零件**：电机壳体、电池包
5. **精密零件**：喷油器、高压共轨

## 用户提供的命名规则框架

根据用户说明，GRT设备命名采用以下数字代码体系：

| 数字代码 | 设备类型 | 说明 |
|----------|----------|------|
| 200, 201 | 特定机型 | 特定配置、唯一特征 |
| 300, 301 | 特定机型 | 特定配置、唯一特征 |
| 800, 801 | 腔体式 | 8X1表示腔体数量 |
| 811, 821 | 腔体式 | 8a1表示1个腔体 |
| 802, 852 | 腔体式 | 第二位数字表示2个腔体 |
| 5000, 5010 | 通过式 | 通过式清洗线 |

### 数字代码规则分析

根据用户描述，数字代码的结构如下：

```
X X X (X)
│ │ │  └── 可选：细分配置
│ │ └──── 腔体数量/配置等级
│ └────── 系列变体
└──────── 设备大类
```

**大类代码**：
- 2XX = 待定义
- 3XX = 待定义
- 8XX = 腔体式清洗设备
- 5XXX = 通过式清洗设备

**腔体数量编码**（8XX系列）**：
- 8X1 = 1个腔体
- 8X2 = 2个腔体
- 8X3 = 3个腔体
