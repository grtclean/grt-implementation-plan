# Ecoclean设备命名体系研究

## 产品分类体系

Ecoclean将产品分为以下主要类别：
- **Batch Cleaning** - 批量清洗设备
- **Reconditioned Machines** - 翻新设备
- **Precision Cleaning** - 精密清洗设备
- **Surface Processing** - 表面处理设备
- **Deburring & Cleaning** - 去毛刺与清洗设备
- **Single Parts Cleaning** - 单件清洗设备
- **Hydrogen Technology** - 氢能技术设备

## 命名规则分析

### 1. 品牌前缀
- 所有产品都以 **Eco** 作为品牌前缀
- 体现环保、可持续的品牌理念

### 2. 产品类别标识
- **C** = Cleaning（清洗）
- 如：EcoCvario, EcoCstretch, EcoCcore

### 3. 产品特性后缀
- **vario** = 可变/多功能
- **stretch** = 延展/大容量
- **core** = 核心/标准型
- **compact** = 紧凑型
- **cube** = 立方体/箱式

### 4. 规格后缀
- **S** = Small（小型）
- **M** = Medium（中型）
- **L** = Large（大型）

## 命名特点总结

1. **品牌一致性**：统一使用"Eco"前缀
2. **功能描述性**：名称暗示产品特性
3. **简洁易记**：单词组合，朗朗上口
4. **国际化**：使用英文，便于全球推广
5. **系列化**：同系列产品命名风格一致

## 命名规则详细分析

### 品牌体系
1. **Ecoclean品牌线**：以"Eco"开头
   - EcoC系列：EcoCvario, EcoCstretch, EcoCcore, EcoCcompact, EcoCedge, EcoCcube, EcoCbase
   
2. **UCM品牌线**：精密清洗专用
   - UCMSmartLine, UCMWatchLine, UCMIndexLine, UCMCombiLine
   
3. **独立命名**：特殊产品
   - Mega 86W, Minio 85C, PulseBoreCenter

### 命名结构
```
[品牌前缀] + [产品特性] + [规格后缀]

示例：
- EcoC + vario = EcoCvario（可变型清洗机）
- EcoC + base + S = EcoCbase S（基础型小号）
- UCM + Smart + Line = UCMSmartLine（智能生产线）
- Minio + 85C = Minio 85C（迷你型85C规格）
```

### 规格后缀规则
- **S** = Small（小型）
- **M** = Medium（中型）
- **L** = Large（大型）
- **数字+字母** = 具体规格（如85C, 86W）
