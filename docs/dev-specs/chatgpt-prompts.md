## 6. 使用说明

### 6.1 提示词使用流程

1. **选择合适的模板**: 根据任务类型选择对应的提示词模板
2. **填充具体内容**: 将模板中的占位符替换为实际内容
3. **添加上下文**: 如有必要，添加更多项目背景信息
4. **提交并迭代**: 根据ChatGPT的回复进行追问或澄清

### 6.2 最佳实践

- **提供足够上下文**: 包含相关的schema、类型定义等
- **明确期望输出**: 清晰说明需要什么格式的输出
- **分步处理复杂任务**: 将大任务拆分为多个小任务
- **验证输出**: 始终验证ChatGPT生成的代码

### 6.3 与Claude Code协作

当ChatGPT完成代码审查或优化建议后：

1. 将建议整理为任务清单
2. 交由Claude Code实现具体代码变更
3. 运行测试验证变更
4. 如有问题，返回ChatGPT进行进一步分析
