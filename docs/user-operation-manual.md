## 1. 系统概述

GRT智能系统V3.0是一套面向工业清洗设备制造企业的全流程数字化管理平台。系统采用主动式资产管理壳（Active AAS Type 3）架构，集成了零知识证明（ZKP）隐私验证、工业本体语义互操作、数据分级治理和哨兵自愈防御五大核心子系统。

### 1.1 系统入口

系统提供三个主要入口：

| 入口类型 | 访问地址 | 适用用户 |
|---------|---------|---------|
| 公开首页 | `/` | 所有访客 |
| 客户门户 | `/portal` | 已注册客户 |
| 管理后台 | `/dashboard` | 内部员工 |

### 1.2 登录流程

1. 访问系统首页，点击右上角"登录"按钮
2. 系统将跳转至Manus OAuth认证页面
3. 输入账号密码完成认证
4. 认证成功后自动跳转回系统

## 2. 客户门户系统

客户门户为外部客户提供项目进度查询、设备状态监控和技术文档下载等功能。

### 2.1 项目进度查询

**操作步骤：**

1. 登录客户门户后，点击左侧菜单"我的项目"
2. 在项目列表中选择目标项目
3. 查看项目详情页面，包含：
   - 项目基本信息（编号、名称、状态）
   - 里程碑进度（M0-M12阶段）
   - 交付物清单
   - 验收记录

4. 点击"进度时间线"查看详细的阶段门禁状态

### 2.2 设备状态监控

**操作步骤：**

1. 进入"设备监控"页面
2. 选择已交付的设备
3. 查看实时运行数据：
   - 运行状态（运行中/待机/故障）
   - 关键参数（温度、压力、流量）
   - 维护提醒

4. 点击"历史数据"查看趋势图表

### 2.3 技术文档下载

**操作步骤：**

1. 进入"文档中心"
2. 按项目或设备筛选文档
3. 选择需要的文档类型：
   - 操作手册
   - 维护指南
   - 技术规格书
   - 验收报告

4. 点击下载按钮获取文档

## 3. CRM与销售管理

CRM模块管理客户关系、销售线索和商机跟踪。

### 3.1 客户管理

**创建新客户：**

1. 进入"CRM" → "客户管理"
2. 点击"新建客户"按钮
3. 填写客户信息：
   - 基本信息（公司名称、行业、规模）
   - 联系人信息（姓名、职位、电话、邮箱）
   - 地址信息
   - 客户等级（A/B/C/D）

4. 点击"保存"完成创建

**客户360°视图：**

1. 在客户列表中点击客户名称
2. 查看客户全景信息：
   - 基本资料
   - 历史订单
   - 沟通记录
   - 关联项目
   - 服务工单

### 3.2 线索管理

**线索录入：**

1. 进入"CRM" → "线索管理"
2. 点击"新建线索"
3. 填写线索信息：
   - 来源渠道（展会/官网/转介绍/电话）
   - 客户需求描述
   - 预算范围
   - 预计成交时间

4. 系统自动进行BANT评分

**线索转化：**

1. 选择已评估的线索
2. 点击"转为商机"
3. 确认商机信息
4. 分配销售负责人

### 3.3 商机跟踪

**商机阶段管理：**

商机分为以下阶段，每个阶段有对应的操作要求：

| 阶段 | 阶段名称 | 关键动作 |
|-----|---------|---------|
| 1 | 需求确认 | 完成需求调研报告 |
| 2 | 方案设计 | 提交技术方案 |
| 3 | 报价谈判 | 生成正式报价单 |
| 4 | 合同签订 | 上传签署合同 |
| 5 | 订单执行 | 转为项目 |

**推进商机阶段：**

1. 进入商机详情页
2. 完成当前阶段的必要动作
3. 点击"推进到下一阶段"
4. 系统检查阶段门禁条件
5. 条件满足后自动更新阶段

## 4. 项目全生命周期管理

项目管理模块覆盖从立项到验收的完整生命周期。

### 4.1 项目立项

**创建新项目：**

1. 进入"项目管理" → "项目列表"
2. 点击"新建项目"
3. 填写项目信息：
   - 项目编号（自动生成）
   - 项目名称
   - 关联客户
   - 关联商机
   - 项目类型（标准/定制）
   - 计划开始/结束日期

4. 选择项目模板（可选）
5. 点击"提交立项申请"

**立项审批：**

1. 审批人收到立项通知
2. 进入"待办事项"查看申请
3. 审核项目信息
4. 选择"批准"或"退回"

### 4.2 阶段门禁管理

项目按M0-M12阶段执行，每个阶段设有门禁检查点：

| 阶段 | 名称 | 门禁要求 |
|-----|------|---------|
| M0 | 项目启动 | 合同签署、首付款到账 |
| M1 | 需求确认 | 需求规格书签署 |
| M2 | 方案设计 | 技术方案评审通过 |
| M3 | 设计评审 | 设计文档归档 |
| M4 | 采购准备 | BOM确认、供应商选定 |
| M5 | 生产准备 | 物料齐套、产线排程 |
| M6 | 生产执行 | 生产完成、质检通过 |
| M7 | 装配调试 | 调试报告签署 |
| M8 | 厂内验收 | FAT报告签署 |
| M9 | 发货交付 | 发货单确认 |
| M10 | 现场安装 | 安装完成确认 |
| M11 | 现场调试 | SAT报告签署 |
| M12 | 最终验收 | 验收证书签署 |

**推进阶段：**

1. 进入项目详情页
2. 点击"阶段门禁"标签
3. 查看当前阶段的门禁条件
4. 上传必要的交付物
5. 点击"申请门禁评审"
6. 评审通过后自动推进到下一阶段

### 4.3 任务管理

**创建任务：**

1. 在项目详情页点击"任务"标签
2. 点击"新建任务"
3. 填写任务信息：
   - 任务名称
   - 任务描述
   - 负责人
   - 计划开始/结束日期
   - 优先级
   - 关联里程碑

4. 点击"保存"

**任务跟踪：**

1. 在任务列表中查看所有任务
2. 使用看板视图拖拽更新状态
3. 点击任务查看详情和进度
4. 添加工时记录和备注

### 4.4 变更管理

**发起变更请求：**

1. 进入项目详情页
2. 点击"变更管理"标签
3. 点击"新建变更请求"
4. 填写变更信息：
   - 变更类型（范围/进度/成本/技术）
   - 变更原因
   - 变更内容描述
   - 影响分析

5. 提交变更申请

**变更审批流程：**

1. 项目经理初审
2. 技术负责人评估
3. 商务负责人评估（涉及成本时）
4. 客户确认（重大变更）
5. 变更实施

## 5. 人力资源管理

HRM模块管理员工信息、培训、绩效和考勤。

### 5.1 员工管理

**员工入职：**

1. 进入"HRM" → "员工管理"
2. 点击"新员工入职"
3. 填写员工信息：
   - 基本信息（姓名、身份证、联系方式）
   - 岗位信息（部门、职位、汇报对象）
   - 合同信息（入职日期、合同期限）

4. 上传证件照片和合同扫描件
5. 点击"完成入职"

**员工档案查询：**

1. 在员工列表中搜索员工
2. 点击员工姓名查看详情
3. 查看员工全景信息：
   - 基本资料
   - 工作经历
   - 培训记录
   - 绩效记录
   - 考勤记录

### 5.2 培训管理

**创建培训计划：**

1. 进入"HRM" → "培训管理"
2. 点击"新建培训"
3. 填写培训信息：
   - 培训名称
   - 培训类型（入职/技能/安全/管理）
   - 培训讲师
   - 培训时间
   - 培训地点
   - 参训人员

4. 点击"发布培训"

**培训签到：**

1. 培训开始时，讲师进入培训详情页
2. 点击"开始签到"
3. 参训人员扫码或手动签到
4. 培训结束后点击"结束签到"

**培训评估：**

1. 培训结束后，系统自动发送评估问卷
2. 参训人员完成问卷填写
3. 讲师查看评估结果
4. 系统生成培训效果报告

### 5.3 绩效管理

**绩效周期设置：**

系统支持以下绩效周期：
- 3个月试用期评估
- 6个月中期评估
- 年度绩效评估

**发起绩效评估：**

1. 进入"HRM" → "绩效管理"
2. 点击"新建评估"
3. 选择评估类型和周期
4. 选择被评估人员
5. 设置评估截止日期
6. 点击"发起评估"

**完成绩效评估：**

1. 被评估人完成自评
2. 直接上级完成评分
3. HR审核评估结果
4. 系统生成绩效报告
5. 进行绩效面谈

### 5.4 考勤管理

**考勤打卡：**

1. 员工通过移动端或考勤机打卡
2. 系统记录打卡时间和位置
3. 自动计算出勤状态

**请假申请：**

1. 进入"HRM" → "考勤管理" → "请假申请"
2. 点击"新建请假"
3. 选择请假类型（年假/事假/病假/婚假等）
4. 填写请假时间和原因
5. 提交审批

**加班申请：**

1. 进入"加班申请"
2. 填写加班日期、时长和原因
3. 提交审批
4. 审批通过后计入考勤

## 6. 成本管理系统

成本管理模块跟踪项目成本、预算和利润分析。

### 6.1 预算管理

**创建项目预算：**

1. 进入"成本管理" → "预算管理"
2. 选择目标项目
3. 点击"编制预算"
4. 按成本类别填写预算：
   - 材料成本
   - 人工成本
   - 外协成本
   - 差旅成本
   - 其他成本

5. 设置预算预警阈值
6. 提交预算审批

**预算调整：**

1. 选择需要调整的预算
2. 点击"预算调整"
3. 填写调整金额和原因
4. 提交调整审批

### 6.2 成本录入

**录入实际成本：**

1. 进入"成本管理" → "成本录入"
2. 选择项目和成本类别
3. 填写成本信息：
   - 成本项目
   - 金额
   - 发生日期
   - 供应商/人员
   - 关联单据

4. 上传发票或凭证
5. 点击"保存"

### 6.3 成本分析

**查看成本报表：**

1. 进入"成本管理" → "成本分析"
2. 选择分析维度：
   - 按项目
   - 按部门
   - 按成本类别
   - 按时间段

3. 查看分析图表：
   - 成本构成饼图
   - 成本趋势折线图
   - 预算vs实际对比

4. 导出报表

### 6.4 利润分析

**项目利润分析：**

1. 进入"成本管理" → "利润分析"
2. 选择目标项目
3. 查看利润指标：
   - 合同金额
   - 总成本
   - 毛利润
   - 毛利率
   - 净利润

4. 查看利润趋势和预测

## 7. AI智能助手

系统集成六类AI智能助手，提供智能化辅助决策。

### 7.1 方案助手 (Solution Assistant)

**使用场景：** 根据客户需求推荐清洗方案

**操作步骤：**

1. 进入"AI助手" → "方案助手"
2. 输入客户需求：
   - 清洗产品类型
   - 清洁度等级（如ISO 14644-1 Class 5）
   - 节拍要求
   - 上下料方式

3. 点击"生成方案"
4. 查看推荐方案列表
5. 选择方案查看详情
6. 导出方案文档

### 7.2 报价助手 (Quotation Assistant)

**使用场景：** 快速生成项目报价

**操作步骤：**

1. 进入"AI助手" → "报价助手"
2. 选择关联方案或手动输入配置
3. 系统自动计算成本和报价
4. 调整利润率和折扣
5. 生成正式报价单
6. 发送给客户

### 7.3 KPI助手 (KPI Assistant)

**使用场景：** 绩效评估和改进建议

**操作步骤：**

1. 进入"AI助手" → "KPI助手"
2. 选择评估对象（员工/部门/项目）
3. 选择评估周期
4. 查看AI生成的评估报告：
   - 绩效得分
   - 优势分析
   - 改进建议
   - 对比分析

5. 导出评估报告

### 7.4 采购助手 (Purchase Assistant)

**使用场景：** 采购决策支持

**操作步骤：**

1. 进入"AI助手" → "采购助手"
2. 输入采购需求
3. 查看供应商推荐
4. 比较价格和交期
5. 生成采购建议报告

### 7.5 计划助手 (Planning Assistant)

**使用场景：** 工作计划制定和跟踪

**操作步骤：**

1. 进入"AI助手" → "计划助手"
2. 选择计划类型（日/周/月）
3. 系统综合以下输入生成计划：
   - 公司年度计划
   - 项目进度
   - 会议纪要
   - 未完成任务

4. 查看AI生成的计划建议
5. 调整并确认计划
6. 设置提醒

### 7.6 工程助手 (Engineering Assistant)

**使用场景：** 工程全生命周期辅助

**操作步骤：**

1. 进入"AI助手" → "工程助手"
2. 选择项目和当前阶段
3. 查看AI汇总的关键信息：
   - 技术要点
   - 风险提示
   - 待办事项
   - 沟通建议

4. 生成阶段报告
5. 发送给相关人员

## 8. 区块链验证系统

区块链模块提供零知识证明验证和合规性认证。

### 8.1 产能验证

**使用场景：** 在不泄露具体产能数据的情况下证明满足订单需求

**操作步骤：**

1. 进入"区块链" → "产能验证"
2. 选择验证类型
3. 输入需求参数
4. 系统生成ZK证明
5. 提交链上验证
6. 获取验证证书

### 8.2 合规性认证

**VDA191合规性验证：**

1. 进入"区块链" → "合规认证"
2. 选择"VDA191"标准
3. 上传相关证明材料
4. 系统生成合规性证明
5. 提交到Polygon zkEVM测试网
6. 获取链上认证记录

**ISO10218安全合规性验证：**

1. 选择"ISO10218"标准
2. 填写安全参数
3. 生成安全合规证明
4. 提交链上验证

### 8.3 验证记录查询

**操作步骤：**

1. 进入"区块链" → "验证记录"
2. 按条件筛选记录
3. 查看验证详情：
   - 验证时间
   - 验证类型
   - 交易哈希
   - 验证结果

4. 点击交易哈希跳转到区块浏览器

## 9. 系统管理与监控

### 9.1 用户权限管理

**创建用户：**

1. 进入"系统管理" → "用户管理"
2. 点击"新建用户"
3. 填写用户信息
4. 分配角色和权限
5. 点击"保存"

**角色管理：**

1. 进入"角色管理"
2. 创建或编辑角色
3. 配置角色权限：
   - 菜单权限
   - 数据权限
   - 操作权限

4. 保存角色配置

### 9.2 系统监控

**死锁监控仪表板：**

1. 进入"系统管理" → "监控中心"
2. 查看死锁检测状态：
   - 检测周期（5分钟）
   - 最近检测时间
   - 检测到的循环数
   - 自动解决数

3. 查看历史记录
4. 配置告警规则

**服务健康检查：**

1. 查看服务状态面板
2. 监控关键指标：
   - CPU使用率
   - 内存使用率
   - 数据库连接数
   - API响应时间

3. 设置阈值告警

### 9.3 审计日志

**查看操作日志：**

1. 进入"系统管理" → "审计日志"
2. 按条件筛选：
   - 操作时间
   - 操作用户
   - 操作类型
   - 操作模块

3. 查看日志详情
4. 导出日志报表

### 9.4 数据备份

**手动备份：**

1. 进入"系统管理" → "数据备份"
2. 点击"立即备份"
3. 选择备份范围
4. 等待备份完成
5. 下载备份文件

**定时备份设置：**

1. 点击"备份设置"
2. 配置备份策略：
   - 备份频率
   - 保留天数
   - 备份时间

3. 保存设置

## 附录B：常见问题

**Q: 忘记密码怎么办？**
A: 点击登录页面的"忘记密码"，通过邮箱重置密码。

**Q: 如何修改个人信息？**
A: 点击右上角头像，选择"个人设置"进行修改。

**Q: 数据导出格式支持哪些？**
A: 支持Excel(.xlsx)、CSV、PDF格式导出。
