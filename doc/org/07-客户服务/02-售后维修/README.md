# 02-售后维修

## 概述

售后维修部门负责GRT机器人产品的故障维修、保修管理和故障根因分析。管理全球约280台在役设备的维修保障，确保设备可用率≥98%。维修模式包括：现场维修(on-site)、返厂维修(RMA)、远程诊断+指导维修三种。质保期内免费维修，质保外按服务合同或工时+备件计费。

## KPI指标

| KPI | 目标 | 说明 |
|-----|------|------|
| 首次修复率 | ≥80% | 一次上门或远程解决 |
| MTTR(平均修复时间) | ≤8小时 | 从开始维修到恢复运行 |
| 返修率 | ≤5% | 同一故障30天内再次发生 |
| 质保索赔率 | ≤3% | 质保内维修次数/在保设备数 |
