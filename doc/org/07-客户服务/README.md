# 07-客户服务

## 概述

客户服务部门负责GRT机器人产品交付后的全生命周期服务，包括现场安装调试、客户培训、售后维修、质保管理、客户投诉处理及客户门户管理。服务覆盖5大事业部（海外/商用车/乘用车/半导体/工业通用）的全球客户，确保设备运行稳定性和客户满意度。核心服务对象包括：TSMC（半导体晶圆清洗）、BMW/大众/长安/一汽（汽车行业清洗）、以及工业通用客户群。

## KPI指标

| KPI | 目标 | 计算方式 | 数据来源 | 考核周期 |
|-----|------|----------|----------|----------|
| 首次修复率(FTF) | ≥80% | 首次上门即解决/总服务次数×100% | 服务工单系统 | 月度 |
| 服务响应时间 | ≤4小时 | 从客户报修到工程师响应的平均时间 | 工单系统 | 月度 |
| 客户满意度(CSAT) | ≥92% | 满意+非常满意评价/总评价×100% | 客户回访 | 季度 |
| 设备可用率 | ≥98% | (总时间-停机时间)/总时间×100% | IoT远程监控 | 月度 |
| 质保索赔率 | ≤3% | 质保期内维修次数/在保设备数×100% | 质保系统 | 季度 |
| 投诉闭环率 | ≥95% | 30天内闭环投诉数/总投诉数×100% | 投诉管理 | 月度 |
| 备件满足率 | ≥95% | 有库存备件/总备件需求×100% | 备件系统 | 月度 |
| NPS(净推荐值) | ≥50 | (推荐者%-贬低者%) | 年度调研 | 年度 |
