# 01-现场服务

## 概述

现场服务团队负责GRT机器人产品的安装调试、客户培训、定期保养及紧急故障处理。团队由15名现场服务工程师组成（国内12名、海外3名），按事业部分工：半导体BU(4人)、汽车BU(5人)、工业通用(3人)、海外(3人)。工程师具备机械、电气、PLC编程等复合技能，持有客户现场所需的安全认证（半导体洁净室、汽车工厂安全）。
