# 03-客户投诉

## 概述

客户投诉管理负责所有客户不满意事件的受理、分级、处理和闭环跟踪。目标是在规定时限内解决客户问题，恢复客户信任，并从每个投诉中提取改善机会。投诉分为四个等级：A级(重大/批量/安全)须48h内闭环初步方案，B级(影响生产)须7天闭环，C级(一般问题)须15天闭环，D级(建议/咨询)须30天回复。

## KPI指标

| KPI | 目标 | 说明 |
|-----|------|------|
| 投诉闭环率(30天) | ≥95% | 30天内完成闭环 |
| A级投诉48h响应率 | 100% | 重大投诉48h内出初步方案 |
| 投诉重复发生率 | ≤5% | 同类投诉12月内再次发生 |
| 客户满意度恢复率 | ≥85% | 投诉处理后客户评价满意/非常满意 |
