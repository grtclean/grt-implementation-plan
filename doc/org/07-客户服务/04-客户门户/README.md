# 04-客户门户

## 概述

客户门户是GRT向客户提供的在线自助服务平台，客户可通过门户查阅技术文档、提交服务请求、跟踪工单进度、签署NDA及下载授权文档。门户实施分层授权管理(T1-T4)，不同层级客户可访问不同级别的技术资料和服务功能。目前已有38个客户账号开通，覆盖5大事业部的主要客户。

## KPI指标

| KPI | 目标 | 说明 |
|-----|------|------|
| 门户活跃率 | ≥60% | 月度至少登录1次的客户占比 |
| 自助服务解决率 | ≥30% | 通过门户文档自行解决/总服务需求 |
| NDA签署率 | 100% | 所有T2+客户完成NDA签署 |
| 文档下载满意度 | ≥90% | 文档查阅后满意度评价 |
