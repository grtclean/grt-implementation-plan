# TPL-客户授权层级

> **适用范围**: 所有通过客户门户访问GRT技术资料的客户
> **更新频率**: 客户合作关系变更时更新
> **审批流程**: 客户关系经理申请 → 服务总监审核 → (T3/T4)VP批准 → NDA签署后生效

### NDA签署流程

```
1. 客户关系经理在系统中发起NDA邀请
   └── 系统生成NDA文档(对应层级模板)
       └── 发送签署链接至客户联系人邮箱
           └── 客户在线阅读并电子签署
               └── 系统生成SHA-256数字哈希
                   └── NDA生效，自动升级客户权限
```

### 授权升降级规则

| 场景 | 动作 | 审批 |
|------|------|------|
| 签订新合同 | T1→T2 | 服务总监 |
| 签订战略合作协议 | T2→T3 | VP |
| 签订联合开发协议 | T3→T4 | CEO |
| 合同到期未续 | 降一级(宽限期3个月) | 自动 |
| NDA到期未续签 | 降至T1 | 自动 |
| 违反NDA条款 | 立即冻结 | VP |
| 客户要求注销 | 归档后删除 | 客户关系经理 |

## 使用说明

1. **开通流程**：销售签单后 → 客户关系经理创建账号 → 发送激活邮件 → 客户首次登录
2. **NDA管理**：T2+客户必须签署对应级别NDA后才能访问受限文档
3. **水印保护**：所有受限文档查阅/下载均自动添加客户身份水印
4. **访问审计**：客户所有文档查阅/下载记录完整留痕，支持审计查询
5. **到期预警**：授权到期前90天自动通知客户关系经理和客户
6. **系统路由**：管理端`/customer-authorization`，客户端`/customer-portal`
7. **安全要求**：T3/T4级别文档禁止截屏（Web端DRM保护），违规自动告警
