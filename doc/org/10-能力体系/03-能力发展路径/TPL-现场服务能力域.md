# TPL-现场服务能力域

> **适用范围**：现场服务工程师、售后支持工程师、FAT/SAT 工程师
> **更新频率**：每年审查一次
> **审批流程**：客户服务部门主管起草 → HR 审核 → CTO 审批

## 模板

### 能力域概述

| 项目 | 内容 |
|------|------|
| 能力域名称 | 现场服务能力域（Field Service） |
| 覆盖岗位 | 现场服务工程师、售后工程师、FAT/SAT 工程师、驻场工程师 |
| 核心 BU | 海外 BU、商用车 BU（客户现场需求最多） |
| 人员数量 | 约 25 人 |
| 关键挑战 | 跨文化沟通、远程故障诊断、独立作战能力 |

### 子能力矩阵

#### 1. 安装调试（Installation & Commissioning）

| 等级 | 行为描述 | 典型任务 | 发展活动 |
|------|----------|----------|----------|
| L1 | 在师傅指导下完成简单设备安装 | 协助机械安装、接线 | 跟随师傅 3+ 个项目 |
| L2 | 能独立完成标准设备安装调试 | 单工位安装调试、基本参数设置 | 独立完成 5+ 个安装项目 |
| L3 | 能完成复杂产线安装调试 | 多工位联调、节拍优化 | 主导 3+ 个复杂项目 |
| L4 | 能主导大型项目现场管理 | 整线交付、现场团队管理 | 管理 2+ 个大型项目 |
| L5 | 能制定安装调试标准并培训团队 | SOP 制定、FAT/SAT 标准化 | 行业最佳实践输出 |

#### 2. 故障排查（Troubleshooting）

| 等级 | 行为描述 | 典型任务 | 发展活动 |
|------|----------|----------|----------|
| L1 | 能识别常见报警并按手册处理 | 查看报警代码、重启设备 | 学习常见故障手册 |
| L2 | 能系统排查机电故障 | 使用万用表/示波器、PLC 在线监控 | 独立处理 20+ 故障 |
| L3 | 能处理复杂系统性故障 | 多系统交互问题、间歇性故障分析 | 建立故障知识库 |
| L4 | 能远程指导故障诊断 | 远程诊断、制定排查决策树 | 培训 3+ 名 L2 工程师 |
| L5 | 能预测性维护与根因分析 | 设计预防性维护方案、数据驱动诊断 | 发表故障分析方法论 |

#### 3. 客户培训（Customer Training）

| 等级 | 行为描述 | 典型任务 | 发展活动 |
|------|----------|----------|----------|
| L1 | 能按培训手册做基础操作演示 | 设备操作演示、日常维护讲解 | 参加 TTT 基础培训 |
| L2 | 能独立完成客户操作培训 | 编写培训材料、考核客户操作员 | 独立培训 5+ 次 |
| L3 | 能开发定制化培训课程 | 针对不同客户定制培训方案 | 开发 2+ 门课程 |
| L4 | 能建立客户培训体系 | 培训体系设计、效果评估 | 建立培训标准 |
| L5 | 能做行业级技术分享 | 行业技术演讲、白皮书撰写 | 行业影响力输出 |

#### 4. 跨文化沟通（Cross-cultural Communication）

| 等级 | 行为描述 | 典型任务 | 发展活动 |
|------|----------|----------|----------|
| L1 | 能用基础英语进行简单工作沟通 | 日常问候、基本工作指令 | 英语基础课程 |
| L2 | 能用英语进行技术沟通 | 技术问题描述、邮件交流 | 技术英语培训 |
| L3 | 能用英语主持客户会议 | 项目汇报、技术方案讨论 | 商务英语培训 |
| L4 | 能处理跨文化冲突和谈判 | 合同谈判、投诉处理 | 跨文化管理培训 |
| L5 | 能建立全球客户关系网络 | 战略客户管理、区域市场拓展 | 国际商务经验 |

### 典型发展路径

```
L1 现场助理工程师 (0-1年)
    ↓
L2 现场服务工程师 (1-3年)
    ↓
L3 高级现场服务工程师 (3-5年)
    ↓ ─────────────────── ↓
L4 现场服务专家/团队负责人     L4 售后服务经理（管理路径）
    ↓                              ↓
L5 首席现场服务专家            L5 客户服务总监
```

## 使用说明

1. **能力评估对标**：季度评估时，现场服务岗位员工以本模板为对标基准
2. **发展计划**：根据当前等级和目标等级，选择对应的发展活动
3. **跨域发展**：现场服务 L3+ 人员可横向发展至项目交付或客户智能服务域
4. **海外 BU 特殊要求**：L3+ 需具备跨文化沟通 L3 以上能力
5. **系统录入**：能力域定义同步到 `/capability-os` 的 `competencyDomains` 配置
