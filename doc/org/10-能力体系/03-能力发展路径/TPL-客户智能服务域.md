# TPL-客户智能服务域

> **适用范围**：销售工程师、方案工程师、客户经理、售前顾问
> **更新频率**：每年审查一次
> **审批流程**：销售部门主管起草 → HR 审核 → 销售 VP 审批

## 模板

### 能力域概述

| 项目 | 内容 |
|------|------|
| 能力域名称 | 客户智能服务域（Customer Intelligence） |
| 覆盖岗位 | 销售工程师、方案工程师、客户经理、售前顾问、BU 销售总监 |
| 核心 BU | 全 BU 通用（海外 BU 增加跨文化要求） |
| 人员数量 | 约 20 人 |
| 关键挑战 | 技术方案与商业价值结合、长周期大客户管理、竞争差异化 |

### 子能力矩阵

#### 1. 客户关系管理（CRM）

| 等级 | 行为描述 | 典型任务 | 发展活动 |
|------|----------|----------|----------|
| L1 | 能维护客户基本信息 | 客户录入、拜访记录 | 学习 CRM 系统操作 |
| L2 | 能独立管理客户关系 | 定期拜访、需求跟进、报价响应 | 管理 10+ 客户 |
| L3 | 能挖掘客户深层需求 | 需求分析、痛点挖掘、增销策略 | 完成 5+ 大项目 |
| L4 | 能建立战略客户合作 | 年度合作规划、高层关系建设 | 管理 3+ 战略客户 |
| L5 | 能建立客户生态体系 | 行业生态联盟、客户成功体系 | 行业客户网络 |

#### 2. 方案设计（Solution Design）

| 等级 | 行为描述 | 典型任务 | 发展活动 |
|------|----------|----------|----------|
| L1 | 能整理客户需求文档 | 需求清单、竞品信息收集 | 学习产品知识 |
| L2 | 能编制标准方案书 | 技术方案书、配置清单、报价 | 独立编制 5+ 方案 |
| L3 | 能设计创新解决方案 | 定制化方案、ROI 分析、差异化竞争 | 赢得 3+ 竞标 |
| L4 | 能主导复杂系统方案 | 整线方案、集成方案、价值主张 | 千万级项目方案 |
| L5 | 能引领行业解决方案方向 | 行业白皮书、标杆方案、技术路线 | 行业方案权威 |

#### 3. 客户管理（Account Management）

| 等级 | 行为描述 | 典型任务 | 发展活动 |
|------|----------|----------|----------|
| L1 | 能响应客户日常询问 | 产品咨询、价格查询 | 学习产品线知识 |
| L2 | 能独立管理客户生命周期 | 从商机到回款的全流程管理 | 全流程管理 5+ 项目 |
| L3 | 能制定客户发展策略 | 客户分级、渗透策略、续约策略 | 客户营收增长 20%+ |
| L4 | 能管理区域/行业客户组合 | 区域销售策略、市场分析 | 管理亿级区域 |
| L5 | 能制定全球客户战略 | 全球化策略、品牌建设 | 全球客户运营 |

#### 4. 商务谈判（Business Negotiation）

| 等级 | 行为描述 | 典型任务 | 发展活动 |
|------|----------|----------|----------|
| L1 | 能传达标准报价 | 标准产品报价、条款说明 | 学习商务礼仪 |
| L2 | 能独立完成常规谈判 | 价格谈判、付款条件协商 | 独立谈判 10+ 次 |
| L3 | 能处理复杂商务谈判 | 多轮谈判、合同条款博弈 | 完成 3+ 大额谈判 |
| L4 | 能制定谈判策略和底线 | 竞争分析、策略制定、团队谈判 | 千万级项目谈判 |
| L5 | 能主导战略合作谈判 | 战略合作协议、行业联盟 | 亿级战略合作 |

### 典型发展路径

```
L1 销售助理 (0-1年)
    ↓
L2 销售工程师 (1-3年)
    ↓
L3 高级销售工程师/方案专家 (3-5年)
    ↓ ─────────────────── ↓
L4 大客户经理/方案总监       L4 BU 销售经理（管理路径）
    ↓                           ↓
L5 首席方案架构师           L5 销售 VP
```

## 使用说明

1. **与销售目标挂钩**：能力等级评估需结合销售业绩数据（签单额、回款率）
2. **技术理解要求**：方案设计 L3+ 需具备机械/电气基础知识（至少 L2）
3. **海外 BU 特殊要求**：需具备跨文化沟通 L3+，英语商务写作 L3+
4. **系统对接**：客户数据从 `/crm`、`/lead-analytics` 获取，方案数据从 `/solution-engine` 获取
