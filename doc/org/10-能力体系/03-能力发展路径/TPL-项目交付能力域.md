# TPL-项目交付能力域

> **适用范围**：项目经理、项目工程师、项目协调员
> **更新频率**：每年审查一次
> **审批流程**：项目管理部主管起草 → HR 审核 → CTO 审批

## 模板

### 能力域概述

| 项目 | 内容 |
|------|------|
| 能力域名称 | 项目交付能力域（Project Delivery） |
| 覆盖岗位 | 项目经理、项目工程师、项目协调员、BU 项目总监 |
| 核心 BU | 全 BU 通用 |
| 人员数量 | 约 20 人（含兼职项目角色） |
| 关键挑战 | 多项目并行管理、跨部门协调、客户期望管理 |

### 子能力矩阵

#### 1. 项目规划（Project Planning）

| 等级 | 行为描述 | 典型任务 | 发展活动 |
|------|----------|----------|----------|
| L1 | 能编制简单任务计划 | WBS 分解协助、甘特图录入 | 学习项目管理基础 |
| L2 | 能独立编制项目计划 | 完整 WBS、里程碑计划、资源分配 | 独立编制 3+ 个项目计划 |
| L3 | 能编制复杂项目计划含关键路径分析 | CPM 分析、资源平衡、多方案对比 | 主导 5+ 个项目规划 |
| L4 | 能管理项目组合计划与资源冲突 | 多项目优先级排序、共享资源调度 | 管理 10+ 个并行项目 |
| L5 | 能建立项目规划方法论和工具体系 | PMO 体系建设、AI 辅助规划 | 行业级 PMO 实践 |

#### 2. 执行管理（Execution Management）

| 等级 | 行为描述 | 典型任务 | 发展活动 |
|------|----------|----------|----------|
| L1 | 能跟踪任务状态并汇报 | 日报/周报编写、进度更新 | 学习任务管理工具 |
| L2 | 能独立推动项目执行 | 会议组织、问题跟踪、进度管控 | 独立管理简单项目 |
| L3 | 能处理项目变更和偏差 | 变更管理、偏差分析、纠偏措施 | 处理 3+ 次重大变更 |
| L4 | 能建立项目执行标准和工具 | 模板化管理、自动化报告、EVM | 建立执行标准体系 |
| L5 | 能在行业层面分享执行最佳实践 | 方法论发表、行业案例 | 行业最佳实践输出 |

#### 3. 风险管理（Risk Management）

| 等级 | 行为描述 | 典型任务 | 发展活动 |
|------|----------|----------|----------|
| L1 | 能识别并报告常见风险 | 风险登记、定期检查 | 学习风险管理基础 |
| L2 | 能评估风险概率和影响 | 风险矩阵填写、应对措施制定 | 参与 5+ 次风险评审 |
| L3 | 能建立项目风险管理计划 | 全面风险识别、定量分析、应急预案 | 主导风险管理 |
| L4 | 能管理组织级风险 | 企业风险框架、供应链风险对冲 | 组织级风险管理 |
| L5 | 能建立风险管理文化和体系 | 风险驱动决策、预测性风险分析 | 行业级风险管理 |

#### 4. 干系人管理（Stakeholder Management）

| 等级 | 行为描述 | 典型任务 | 发展活动 |
|------|----------|----------|----------|
| L1 | 能识别关键干系人 | 干系人登记、基本沟通 | 学习沟通技巧 |
| L2 | 能管理常规干系人期望 | 定期汇报、需求确认 | 管理 5+ 个干系人 |
| L3 | 能处理干系人冲突 | 期望管理、冲突调解、变更协商 | 处理 3+ 次冲突 |
| L4 | 能建立战略客户关系 | C-level 汇报、长期合作策略 | 管理 3+ 个战略客户 |
| L5 | 能建立行业合作网络 | 行业联盟、标准组织参与 | 建立行业网络 |

### 典型发展路径

```
L1 项目助理 (0-1年)
    ↓
L2 项目工程师 (1-3年)
    ↓
L3 项目经理 (3-5年)
    ↓ ─────────────────── ↓
L4 高级项目经理/PMO          L4 BU项目总监（管理路径）
    ↓                           ↓
L5 首席项目管理专家          L5 VP 项目管理
```

| M12 交付 SAT | 风险管理 | L3+ | 现场风险应对 |

## 使用说明

1. **与 M0-M12 对齐**：项目交付能力评估应结合具体项目阶段表现
2. **认证关联**：L3+ 建议考取 PMP 认证，L4+ 建议 PgMP 认证
3. **跨域协作**：项目经理需理解现场服务域和制造调试域的基本能力要求
4. **系统对接**：项目绩效数据从 `/pos` 和 `/project` 模块获取，能力评估录入 `/capability-os`
