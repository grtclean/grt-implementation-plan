# TPL-知识地图

> **适用范围**：全公司知识域与专家映射
> **更新频率**：每半年更新一次
> **审批流程**：知识管理员编制 → 各领域专家确认 → CTO 审批

## 模板

### 知识地图结构

```
知识域（Domain）
├── 子域（Sub-domain）
│   ├── 知识领域（Knowledge Area）
│   │   ├── 领域专家（Expert）
│   │   ├── 参考文档（Reference Documents）
│   │   └── 系统模块（System Module）
```

## 使用说明

1. **知识地图用途**：新人入职查找学习资源、项目组建时找领域专家、培训规划参考
2. **专家标注**：L4+ 专家由技术委员会认定，标注在知识地图中
3. **文档关联**：每个知识领域需关联核心参考文档（存储在 `/knowledge-base`）
4. **系统搜索**：知识地图数据同步到 Copilot，支持"谁是XX领域专家"类查询
5. **更新机制**：每半年由知识管理员协调各领域专家更新，人员变动时即时更新
6. **知识空白**：知识成熟度为"初始"且专家 < 2 人的领域视为知识空白，纳入年度培训规划
