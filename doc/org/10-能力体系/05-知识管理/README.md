# 05-知识管理

## 概述

知识管理模块负责组织知识资产的系统化管理，包括最佳实践沉淀、经验教训总结、知识地图构建，形成 GRT 的"组织记忆"。通过知识管理，避免重复犯错，加速新人融入，持续提升组织能力。

### 知识管理原则

1. **知识是资产**：项目经验、技术方案、客户洞察都是公司核心资产
2. **分享是义务**：知识贡献纳入绩效考核，鼓励开放分享
3. **质量第一**：知识入库需经专家审核，确保准确性和适用性
4. **AI 赋能**：利用 AI 辅助知识提取、分类、检索和推荐

### 系统对接

- 知识库：`/knowledge-base` 模块
- AI 检索：`/help`（Copilot RAG 检索）
- 文档智能：`/doc-intelligence`（自动提取与分类）
- 推荐引擎：`/skill-recommendation`（基于能力差距推荐知识）
