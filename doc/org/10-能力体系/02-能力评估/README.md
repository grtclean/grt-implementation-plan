# 02-能力评估

## 概述

能力评估模块负责定期评估员工的能力等级，识别能力差距，为培训发展和人才配置提供数据支撑。采用"自评 + 主管评 + 同行评 + 实绩验证"四维评估方法，确保评估结果客观公正。

### 评估周期

- **季度评估**：每季度末进行，覆盖全员，3 个工作日内完成
- **年度盘点**：每年 12 月进行全面能力盘点，结合年度绩效
- **项目后评估**：重大项目结束后 2 周内，对项目成员进行能力复评

### 与系统对接

- 评估数据录入 `/capability-os` 模块
- 评估结果自动生成能力雷达图
- 差距数据驱动培训推荐（`/skill-recommendation`）
