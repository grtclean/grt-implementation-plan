# 04-认证管理

## 概述

认证管理模块负责内部技能认证和外部资质证书的全生命周期管理，包括认证申请、考核、颁发、续期和过期提醒。确保员工持有岗位必需的认证资质，满足行业法规和客户审核要求。

### 认证分类

| 类别 | 说明 | 数量 | 管理方 |
|------|------|------|--------|
| 内部技能认证 | 公司内部考核的技能资质 | 10+ 项 | HR + 技术委员会 |
| 外部资质证书 | 行业/国家颁发的资质 | 15+ 项 | HR + 持证人 |
| 客户指定认证 | 客户要求的特殊认证 | 按项目 | 项目经理 + HR |

### 系统对接

- 认证台账数据存储在 `/certification` 模块
- 到期提醒通过 `/scheduler` 自动扫描和通知
- 认证数据同步到 `/capability-os` 影响能力评估
