# 10-能力体系

## 概述

能力体系是 GRT 人才发展与组织能力建设的核心框架。涵盖能力定义、评估、发展路径、认证管理和知识管理五大模块，确保 130+ 员工在机器人与自动化领域的核心竞争力持续提升。

基于 L1-L5 五级能力模型，结合 5 大 BU（海外/商用车/乘用车/半导体/工业通用）的差异化需求，建立覆盖技术、管理、通用三大能力类别的完整能力画像体系。

## 负责人

| 角色 | 姓名 | 职责 |
|------|------|------|
| 体系 Owner | CTO | 能力框架设计与战略对齐 |
| 执行负责人 | HR 总监 | 评估实施与发展计划跟踪 |
| 技术能力委员会 | 各 BU 技术负责人 | 专业能力标准制定与评审 |
| 认证管理员 | HR 专员 | 认证台账维护与到期提醒 |
| 知识管理员 | 项目管理部 | 最佳实践与经验教训收集 |

## KPI 指标

| 指标 | 目标值 | 计算方式 | 数据来源 | 频率 |
|------|--------|----------|----------|------|
| 关键岗位能力达标率 | ≥80% | 达标人数 / 关键岗位总人数 | capability-os | 季度 |
| 认证持有率 | ≥90% | 持有有效认证人数 / 应持有人数 | certification | 月度 |
| 能力评估完成率 | ≥95% | 已完成评估人数 / 应评估人数 | capability-os | 季度 |
| 培训覆盖率 | ≥95% | 已参训人数 / 全员人数 | training-assessment | 年度 |
| 知识贡献率 | ≥60% | 有知识贡献的员工 / 全员 | knowledge-base | 季度 |
| 能力差距关闭率 | ≥70% | 已关闭差距数 / 识别差距总数 | capability-os | 半年度 |
| 高级/专家占比 | ≥25% | L4+L5 人数 / 技术人员总数 | capability-os | 年度 |
