# 01-能力定义

## 概述

能力定义模块是能力体系的基础，负责建立 GRT 全公司统一的能力分类体系、等级标准和岗位能力画像。通过标准化的能力词典，确保招聘、培训、评估、晋升等环节使用一致的能力语言。

### 核心输出

- **能力目录**：3 大类别 × 15+ 能力项，覆盖技术/管理/通用维度
- **等级标准**：L1-L5 五级框架，每级含行为指标描述
- **岗位画像**：关键岗位 × 所需能力 × 目标等级，指导人才发展

### 更新周期

- 能力目录：每年审查一次，由技术能力委员会审批
- 等级标准：每年审查一次
- 岗位画像：岗位职责变更时更新
