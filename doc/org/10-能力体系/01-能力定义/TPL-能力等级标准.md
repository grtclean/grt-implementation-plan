# TPL-能力等级标准

> **适用范围**：全公司所有能力评估场景
> **更新频率**：每年审查一次
> **审批流程**：HR 起草 → 技术委员会评审 → CTO 审批

## 模板

### L1-L5 五级能力框架

| 等级 | 名称 | 英文 | 总体定义 | 独立性 | 复杂度 | 影响范围 | 典型工作年限参考 |
|------|------|------|----------|--------|--------|----------|------------------|
| L1 | 新手 | Novice | 在指导下完成基础工作 | 需要持续指导 | 简单/标准化任务 | 个人工作 | 0-1 年 |
| L2 | 初级 | Junior | 能独立完成常规工作 | 大部分独立 | 常规任务 | 个人/小组 | 1-3 年 |
| L3 | 中级 | Intermediate | 能处理复杂任务并有一定创新 | 完全独立 | 复杂/非标任务 | 部门 | 3-5 年 |
| L4 | 高级 | Senior | 能指导他人并推动体系建设 | 独立并指导他人 | 跨领域复杂问题 | 跨部门/公司 | 5-10 年 |
| L5 | 专家 | Expert | 行业级思想领袖 | 引领方向 | 前沿/创新领域 | 行业 | 10+ 年 |

### 各等级行为指标详解

#### L1 新手（Novice）

| 维度 | 行为指标 |
|------|----------|
| 知识 | 掌握岗位基础理论知识，了解常用工具和方法 |
| 技能 | 能在指导下完成标准化操作，按照 SOP 执行 |
| 问题解决 | 能识别明显问题，在指导下寻找解决方案 |
| 协作 | 能清晰表达自己的工作状态，按时完成分配任务 |
| 学习 | 积极参与培训，主动记录学习笔记 |
| 产出质量 | 产出需要上级审核后才能交付 |

#### L2 初级（Junior）

| 维度 | 行为指标 |
|------|----------|
| 知识 | 系统掌握岗位所需专业知识，了解上下游工作流程 |
| 技能 | 能独立完成常规工作任务，质量可控 |
| 问题解决 | 能分析问题原因，提出解决方案并执行 |
| 协作 | 能有效配合团队成员，主动同步工作进展 |
| 学习 | 能主动学习新工具、新方法并应用到工作中 |
| 产出质量 | 常规产出可直接交付，复杂产出需上级审核 |

#### L3 中级（Intermediate）

| 维度 | 行为指标 |
|------|----------|
| 知识 | 深入掌握专业领域知识，了解行业最佳实践 |
| 技能 | 能处理复杂/非标准任务，有一定创新能力 |
| 问题解决 | 能用结构化方法（5Why, FMEA 等）分析复杂问题 |
| 协作 | 能跨部门协调资源，推动项目目标达成 |
| 学习 | 能跨领域学习并整合知识，形成方法论 |
| 产出质量 | 能独立交付高质量成果，并能审核他人产出 |
| 带教 | 能带教 1-2 名新人，传授经验和方法 |

#### L4 高级（Senior）

| 维度 | 行为指标 |
|------|----------|
| 知识 | 在专业领域达到公司级权威，掌握前沿技术动态 |
| 技能 | 能主导复杂项目/系统的设计与实施 |
| 问题解决 | 能解决跨领域的系统性问题，建立预防机制 |
| 协作 | 能领导跨部门团队，建设高效协作文化 |
| 学习 | 能建立团队学习机制，推动知识体系建设 |
| 产出质量 | 产出具有标杆价值，可作为公司级标准 |
| 体系建设 | 能建立和优化专业领域的规范、流程和工具 |
| 人才培养 | 能培养 L2-L3 级人才，建立培养梯队 |

#### L5 专家（Expert）

| 维度 | 行为指标 |
|------|----------|
| 知识 | 行业级思想领袖，引领技术方向 |
| 技能 | 能解决行业前沿问题，开创新方法论 |
| 问题解决 | 能预见行业趋势并提前布局 |
| 协作 | 能建立行业合作网络，推动产业协作 |
| 学习 | 持续引领创新，推动行业知识进步 |
| 产出质量 | 产出具有行业影响力（论文、专利、标准制定） |
| 影响力 | 受邀参与行业会议演讲、标准制定、专家评审 |
| 人才培养 | 能培养 L4 级专家，建立专家社区 |

### 能力等级评定标准

| 评定项 | 权重 | 说明 |
|--------|------|------|
| 自评 | 20% | 员工自我评价 |
| 主管评价 | 40% | 直接主管基于日常观察评价 |
| 同行评议 | 20% | 2-3 名同行/协作者评价 |
| 实绩验证 | 20% | 基于实际项目成果和产出验证 |

### 等级晋升条件

| 晋升路径 | 最低时间要求 | 核心条件 |
|----------|-------------|----------|
| L1 → L2 | 6 个月 | 独立完成 3+ 常规任务，通过 L2 评估 |
| L2 → L3 | 12 个月 | 完成 2+ 复杂项目，带教 1 名新人 |
| L3 → L4 | 18 个月 | 主导 1+ 跨部门项目，建立 1+ 流程规范 |
| L4 → L5 | 24 个月 | 行业发表/专利 2+，公司级技术方案 3+ |

## 使用说明

1. **评估周期**：每季度进行一次能力等级评估，结果录入 `/capability-os` 系统
2. **评估流程**：自评 → 主管评价 → 同行评议（可选）→ 实绩验证 → 综合定级
3. **等级复核**：当评估结果与上次差异超过 1 级时，需技术委员会复核
4. **数据对接**：评估结果自动同步到 `competencyAssessments` 表，驱动能力雷达图生成
5. **与晋升挂钩**：岗位晋升的前提条件之一是相关能力达到目标等级
