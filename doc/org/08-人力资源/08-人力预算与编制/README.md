# 人力预算与编制

## 概述

统筹GRT全公司的年度人力编制规划、人力成本预算及人员流动分析，基于业务战略和各事业部发展需求，合理配置人力资源。2026年度编制目标为145人（现有130人，净增15人）。

## 负责人

- **Owner**: HR总监
- **协同**: 财务部（成本预算）、各事业部总经理（编制需求）
- **审批**: HR总监 → CFO → CEO

## 对应系统模块

- `/hr` — 人力资源管理
- `/hr-sandbox` — HR沙盘推演
- `/analytics` — 数据分析
- `/expense-forecast` — 费用预测

## 编制管理原则

1. **战略导向**: 编制跟随业务战略，优先保障核心岗位
2. **效能优先**: 人效比（人均产值）逐年提升≥5%
3. **弹性配置**: 核心岗位正式编制 + 辅助岗位灵活用工
4. **预算约束**: 人力成本不超过营收的18%
