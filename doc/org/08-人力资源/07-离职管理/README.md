# 离职管理

## 概述

规范GRT员工离职全流程管理，包括离职面谈、工作交接、系统权限注销、最终薪资结算及离职后分析，确保知识资产有效传承，控制年度离职率≤8%。

## 负责人

- **Owner**: 员工关系经理
- **协同**: IT部（系统权限注销）、财务部（最终薪资）、用人部门（交接验收）
- **审批**: 部门主管 → HR总监（关键岗位需CEO审批）

## 对应系统模块

- `/offboarding` — 离职管理
- `/hr-lifecycle` — 员工全生命周期
- `/employee` — 员工档案

## 离职流程

```
离职申请 → 审批(部门主管→HR) → 离职面谈 → 工作交接(5-15个工作日)
→ IT权限注销 → 设备归还 → 最终薪资核算 → 离职证明 → 档案归档
```

## 离职类型

| 类型 | 提前通知 | 审批层级 |
|------|----------|----------|
| 主动辞职 | 30天 | 部门主管→HR总监 |
| 合同到期不续签 | 30天 | HR总监 |
| 协商解除 | 按协议 | HR总监→CEO |
| 辞退（绩效不达标） | 30天/N+1 | HR总监→CEO |
| 开除（严重违规） | 即时 | HR总监→CEO→法务 |
