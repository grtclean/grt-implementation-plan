# 绩效改进计划 (PIP)

> **适用范围**: 绩效评级为C或D的员工，启动绩效改进
> **更新频率**: 按需启动，30/60/90天跟踪
> **审批流程**: 直属上级发起 → HRBP审核 → HR总监批准 → 法务知会

## 使用说明

1. PIP由直属上级发起，须附绩效考核记录作为依据
2. PIP启动前须与员工进行正式面谈，告知PIP内容、周期和后果
3. PIP周期一般为90天（可根据情况调整为60天或120天）
4. 每个阶段结束时须进行正式检查，记录实际表现
5. PIP全程HRBP参与，确保流程合规
6. 未通过PIP的处置方案须经HR总监批准，涉及解除合同的须法务审核
7. 所有PIP记录归档至员工档案，保留期限3年
