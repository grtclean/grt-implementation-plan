# 绩效管理

## 概述

实施GRT全公司的绩效管理体系，采用"KPI（60%）+ 能力（25%）+ 态度（15%）"三维评估模型，结合OKR目标管理和360度反馈，实现绩效与薪酬、晋升、培训的有机联动。半年度评估一次，年度综合评定。

## 负责人

- **Owner**: 薪酬绩效经理
- **协同**: 各部门主管、HRBP
- **审批**: HR总监（PIP需CEO知会）

## 对应系统模块

- `/performance` — 绩效管理
- `/perf-salary` — 薪酬绩效一体化
- `/okr` — OKR目标管理
- `/performance-record` — 绩效记录

## 评估周期

```
Q1: OKR设定 (1月) → 季度回顾 (3月)
H1: 半年度绩效评估 (6月) → 绩效面谈 (7月)
Q3: OKR调整 (7月) → 季度回顾 (9月)
H2: 年度绩效评估 (12月) → 绩效面谈+年终奖 (1月)
```

## 评级体系

| 等级 | 含义 | 比例控制 | 奖金系数 |
|------|------|----------|----------|
| S | 卓越 | ≤5% | 2.0 |
| A | 优秀 | 15-20% | 1.5 |
| B | 良好 | 50-60% | 1.0 |
| C | 待改进 | 15-20% | 0.5 |
| D | 不达标 | ≤5% | 0 |
