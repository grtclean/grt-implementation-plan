# 人力资源

## 概述

人力资源部门负责GRT全公司130+员工的招聘、培训、绩效、薪酬、考勤、离职等全生命周期管理，建设高素质人才队伍，支撑五大事业部（海外/商用车/乘用车/半导体/工业通用）的业务发展需要。

## 负责人

- **Owner**: HR总监
- **System Role**: hr_director / hr_manager
- **汇报线**: HR总监 → CEO

## 对应系统模块

- `/hr` — 人力资源综合管理
- `/employee` — 员工档案管理
- `/training` — 培训与发展
- `/performance` — 绩效管理
- `/perf-salary` — 薪酬绩效一体化
- `/okr` — OKR目标管理
- `/offboarding` — 离职管理
- `/hr-lifecycle` — 员工全生命周期
- `/competency` — 能力素质模型
- `/skill-recommendation` — 技能推荐

## KPI指标

| 指标 | 目标值 | 频率 |
|------|--------|------|
| 员工离职率 | ≤8% | 年度 |
| 关键人才离职率 | ≤3% | 年度 |
| 培训覆盖率 | ≥95% | 年度 |
| 人均培训时长 | ≥40小时 | 年度 |
| 人效比（人均产值）提升 | ≥5% | 年度 |
| 招聘平均周期 | ≤30个工作日 | 月度 |
| 试用期通过率 | ≥90% | 季度 |
| 员工满意度 | ≥85分 | 半年度 |
| 人力成本占营收比 | ≤18% | 月度 |
| 关键岗位继任覆盖率 | ≥80% | 年度 |

## 组织架构

```
HR总监
├── 招聘与人才发展部 (招聘/培训/能力建设)
├── 薪酬绩效部 (薪资核算/绩效管理/福利)
├── 员工关系部 (劳动关系/考勤/离职/企业文化)
└── HRBP团队 (各事业部驻点)
```
