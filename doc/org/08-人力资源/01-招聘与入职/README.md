# 招聘与入职

## 概述

负责GRT全公司的人才招聘、面试评估、录用审批及新员工入职引导全流程，确保各事业部和职能部门及时获得合格人才，支撑年度人力编制计划的达成。

## 负责人

- **Owner**: 招聘经理
- **协同**: 各部门HRBP、用人部门主管
- **审批**: HR总监（关键岗位需CEO审批）

## 对应系统模块

- `/hr` — 人力资源管理
- `/hr-lifecycle` — 员工全生命周期
- `/employee` — 员工档案

## 核心流程

```
需求提报 → 发布职位 → 简历筛选 → 面试安排(1-3轮)
→ 面试评估 → 录用审批 → Offer发放 → 入职办理 → 试用期跟踪 → 转正
```
