# 员工档案

## 概述

集中管理GRT全公司130+员工的人事档案信息，包括基本信息、岗位变动历史、劳动合同状态等，确保信息完整、准确、及时更新，为人事决策提供数据支撑。

## 负责人

- **Owner**: 员工关系经理
- **协同**: 各部门HRBP
- **系统管理**: HR信息化专员

## 对应系统模块

- `/employee` — 员工档案管理
- `/employee-profile` — 员工画像
- `/hr-lifecycle` — 员工全生命周期

## 核心数据

- 员工基本信息（姓名、工号、部门、职位、联系方式）
- 学历与资质证书
- 岗位变动记录（调岗/晋升/降级）
- 劳动合同与续签管理
- 紧急联系人信息

## 文件清单

| 文件名 | 用途 | 更新频率 |
|--------|------|----------|
| TPL-员工花名册.md | 全员在册信息总表 | 月度 |

| TPL-劳动合同台账.md | 合同期限与续签跟踪 | 月度 |
