### 四、续签管理流程

```
合同到期前90天 → HR系统自动预警
→ HRBP评估续签建议（绩效/出勤/能力）
→ 到期前60天 → 部门主管面谈
→ 到期前30天 → HR总监审批续签/不续签
→ 到期前15天 → 签署新合同 / 发送不续签通知
```

### 五、续签决策标准

| 条件 | 续签建议 |
|------|----------|
| 连续2期绩效B级以上 + 无重大违规 | 续签（同期限或升级） |
| 已签2次固定期限合同 | 依法转无固定期限 |
| 最近1期绩效C级 | 续签1年（观察期） |
| 最近1期绩效D级或重大违规 | 不续签，提前30天通知 |
| 连续工作满10年 | 依法应签无固定期限 |

## 使用说明

1. HR专员每月更新合同台账，确保与实际签约一致
2. 系统在合同到期前90/60/30天自动发送预警邮件
3. HRBP须在到期前60天提交续签建议
4. 不续签的须经法务审核通知函措辞，避免劳动争议
5. 无固定期限合同转签后更新台账状态
6. 合同原件由HR归档，电子扫描件上传`/employee`系统
