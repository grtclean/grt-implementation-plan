# 薪酬福利

## 概述

管理GRT全公司的薪酬体系设计、薪资核算、福利管理及年终奖方案，建立G1-G10职级薪酬带宽体系，确保内部公平性与外部竞争力，吸引和保留核心人才。年度人工总成本约7,500万元。

## 负责人

- **Owner**: 薪酬绩效经理
- **协同**: 财务部（薪资发放）、各部门主管（调薪建议）
- **审批**: HR总监 → CEO（批量调薪）

## 对应系统模块

- `/perf-salary` — 薪酬绩效一体化
- `/expense-report` — 费用报销
- `/hr` — 人力资源管理

## 薪酬结构

```
总薪酬 = 基本工资 + 岗位津贴 + 绩效奖金 + 年终奖 + 福利
├── 基本工资 (60-70%): 按职级G1-G10确定
├── 岗位津贴 (10-15%): 技术津贴/管理津贴/特殊岗位
├── 绩效奖金 (10-20%): 与绩效等级挂钩
├── 年终奖 (0-2个月): 公司×BU×个人系数
└── 福利 (社保/公积金/补充商保/餐补/交通)
```
