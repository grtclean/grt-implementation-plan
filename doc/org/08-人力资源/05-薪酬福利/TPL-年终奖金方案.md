# 年终奖金方案

> **适用范围**: 全公司在职员工（试用期内按比例折算）
> **更新频率**: 年度制定（每年12月确定方案，次年1月发放）
> **审批流程**: 薪酬绩效经理 → HR总监 → CFO → CEO → 董事会备案

## 模板

### 一、2025年度年终奖方案（2026年1月发放）

#### 基本公式

```
个人年终奖 = 基本工资 × 公司系数 × BU系数 × 个人系数 × 在职月数/12
```

### 二、公司经营系数

| 公司目标达成率 | 公司系数 | 2025年实际 |
|---------------|----------|-----------|
| ≥120% | 2.0 | — |
| 110-119% | 1.5 | — |
| 100-109% | 1.2 | ☑ (103%) |
| 90-99% | 1.0 | — |
| 80-89% | 0.8 | — |
| ＜80% | 0.5 | — |

> **2025年公司系数: 1.2** (营收目标7.5亿，实际7.73亿，达成率103%)

### 三、BU经营系数

| 事业部 | 营收目标(亿) | 实际营收(亿) | 达成率 | BU系数 |
|--------|------------|------------|--------|--------|
| 海外 | 1.80 | 2.05 | 114% | 1.5 |
| 商用车 | 2.00 | 1.92 | 96% | 1.0 |
| 乘用车 | 1.50 | 1.55 | 103% | 1.2 |
| 半导体 | 1.20 | 1.35 | 113% | 1.5 |
| 工业通用 | 1.00 | 0.86 | 86% | 0.8 |
| 职能部门 | — | — | — | 1.0(取公司系数) |

### 四、个人绩效系数

| 绩效等级 | 个人系数 | 说明 |
|----------|----------|------|
| S-卓越 | 2.0 | 最高2个月基本工资 |
| A-优秀 | 1.5 | — |
| B-良好 | 1.0 | 标准水平 |
| C-待改进 | 0.5 | — |
| D-不达标 | 0 | 无年终奖 |

### 五、年终奖计算示例

#### 示例1: 张伟（研发-机械组，半导体BU项目）

| 项目 | 数值 |
|------|------|
| 基本工资 | 16,000元 |
| 公司系数 | 1.2 |
| BU系数 | 1.5 (半导体) |
| 个人系数 | 1.5 (绩效A级) |
| 在职月数 | 12/12 |
| **年终奖** | **16,000 × 1.2 × 1.5 × 1.5 = 43,200元** |

#### 示例2: 杨国庆（生产-装配，多BU支撑）

| 项目 | 数值 |
|------|------|
| 基本工资 | 10,500元 |
| 公司系数 | 1.2 |
| BU系数 | 1.0 (职能部门取公司系数) |
| 个人系数 | 1.0 (绩效B级) |
| 在职月数 | 12/12 |
| **年终奖** | **10,500 × 1.2 × 1.0 × 1.0 = 12,600元** |

#### 示例3: 张明辉（新入职，2026年4月入职，在2026年底计算）

| 项目 | 数值 |
|------|------|
| 基本工资 | 15,600元(转正后) |
| 公司系数 | 待定 |
| BU系数 | 待定 |
| 个人系数 | 待定 |
| 在职月数 | 9/12 (4月-12月) |
| **年终奖** | **基本工资 × 公司 × BU × 个人 × 0.75** |

### 六、年终奖预算总控

| 项目 | 金额(万元) |
|------|-----------|
| 全员基本工资月总额 | 约625 |
| 预计公司系数 | 1.2 |
| 预计BU平均系数 | 1.15 |
| 预计个人平均系数 | 1.05 |
| **预计年终奖总额** | **约905万** |
| 占年度人工总成本 | 12.1% |
| 占年度营收 | 1.17% |

### 七、特殊规定

| 情况 | 处理规则 |
|------|----------|
| 入职不满3个月 | 无年终奖 |
| 入职3-12个月 | 按在职月数折算 |
| 年内有严重违纪 | 扣减50-100% |
| 年内有PIP记录 | 个人系数按PIP期间绩效计 |
| 12月离职 | 不享受年终奖 |
| 产假/病假（6个月内） | 按实际出勤月折算 |
| 跨BU调动 | 按各BU在职时间加权计算BU系数 |

### 八、发放时间表

| 事项 | 时间 |
|------|------|
| 确定公司系数 | 12月20日（年度经营数据确认后） |
| 确定BU系数 | 12月25日 |
| 个人年终奖计算 | 1月5日 |
| HR总监/CFO审核 | 1月8日 |
| CEO/董事会审批 | 1月10日 |
| 年终奖发放 | **1月15日（春节前15天）** |

## 使用说明

1. 年终奖方案每年12月由薪酬绩效经理草拟
2. 公司系数和BU系数基于财务确认的年度经营数据
3. 个人系数严格按年度绩效评级确定，不得人为调整
4. 年终奖发放后由财务代扣个人所得税
5. 年终奖金额属于薪酬保密信息
6. 对年终奖有异议的，可在发放后5个工作日内向HRBP申诉
