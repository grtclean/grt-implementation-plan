# 培训与发展

## 概述

规划并执行GRT全公司的培训体系，涵盖技术培训、管理培训、安全培训、质量培训及新员工培训五大类，配合能力素质模型实现员工职业发展与企业战略目标的对齐。年度培训预算约120万元，覆盖130+员工。

## 负责人

- **Owner**: 培训发展经理
- **协同**: 各部门技术骨干（内训师）、外部培训机构
- **审批**: HR总监

## 对应系统模块

- `/training` — 培训管理
- `/training-assessment` — 培训考核
- `/training-certificate` — 培训证书
- `/competency` — 能力素质模型
- `/skill-recommendation` — 技能推荐
- `/excellence-culture` — 卓越文化

## 培训体系

```
培训类别
├── 技术培训 (机械/电气/PLC/机器人/CAD/仿真)
├── 管理培训 (项目管理/领导力/沟通/时间管理)
├── 安全培训 (安全生产/消防/化学品/急救/特种作业)
├── 质量培训 (IATF16949/SPC/FMEA/8D/测量)
└── 新员工培训 (企业文化/制度流程)
```
