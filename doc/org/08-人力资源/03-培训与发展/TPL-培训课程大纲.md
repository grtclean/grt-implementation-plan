# 培训课程大纲

> **适用范围**: 内训师/外部培训师编写课程教学计划
> **更新频率**: 每门新课程开设前编制
> **审批流程**: 培训师编写 → 培训发展经理审核 → 业务部门确认

## 模板

### 一、课程基本信息

| 字段 | 内容 |
|------|------|
| 课程编号 | T06-2026 |
| 课程名称 | 机器人视觉系统（OpenCV + 深度学习） |
| 培训师 | 赵敏（软件组长，G7） |
| 课程类别 | 技术培训 |
| 适用层级 | G4-G7 |
| 先修要求 | Python基础，了解图像处理概念 |
| 总课时 | 16小时（2天） |
| 最大人数 | 12人 |
| 授课方式 | 讲授(40%) + 实操(40%) + 讨论(20%) |
| 考核方式 | 实操项目(70%) + 笔试(30%) |

### 二、课程目标

| 序号 | 学习目标 | 目标层级 |
|------|----------|----------|
| 1 | 掌握OpenCV基础图像处理（滤波/边缘检测/特征提取） | 应用 |
| 2 | 理解深度学习目标检测模型原理（YOLO/SSD） | 理解 |
| 3 | 能独立搭建视觉检测流水线（采图→预处理→推理→判定） | 应用 |
| 4 | 能将视觉检测集成到GRT机器人控制系统 | 应用 |
| 5 | 掌握视觉系统标定与精度验证方法 | 分析 |

## 使用说明

1. 培训师在开课前30天提交课程大纲，培训发展经理审核内容与岗位需求匹配度
2. 内训师课程大纲由对应部门主管确认技术内容准确性
3. 外部培训师的大纲需额外附上讲师资质证明
4. 课程大纲审批通过后，培训师在开课前10天完成教材准备
5. 课后评估结果反馈给培训师，用于课程持续改进
