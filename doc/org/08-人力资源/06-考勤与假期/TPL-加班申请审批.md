### 加班管理规则

| 规则 | 说明 |
|------|------|
| 审批时限 | 工作日加班须提前当天申请，周末/假日须提前1天 |
| 月度上限 | 每月加班不超过36小时（劳动法要求） |
| 补偿方式 | 工作日加班优先调休，周末可选加班费或调休 |
| 法定假日 | 必须支付3倍加班费（不可用调休替代） |
| 调休有效期 | 当季度内使用，逾期作废 |
| 餐费补贴 | 加班超过2小时补贴餐费30元 |
| 交通补贴 | 加班超过21:00报销打车费 |

## 使用说明

1. 员工在钉钉/GRT系统提交加班申请
2. 直属上级在加班前完成审批，未审批的加班不计入工时
3. 特殊情况（生产紧急/客户现场）可事后24小时内补交
4. 加班完成后须在钉钉打卡确认实际时间
5. 月度加班超过30小时的，HR发送预警给部门主管
6. 部门加班集中的月份，HR需与部门主管沟通是否需要增员
