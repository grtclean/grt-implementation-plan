# 考勤与假期

## 概述

管理GRT全公司的考勤记录、加班审批、假期额度及使用情况，执行标准工时制（8:30-17:30，午休1小时），确保劳动合规，为薪资核算提供准确数据。生产车间实行两班倒制度。

## 负责人

- **Owner**: 员工关系经理
- **协同**: 各部门考勤管理员、产线班组长
- **系统**: 钉钉考勤 + GRT系统同步

## 对应系统模块

- `/hr` — 人力资源管理
- `/kiosk` — 考勤自助终端
- `/worker` — 工人管理（产线考勤）

## 考勤规则

| 项目 | 规则 |
|------|------|
| 标准工时 | 8:30-17:30 (含1小时午休) |
| 产线班制 | 白班 6:00-14:00 / 夜班 14:00-22:00 |
| 迟到 | 超过8:30未打卡 |
| 早退 | 17:30前离开未申请 |
| 加班 | 须提前申请，审批后方可执行 |
| 年假 | 工龄1-10年：5-10天；10年以上：10-15天 |
| 病假 | 3天以内免证明，超过3天须医院证明 |
