# 年假统计表

## 模板

### 一、年假额度标准

| 累计工作年限 | 年假天数 | 适用说明 |
|-------------|----------|----------|
| 1年以上不满10年 | 5天 | 含社会工龄 |
| 10年以上不满20年 | 10天 | 含社会工龄 |
| 20年以上 | 15天 | 含社会工龄 |

> 入职不满1年的当年无年假；试用期内不可使用年假

### 五、年假管理规则

| 规则 | 说明 |
|------|------|
| 年假有效期 | 当年度（1月1日-12月31日） |
| 是否可延期 | 经部门同意可延至次年Q1(3月31日前)用完 |
| 未休补偿 | 因工作原因确实无法休的，按300%日薪补偿 |
| 请假审批 | 3天以内部门主管审批，3天以上需HR总监审批 |
| 项目冲突 | 项目关键节点前15天内原则上不批准年假 |

## 使用说明

1. HR考勤专员每月更新年假统计表
2. 每季度末向部门主管发送年假使用率提醒
3. 使用率低于25%的部门，HR需与部门主管沟通休假安排
4. 年假申请在钉钉/GRT系统提交，自动扣减余额
5. 11月起对年假剩余超过3天的员工发送个人提醒
6. 年末统计未休年假补偿金额，纳入12月工资发放
