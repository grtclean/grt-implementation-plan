# 01-系统架构

## 概述

系统架构模块描述 GRT 数字化平台的整体技术架构、模块组成、数据流和部署方案。当前平台采用全栈 TypeScript 技术栈，前后端统一类型安全，实现了从设计、制造、项目管理到客户服务的全业务域覆盖。

### 技术栈概览

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端框架 | React 19 + TypeScript | SPA 应用，386 个页面组件 |
| 构建工具 | Vite | 快速 HMR，生产构建 ~25s |
| 路由 | Wouter | 轻量路由库 |
| API 层 | tRPC v10 | 类型安全的 RPC 框架 |
| UI 组件 | shadcn/ui + Tailwind CSS | 可定制化组件库 |
| 图标 | Lucide Icons | 一致的图标体系 |
| 后端 | Express + tRPC | Node.js 服务端 |
| ORM | Drizzle ORM | 类型安全的 SQL 构建器 |
| 数据库 | MySQL / TiDB | 兼容 MySQL 协议的分布式数据库 |
| 测试 | Vitest | 327 个测试文件，12,000+ 测试 |
| 国际化 | 自研 i18n | 支持中/英/德/法四语言 |
