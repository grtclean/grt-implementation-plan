# 12-IT与数字化

## 概述

IT与数字化部门负责 GRT 全公司信息系统的规划、建设、运维和安全保障。核心使命是通过数字化手段赋能业务，实现从设计、制造到服务的全链条数字化管理。

当前系统基于 React 19 + Vite + tRPC + MySQL/TiDB + Drizzle ORM 技术栈构建，包含 86 个 tRPC 路由器、18 个系统角色、278 项 RBAC 权限、327 个测试文件（12,000+ 测试用例），支撑 130+ 员工的日常业务运营。
