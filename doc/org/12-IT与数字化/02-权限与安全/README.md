# 02-权限与安全

## 概述

权限与安全模块负责 GRT 数字化平台的身份认证、访问授权、数据安全和安全审计。采用 RBAC（基于角色的访问控制）模型，支持 18 个系统角色、278 项细粒度权限，覆盖 1127 个 mutation 操作的权限检查。

### 安全架构要点

- **零信任认证**：所有 mutation 操作均需 `requirePermission()` 校验
- **SQL 注入防护**：100% 参数化查询，零 `sql.raw()` 注入向量
- **API 安全**：CSP 头、CORS 控制、Rate Limiting
- **审计追踪**：全链路审计日志，操作可追溯
- **数据加密**：敏感数据加密存储，传输 HTTPS

### 系统对接

- 权限管理：`/permission-management`
- 安全合规：`/security-compliance`
- 审计日志：`/gateway-audit`
- 密钥管理：`/vault`
