### 四、审批流程集成

#### 4.1 审批场景

| 审批类型 | 发起方 | 审批节点 | 回调处理 |
|----------|--------|----------|----------|
| 采购申请 | GRT `/procurement` | 部门经理 → 财务 → 总经理 | 审批结果写入 PO 状态 |
| 费用报销 | GRT `/expense-report` | 直接主管 → 财务 | 审批结果更新报销单 |
| 请假申请 | 钉钉原生 | 直接主管 → HR | 结果同步到 GRT 考勤 |
| 加班申请 | 钉钉原生 | 直接主管 | 结果同步到 GRT 工时 |
| 出差申请 | GRT `/trip-request` | 直接主管 → 行政 | 审批结果更新差旅单 |
| 设备采购 | GRT `/procurement` | 技术经理 → 财务 → CEO | 审批结果更新采购单 |

#### 4.2 审批回调处理

```
钉钉审批完成
    ↓ HTTP 回调
GRT Webhook 接收
    ↓ 验签
解析审批结果 (agree/refuse)
    ↓
更新 GRT 业务表状态
    ↓
触发后续流程 (如：agree → 自动下采购单到 ERP)
    ↓
发送通知给申请人
```

### 五、组织架构同步

| 同步内容 | 频率 | 方向 | 处理规则 |
|----------|------|------|----------|
| 部门结构 | 每日 1 次 | 钉钉 → GRT | 新增/更新/停用 |
| 员工信息 | 每日 1 次 | 钉钉 → GRT | 入职自动创建账户 |
| 离职处理 | 实时事件 | 钉钉 → GRT | 立即禁用 GRT 账户 |
| 岗位变动 | 每日 1 次 | 钉钉 → GRT | 更新角色和权限 |

### 六、安全配置

| 安全项 | 配置 |
|--------|------|
| AppKey/AppSecret | 存储在 `.env`，通过 `/vault` 加密 |
| 回调签名验证 | 启用（SHA-256 签名） |
| IP 白名单 | 钉钉回调 IP 段已配置 |
| 权限范围 | 最小权限原则（仅申请必需权限） |
| Token 缓存 | access_token 缓存 2 小时，自动刷新 |
| 消息加密 | 启用 AES 加密 |

### 七、监控与限流

| 监控项 | 告警条件 | 处理方式 |
|--------|----------|----------|
| 消息发送成功率 | < 98% | 检查 Token、网络 |
| API 调用量 | 接近钉钉限额 80% | 降低同步频率 |
| 回调延迟 | > 30 秒 | 检查服务器负载 |
| Token 刷新失败 | 连续 2 次失败 | 短信告警 IT |
| 组织同步异常 | 差异人数 > 10 | 人工核查 |

## 使用说明

1. **配置管理**：钉钉应用配置在 `.env` 文件中（`DINGTALK_APP_KEY`, `DINGTALK_APP_SECRET`）
2. **新增通知场景**：在 `task-notification.service.ts` 中添加新模板
3. **审批流程**：在钉钉管理后台配置审批模板，在 GRT 中注册回调 URL
4. **故障排查**：检查 `server/dingtalk/` 下的日志，常见问题：Token 过期、IP 不在白名单
5. **企微迁移**：预留了企微集成接口，需要时参照钉钉模式实现
