# TPL-数字化成熟度评估

> **适用范围**：全公司数字化现状评估与规划
> **更新频率**：每年评估一次
> **审批流程**：IT 评估 → 各部门确认 → CTO 审批 → CEO 发布

## 模板

### 评估框架：5 维度 × 5 等级

| 等级 | 名称 | 定义 |
|------|------|------|
| L1 | 初始级 | 手动操作为主，数字化覆盖 < 20% |
| L2 | 基础级 | 核心流程数字化，覆盖 20-40% |
| L3 | 标准级 | 主要流程标准化数字化，覆盖 40-60% |
| L4 | 集成级 | 系统互联互通，数据驱动决策，覆盖 60-80% |
| L5 | 智能级 | AI 驱动，预测性分析，覆盖 80%+ |

### 评估维度详细定义

#### 维度一：战略与治理（Strategy & Governance）

| 等级 | 评估标准 |
|------|----------|
| L1 | 无明确数字化战略，IT 仅处理基础设施 |
| L2 | 有 IT 预算，但数字化项目按需审批 |
| L3 | 有数字化战略规划，IT 与业务定期对齐 |
| L4 | 数字化战略融入公司战略，CTO 参与经营决策 |
| L5 | 数字化驱动业务创新，持续的数字化投资 |

#### 维度二：技术架构（Technology Architecture）

| 等级 | 评估标准 |
|------|----------|
| L1 | 独立的 Excel/纸质系统，无统一平台 |
| L2 | 基础 ERP/OA 系统，但数据孤岛 |
| L3 | 统一技术平台，核心系统标准化 |
| L4 | 系统集成互通，API 驱动，数据共享 |
| L5 | 云原生/微服务架构，AI 嵌入，实时数据流 |

#### 维度三：数据管理（Data Management）

| 等级 | 评估标准 |
|------|----------|
| L1 | 数据分散在个人电脑/纸质文件中 |
| L2 | 核心数据集中存储，但质量参差不齐 |
| L3 | 数据标准化，主数据管理，定期清洗 |
| L4 | 数据仓库/BI，数据驱动决策 |
| L5 | 数据湖/实时分析，AI 自动洞察 |

#### 维度四：组织与人才（Organization & Talent）

| 等级 | 评估标准 |
|------|----------|
| L1 | 无 IT 团队，依赖外部供应商 |
| L2 | 有基础 IT 支持团队 |
| L3 | 有 IT 开发团队，全员基础数字化技能 |
| L4 | 各部门有数字化 Champion，数据分析能力 |
| L5 | 全员数字化思维，持续创新文化 |

#### 维度五：文化与变革（Culture & Change）

| 等级 | 评估标准 |
|------|----------|
| L1 | 抵触数字化变革，习惯手工操作 |
| L2 | 被动接受新系统，使用率低 |
| L3 | 主动使用系统，提出改进建议 |
| L4 | 拥抱数字化变革，主动创新 |
| L5 | 数字化创新文化，持续实验和迭代 |

## 使用说明

1. **评估频率**：每年 12 月进行年度评估，作为下年度数字化预算的依据
2. **评估方法**：IT 团队初评 → 各部门主管确认 → 管理层审核
3. **评分标准**：每项 1-5 分，维度得分为各项平均值
4. **目标设定**：参考行业标杆，结合公司实际制定渐进目标
5. **差距跟踪**：季度跟踪行动计划执行情况，年末复评
6. **行业对标**：机器人/自动化行业平均成熟度约 L2.5-L3.0
