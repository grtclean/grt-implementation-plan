# 03-TX工作阶段

## 概述

TX工作阶段是GRT项目执行层面的细粒度管控机制，共分为TX-001至TX-015共15个工作阶段。与M0-M12里程碑阶段门关注"决策节点"不同，TX工作阶段关注"执行过程"——每个TX阶段有明确的工作内容、输入/输出物、责任部门和工时预算。TX阶段与M阶段门存在映射关系，多个TX阶段的完成对应一个M阶段门的达成。

## TX-001至TX-015阶段定义

| TX编号 | 阶段名称 | 主要活动 | 关联M阶段 | 典型周期 | 责任部门 |
|--------|----------|----------|-----------|----------|----------|
| TX-001 | 需求分析 | 客户需求收集、CRS编制、可行性评估 | M0 | 2-3周 | 销售+技术 |
| TX-002 | 项目规划 | WBS编制、资源计划、风险登记、章程编制 | M1 | 1-2周 | PMO |
| TX-003 | 概念设计 | 方案比选、架构设计、初步BOM、成本估算 | M2 | 3-4周 | 技术中心 |
| TX-004 | 详细设计 | 图纸绘制、BOM定稿、FMEA、计算书 | M3 | 3-4周 | 技术中心 |
| TX-005 | 设计冻结 | 设计审签、BOM锁定、ECN基线建立 | M4 | 3-5天 | 技术中心 |
| TX-006 | 采购执行 | 询价比价、PO下达、供应商跟催、到货检验 | M5 | 4-8周 | 采购部 |
| TX-007 | 外协管理 | 外协件加工跟踪、质量验收 | M5 | 4-6周 | 采购部+质量 |
| TX-008 | 装配执行 | 机械装配、电气布线、管路连接 | M6 | 3-4周 | 生产部 |
| TX-009 | 调试测试 | PLC调试、功能测试、性能测试、整改 | M7 | 2-3周 | 软件+质量 |
| TX-010 | FAT执行 | FAT方案执行、客户见证、报告签署 | M8 | 1-2周 | 质量+项目 |
| TX-011 | 包装发运 | 拆分包装、装箱发运、运输跟踪 | M9 | 1周 | 物流+生产 |
| TX-012 | 现场安装 | 卸货就位、组装连接、通电调试 | M10 | 2-3周 | 售后+技术 |
| TX-013 | 现场验收 | SAT执行、试运行、操作培训 | M11 | 2周 | 售后+质量 |
| TX-014 | 终验收 | 终验收签字、文档移交、质保启动 | M12 | 1周 | 项目+售后 |
| TX-015 | 项目收尾 | 经验教训、财务结算、资源释放、归档 | M12后 | 1-2周 | PMO+项目 |

## TX与M阶段门映射关系

```
TX-001 ────────→ M0 (需求确认)
TX-002 ────────→ M1 (项目启动)
TX-003 ────────→ M2 (方案设计)
TX-004 ────────→ M3 (详细设计)
TX-005 ────────→ M4 (设计冻结)
TX-006 + TX-007 → M5 (采购完成)
TX-008 ────────→ M6 (装配完成)
TX-009 ────────→ M7 (内部测试)
TX-010 ────────→ M8 (FAT通过)
TX-011 ────────→ M9 (发货)
TX-012 ────────→ M10 (现场安装)
TX-013 ────────→ M11 (SAT通过)
TX-014 + TX-015 → M12 (终验收)
```
