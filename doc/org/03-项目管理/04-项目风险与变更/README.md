# 04-项目风险与变更

## 概述

项目风险与变更管理是GRT项目管理体系的核心保障机制。风险管理采用PMBOK风险管理框架，覆盖风险识别、定性/定量分析、应对规划、监控和关闭全过程。变更管理采用严格的变更控制委员会(CCB)审批机制，确保任何对项目基线（范围、成本、进度）的修改都经过充分评估和授权审批。经验教训(Lessons Learned)在项目收尾阶段系统性总结，并纳入组织过程资产库。

## 风险等级定义

| 概率\影响 | 低(1) | 中(2) | 高(3) | 极高(4) |
|-----------|-------|-------|-------|---------|
| 高(3) | 中(3) | 高(6) | 高(9) | 极高(12) |
| 中(2) | 低(2) | 中(4) | 高(6) | 高(8) |
| 低(1) | 低(1) | 低(2) | 中(3) | 中(4) |

- **极高(≥9)**: 须立即上报BU总经理，制定应急方案
- **高(6-8)**: 须制定应对措施并每周跟踪
- **中(3-4)**: 须制定应对措施并每两周跟踪
- **低(1-2)**: 接受风险，定期监控
