# 03-项目管理

## 概述

项目管理体系覆盖GRT所有产品交付项目的全生命周期管理，采用M0-M12里程碑阶段门控模型与TX-001至TX-015工作阶段并行管控机制。体系涵盖项目启动立项、阶段门评审、进度跟踪、风险变更管理、交付验收及项目分析闭环等核心流程。适用于工业清洗机器人、装配线、半导体清洗系统等全系列产品项目，符合IATF 16949项目管理要求。

## KPI指标

| KPI | 目标 | 计算公式 | 数据来源 | 统计周期 |
|-----|------|----------|----------|----------|
| 项目交付准时率 | ≥85% | 按期交付项目数 / 总项目数 × 100% | POS系统 | 月度 |
| 成本偏差率 | ≤5% | \|实际成本 - 预算成本\| / 预算成本 × 100% | ERP + 项目台账 | 月度 |
| 客户满意度 | ≥90% | CSAT问卷得分均值 | 客户反馈系统 | 项目结束 |
| 阶段门一次通过率 | ≥75% | 一次通过评审数 / 评审总数 × 100% | Stage-Gate系统 | 季度 |
| 变更控制率 | ≤10% | 变更次数 / 基线范围项数 × 100% | 变更管理台账 | 月度 |
| 风险闭环率 | ≥90% | 已关闭风险数 / 识别风险总数 × 100% | 风险登记册 | 月度 |
| FAT一次通过率 | ≥80% | 首次FAT通过项目数 / FAT总项目数 × 100% | FAT报告 | 季度 |
| 项目资源利用率 | ≥80% | 实际工时 / 计划工时 × 100% | 工时系统 | 月度 |
