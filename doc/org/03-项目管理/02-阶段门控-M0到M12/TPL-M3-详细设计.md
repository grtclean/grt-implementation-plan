## 使用说明

1. **核心目的**: M3确保"设计完整且可制造"——图纸可直接用于采购和生产
2. **图纸质量**: 详细图纸须经设计、校对、审核三级签审
3. **DFMEA**: 所有RPN>200的失效模式必须在M3前降至200以下
4. **系统操作**: `/stage-gate → M3 → 发起评审`，关联图纸和BOM版本
