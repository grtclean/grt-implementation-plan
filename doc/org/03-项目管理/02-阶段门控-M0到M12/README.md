# 02-阶段门控 M0到M12

## 概述

GRT项目管理采用M0-M12共13个里程碑阶段门控模型，覆盖从需求确认到终验收的完整项目生命周期。每个阶段门设有明确的入口准则、出口准则、交付物清单和评审机制，确保项目在各关键节点质量可控、风险可管。阶段门评审结果分为"通过"、"有条件通过"和"不通过"三级。

## M0-M12 阶段定义

| 阶段 | 中文名 | 英文名 | 主要活动 | 典型周期 | 评审级别 |
|------|--------|--------|----------|----------|----------|
| **M0** | 需求确认 | Requirements Confirmed | 客户需求分析、可行性评估、CRS签署 | — | 部门级 |
| **M1** | 项目启动 | Project Kickoff | 项目章程、团队组建、启动会、WBS编制 | — | 部门级 |
| **M2** | 方案设计 | Concept Design | 概念方案、架构选型、初步BOM、成本估算 | 3-4周 | BU级 |
| **M3** | 详细设计 | Detail Design | 详细图纸、BOM定稿、FMEA、设计计算书 | 3-4周 | 部门级 |
| **M4** | 设计冻结 | Design Freeze | 设计基线冻结、BOM锁定、长周期件订购 | 1周 | 部门级 |
| **M5** | 采购完成 | Procurement Complete | 全部物料到齐、IQC检验通过、BOM齐套确认 | 4-8周 | 部门级 |
| **M6** | 装配完成 | Assembly Complete | 机械装配、电气布线、尺寸检验、外观检查 | 3-4周 | 部门级 |
| **M7** | 内部测试 | Internal Testing | 功能测试、安全测试、性能测试、整改闭环 | 2周 | BU级 |
| **M8** | FAT通过 | FAT Passed | 工厂验收测试执行、客户见证、FAT报告签署 | 1-2周 | 客户级 |
| **M9** | 发货 | Shipment | 包装防护、装车发运、运输保险、报关 | 1周 | 部门级 |
| **M10** | 现场安装 | Site Installation | 卸货就位、基础连接、水电气接通、调试启动 | 2-3周 | 部门级 |
| **M11** | SAT通过 | SAT Passed | 现场验收测试、生产试运行、操作员培训 | 2周 | 客户级 |
| **M12** | 终验收 | Final Acceptance | 终验收证书签署、质保启动、项目收尾 | 1-2周 | 客户级+BU级 |

## 阶段门流程图

```
M0 → M1 → M2 → M3 → M4 → M5 → M6 → M7 → M8 → M9 → M10 → M11 → M12
需求   启动   方案   详细   冻结   采购   装配   测试   FAT   发货   安装   SAT   终验
确认         设计   设计               完成                                      收
```

## 评审决策规则

| 决策 | 条件 | 后续动作 |
|------|------|----------|
| 通过 (Pass) | 所有必选检查项完成，无A类遗留项 | 进入下一阶段 |
| 有条件通过 (Conditional) | 必选检查项完成≥90%，遗留项有明确整改计划 | 进入下一阶段，限期关闭遗留项 |
| 不通过 (Fail) | 必选检查项完成<90%，或存在A类阻塞问题 | 整改后重新评审 |
