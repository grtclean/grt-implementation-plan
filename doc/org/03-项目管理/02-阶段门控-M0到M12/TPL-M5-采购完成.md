## 使用说明

1. **核心目的**: M5确保"料齐了"——所有物料经检验合格并齐套入库
2. **齐套定义**: 按装配站位/工序分拣齐套，而非仅按BOM总数统计
3. **让步接收**: 让步接收须经质量工程师评审，记录不符合项和使用风险评估
4. **系统操作**: `/stage-gate → M5 → 发起评审`，系统自动检查WMS齐套状态
