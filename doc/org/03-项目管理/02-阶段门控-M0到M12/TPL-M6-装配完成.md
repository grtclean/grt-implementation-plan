## 使用说明

1. **核心目的**: M6确保"装完了、装对了"——整机装配完成且自检合格
2. **安全优先**: 安全防护装置（急停、安全光幕、护栏互锁）是必检项，缺一不可通过
3. **检验标准**: 关键尺寸以图纸公差为准，安全测试以GB/CE标准为准
4. **系统操作**: `/stage-gate → M6 → 发起评审`，上传检验报告
