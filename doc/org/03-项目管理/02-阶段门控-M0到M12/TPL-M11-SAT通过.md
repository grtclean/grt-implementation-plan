## 使用说明

1. **核心目的**: M11确保"客户现场能稳定生产"——实际工况下性能达标
2. **试运行**: 须使用客户实际工件进行试运行，不可用模拟件替代
3. **培训**: 操作员培训须含理论+实操+考核，考核不合格须补训
4. **系统操作**: `/stage-gate → M11 → 发起评审`，上传客户签字版SAT报告
