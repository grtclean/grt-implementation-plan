## 使用说明

1. **核心目的**: M4确保"不再改了"——设计基线冻结，进入采购和生产阶段
2. **冻结令**: 技术总监签署的冻结令是M4最关键的文件
3. **ECN流程**: M4后的任何设计修改必须走ECN流程，评估成本/交期/质量影响
4. **系统操作**: `/stage-gate → M4 → 发起评审`，BOM状态自动切换为Frozen
