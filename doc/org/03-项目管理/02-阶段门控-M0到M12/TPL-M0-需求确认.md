## 使用说明

1. **核心目的**: M0确保"做不做这个项目"的决策基于充分的需求分析和可行性论证
2. **关键交付物**: CRS（客户需求规格书）是M0最重要的输出，后续所有设计以此为基准
3. **系统操作**: `/stage-gate → M0 → 发起评审`，上传CRS和可行性报告后触发
4. **注意事项**: M0通过后，客户需求变更须走正式变更控制流程
