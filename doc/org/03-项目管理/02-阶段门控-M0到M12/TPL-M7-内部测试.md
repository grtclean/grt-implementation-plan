## 使用说明

1. **核心目的**: M7确保"设备能正常工作"——功能完备、安全合格、性能达标
2. **Punch List**: 内测期间发现的问题逐条记录，A/B类必须全部闭环后方可通过
3. **FAT准备**: M7通过后应确认FAT日期、FAT方案、客户见证人员
4. **系统操作**: `/stage-gate → M7 → 发起评审`，关联测试报告和Punch List
