## 使用说明

1. **评审准备**: 项目经理须在评审前≥2个工作日将评审资料分发给评审委员
2. **入口准则**: 必须先确认入口准则全部满足，否则不启动正式评审
3. **问题分级**: A类问题存在时不得通过或有条件通过，必须返回整改
4. **系统操作**: 在 `/stage-gate → 项目 → 对应阶段门 → 发起评审` 中操作
5. **记录归档**: 评审后2个工作日内将签字版PDF上传至系统，关联对应阶段门
6. **遗留跟踪**: 有条件通过的遗留项自动生成待办，系统跟踪至关闭
