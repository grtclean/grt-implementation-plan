## 使用说明

1. **核心目的**: M10确保"装好了、能跑起来"——现场安装联调完成
2. **客户配合**: 安装期间需客户提供吊装设备、水电气接通、MES端口开放
3. **安全施工**: 现场施工须遵守客户工厂安全规定，每日安全交底
4. **系统操作**: `/stage-gate → M10 → 发起评审`，上传安装报告和通电测试记录
