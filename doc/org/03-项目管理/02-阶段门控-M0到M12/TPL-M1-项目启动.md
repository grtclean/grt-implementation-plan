## 使用说明

1. **核心目的**: M1确认项目"准备好了吗"——团队、计划、资源、资金四位一体
2. **启动会**: M1评审通常与启动会合并召开，先启动会再评审
3. **系统操作**: `/stage-gate → M1 → 发起评审`
4. **注意事项**: M1后项目章程和WBS计划即为基线，后续变更需走正式流程
