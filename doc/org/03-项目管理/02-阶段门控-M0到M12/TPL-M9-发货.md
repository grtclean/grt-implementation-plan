## 使用说明

1. **核心目的**: M9确保"安全到达"——包装防护充分、文件齐全、保险到位
2. **装箱核对**: 必须逐项核对装箱清单与BOM，防止漏装
3. **GPS追踪**: 建议在大件设备上安装GPS追踪器，实时监控运输状态
4. **系统操作**: `/stage-gate → M9 → 发起评审`，上传装箱清单和运输单据
