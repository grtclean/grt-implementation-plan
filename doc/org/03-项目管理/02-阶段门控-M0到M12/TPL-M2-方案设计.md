## 使用说明

1. **核心目的**: M2确保"方向对不对"——概念方案经过充分比选和论证
2. **方案比选**: 必须提供≥2种方案并从技术、成本、交期、风险四维度比选
3. **客户确认**: 建议在正式评审前与客户进行至少一次方案沟通
4. **系统操作**: `/stage-gate → M2 → 发起评审`，上传方案报告和BOM
