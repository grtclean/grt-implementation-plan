## 使用说明

1. **核心目的**: M8确保"客户认可了"——客户见证测试并签署FAT报告
2. **客户见证**: FAT必须有客户代表全程见证，测试数据现场记录
3. **FAT报告**: 必须包含全部测试项的数据、照片、结论，双方签字
4. **系统操作**: `/stage-gate → M8 → 发起评审`，上传客户签字版FAT报告
