# 06-项目分析

## 概述

项目分析模块提供多维度的项目绩效评估和经营分析能力，包括单项目KPI记分卡、项目月度报告和项目成本分析三大工具。通过数据驱动的分析方法，支撑项目经理实时掌控项目健康度，支持PMO进行项目集层面的决策，并为BU经营分析提供项目维度的数据支撑。
