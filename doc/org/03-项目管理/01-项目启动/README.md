# 01-项目启动

## 概述

项目启动阶段是GRT项目管理体系的起点，涵盖从商机转化为正式项目的全过程。包括项目立项审批、项目章程编制、M0需求确认和M1项目启动会两个里程碑的达成。本阶段确保项目在正式开工前完成客户需求确认、可行性评估、资源预分配、风险初评和项目团队组建。

## 阶段流程

```
商机确认 → 可行性评估 → 立项申请 → 审批通过 → 项目章程 → M0需求确认 → M1项目启动
```
