# 03-供应商管理

## 概述

供应商管理部门负责GRT机器人供应商的全生命周期管理：从供应商开发、准入评估、绩效管理到处罚退出。维护合格供应商名录(ASL)，定期评估供应商风险，推动供应商持续改善。目前在册供应商约105家，覆盖电气、机械、电子、化工、外协加工等品类。

## KPI指标

| KPI | 目标 | 计算方式 |
|-----|------|----------|
| ASL供应商数量 | 优化至100家 | 淘汰D级+合并同类 |
| A级供应商占比 | ≥40% | A级数量/ASL总数 |
| 供应商不良PPM | ≤500 | 不良件数/交货件数×10^6 |
| 单一供应商比例 | ≤15% | 单源采购额/总采购额 |
