# 01-采购管理

## 概述

采购管理负责GRT机器人所有直接物料、间接物料及外协服务的采购全流程管理。从需求提出到合同签订、交付验收、付款结算的端到端闭环，确保物料供应的及时性、质量合格性和成本最优化。采购品类涵盖：伺服电机及驱动器、工业传感器（激光雷达、视觉相机、力矩传感器）、PLC/运动控制器、机械结构件（铝型材、钣金件、精密铸件）、线束/连接器、清洗喷嘴/泵组件等。

## KPI指标

| KPI | 目标 | 计算方式 |
|-----|------|----------|
| 采购成本节降率 | ≥5% | (上期均价-本期均价)/上期均价×100% |
| 采购周期（标准件） | ≤7个工作日 | 从PR审批到交货入库天数 |
| 采购周期（定制件） | ≤30个工作日 | 从PR审批到交货入库天数 |
| 合同覆盖率 | ≥95% | 有框架合同的采购额/总采购额×100% |
| 紧急采购比例 | ≤10% | 紧急采购单数/总采购单数×100% |
