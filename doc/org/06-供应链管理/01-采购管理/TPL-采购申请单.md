## 使用说明

1. **填写规范**：物料编码按GRT编码规则填写（MTL-{类别}-{序号}），无编码的新物料标注"待编码"
2. **预算单价**：参考历史采购价或市场询价，偏差超过10%需说明原因
3. **紧急采购**：需在"加急原因"栏详细说明，紧急采购将纳入月度采购KPI统计
4. **审批权限**：
   - ≤1万元：部门经理 → 采购经理
   - ≤5万元：部门经理 → 采购经理 → 采购总监
   - ≤20万元：部门经理 → 采购经理 → 采购总监 → VP
   - \>20万元：部门经理 → 采购经理 → 采购总监 → VP → CEO
5. **附件要求**：定制件须附设计图纸（DWG/STEP），技术协议须附签字版扫描件
6. **系统操作**：在采购工作台(`/procurement`)提交电子PR，系统自动触发审批流
