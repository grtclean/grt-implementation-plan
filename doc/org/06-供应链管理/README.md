# 06-供应链管理

## 概述

供应链管理部门负责GRT机器人全产业链的采购、仓储、物流、供应商管理及追溯体系建设。覆盖5大事业部（海外/商用车/乘用车/半导体/工业通用）的物料供应保障，确保IATF 16949合规要求下的供应链可靠性与成本竞争力。管理范围包括：直接物料（伺服电机、传感器、控制器、结构件）、间接物料（工具耗材、包装）、备件（售后服务备件池）以及外协加工服务。

## KPI指标

| KPI | 目标 | 计算方式 | 数据来源 | 考核周期 |
|-----|------|----------|----------|----------|
| 采购成本节降率 | ≥5% | (上期均价-本期均价)/上期均价×100% | ERP采购订单 | 季度 |
| 供应商交期准时率 | ≥90% | 准时交货批次/总交货批次×100% | 供应链系统 | 月度 |
| IQC来料合格率 | ≥98% | IQC合格批次/总检验批次×100% | IQC检验记录 | 月度 |
| 库存周转率 | ≥6次/年 | 年度出库金额/平均库存金额 | WMS系统 | 季度 |
| 供应商集中度 | 单一供应商≤30% | 最大供应商采购额/总采购额×100% | 采购系统 | 年度 |
| 紧急采购比例 | ≤10% | 紧急采购单数/总采购单数×100% | 采购系统 | 月度 |
| 库存准确率 | ≥99% | 盘点一致项/总盘点项×100% | 盘点记录 | 季度 |
| 供应商不良PPM | ≤500 | 不良件数/交货总件数×10^6 | IQC系统 | 月度 |
