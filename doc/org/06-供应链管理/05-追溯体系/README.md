# 05-追溯体系

## 概述

追溯体系是GRT机器人IATF 16949质量管理体系的核心组成部分，实现从原材料供应商到最终客户的全链路正向/反向追溯。覆盖供应商来料批次、IQC检验、仓储流转、生产装配、成品测试、发货交付的全过程。当发生质量问题时，能快速定位影响范围、锁定批次、通知相关客户。

## KPI指标

| KPI | 目标 | 计算方式 |
|-----|------|----------|
| 追溯覆盖率 | 100% | 有追溯记录的物料批次/总批次 |
| 追溯响应时间 | ≤2小时 | 从问题发现到完成追溯分析的时间 |
| 标签扫描率 | ≥99% | 装配过程实际扫码次数/应扫码次数 |
