# TPL-追溯性标签

> **适用范围**: 所有来料、半成品、成品、备件的追溯标识
> **更新频率**: 标签规范变更时更新
> **审批流程**: 质量经理制定 → IT部实现 → 采购总监确认（供应商端标签要求）

---

## 模板

### 标签类型定义

| 标签类型 | 适用对象 | 载体 | 尺寸 | 打印时机 |
|----------|---------|------|------|----------|
| 来料标签 | 采购到货物料 | QR码 + 文字 | 50×30mm | IQC合格后 |
| 半成品标签 | 在制品/组件 | QR码 + 文字 | 70×40mm | 工序完成后 |
| 成品标签 | 整机/模组 | QR码 + 条码 + 文字 | 100×60mm | 终检合格后 |
| 备件标签 | 售后备件 | QR码 + 文字 | 50×30mm | 入备件库时 |
| 铭牌 | 整机设备 | 金属铭牌(激光刻印) | 80×50mm | 整机组装完成 |

#### QR码编码内容（JSON格式）

```json
{
  "t": "MAT",
  "mc": "MTL-SV-0034",
  "bt": "BT-PNA-20260308-01",
  "sp": "SUP-E-001",
  "pd": "2026-03-06",
  "iq": "PASS",
  "qi": "ZL",
  "qd": "2026-03-09",
  "qty": 6,
  "loc": "A-03-02"
}
```

| 字段 | 说明 | 长度 | 必填 |
|------|------|------|------|
| t | 标签类型 (MAT/WIP/FG/SP) | 3 | 是 |
| mc | 物料编码 | 15 | 是 |
| bt | 批次号 (BT-{供应商码}-{日期}-{序号}) | 25 | 是 |
| sp | 供应商编码 | 10 | 是 |
| pd | 生产日期 (YYYY-MM-DD) | 10 | 是 |
| iq | IQC结论 (PASS/FAIL/COND) | 4 | 是 |
| qi | 检验员工号 | 5 | 是 |
| qd | 检验日期 | 10 | 是 |
| qty | 数量 | 5 | 是 |
| loc | 库位编码 | 10 | 是 |

### 装配过程扫码规范

| 工序 | 扫码内容 | 扫码方式 | 记录内容 |
|------|----------|----------|----------|
| 来料上架 | 来料标签QR码 | PDA扫码 | 库位+时间+操作员 |
| 生产领料 | 来料标签QR码 | PDA扫码 | 工单号+领料人+时间 |
| 关键件安装 | 物料QR码 + 工位码 | 工位扫码枪 | 物料-工位-产品序列号绑定 |
| 测试工位 | 产品序列号 | 工位扫码枪 | 测试结果+数据 |
| 终检合格 | 成品标签QR码 | PDA扫码 | 检验员+合格标记 |
| 包装发货 | 成品标签QR码 | PDA扫码 | 物流单号+发货时间 |

### 供应商标签要求

| 要求项 | 规范 |
|--------|------|
| 标签位置 | 每个最小包装单位外侧 |
| 批次号格式 | 与GRT批次编码一致或可映射 |
| 必要信息 | 供应商名称、物料型号、批次号、生产日期、数量、检验标记 |
| 条码/QR | 必须提供可机读的条码或QR码 |
| 耐久性 | 标签在运输、存储过程中不可脱落或模糊 |
| 认证标识 | 适用时须标注CE、UL、SEMI S2等认证标识 |

## 使用说明

1. **标签打印**：在供应链系统(`/supply-chain?tab=labels`)中生成并打印标签
2. **扫码工具**：PDA手持终端(Zebra TC52)或工位固定扫码枪(基恩士SR-2000)
3. **数据存储**：所有扫码记录存入追溯数据库，支持供应链系统实时查询
4. **IATF要求**：标签系统满足IATF 16949 8.5.2"标识和可追溯性"条款
5. **标签损坏**：标签损坏或丢失须立即补打，并在系统记录补打原因
6. **保存期限**：追溯数据永久保存（至少15年，超过设备设计寿命）
7. **客户要求**：特定客户（TSMC、BMW）可能有额外标签要求，以客户规范优先
