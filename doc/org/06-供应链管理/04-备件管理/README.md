# 04-备件管理

## 概述

备件管理负责GRT机器人售后服务备件池的规划、采购、存储和发放。确保客户现场设备故障时能快速提供替换件，最大限度减少设备停机时间。备件覆盖机械易损件（喷嘴、密封圈、轴承）、电气易损件（传感器、继电器、保险丝）及核心组件（伺服电机、控制板、泵组件）。

## KPI指标

| KPI | 目标 | 计算方式 |
|-----|------|----------|
| 备件满足率 | ≥95% | 有库存可发的备件需求/总需求 |
| 备件周转率 | ≥4次/年 | 年发出金额/平均库存金额 |
| 呆滞备件比例 | ≤8% | 12月无动态备件金额/总备件金额 |
