# 02-仓储物流

## 概述

仓储物流部门负责GRT机器人所有物料的入库验收、存储管理、出库配发及物流运输跟踪。管理仓库包括：原材料库（电气件区/机械件区/化学品区）、半成品库、成品库、备件库及海外中转仓。严格执行FIFO原则，确保IATF 16949对物料可追溯性的要求。

## KPI指标

| KPI | 目标 | 计算方式 |
|-----|------|----------|
| 库存准确率 | ≥99% | 盘点一致项/总盘点项×100% |
| 入库及时率 | ≥95% | 到货24h内完成入库/总到货批次×100% |
| 库存周转率 | ≥6次/年 | 年出库金额/平均库存金额 |
| 呆滞库存比例 | ≤5% | 180天无动态物料金额/总库存金额×100% |
