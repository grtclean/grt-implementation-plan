# 数字孪生与仿真

## 概述

数字孪生与仿真组负责GRT产品的3D数字化建模、运动仿真、流体仿真及数字孪生平台开发，为设计验证、客户Demo、远程监控及预测性维护提供数字化支撑。

## 负责人

- **Owner**: 数字孪生主管
- **System Role**: engineer
- **汇报线**: 数字孪生主管 → CTO

## 对应系统模块

- `/digital-twin` — 数字孪生中心
- `/design-engine` — 设计引擎（仿真结果可视化）
- `/iot-digital-twin` — IoT + 数字孪生集成
