# 机械设计

## 概述

机械设计部负责GRT全系列产品的结构设计、仿真分析、BOM编制及标准件选型，涵盖清洗设备、装配系统及通用机构的全部机械工程工作。

## 负责人

- **Owner**: 机械设计总工
- **System Role**: bu_mech
- **汇报线**: 机械设计总工 → CTO

## 对应系统模块

- `/mechanical-design` — 机械设计工作台
- `/bom` — BOM管理
- `/plm` — PLM图纸与文档管理
- `/design-engine` — 设计引擎（SolidWorks集成）

## KPI指标

| 指标 | 目标值 | 频率 |
|------|--------|------|
| 设计一次通过率 | ≥75% | 月度 |
| BOM准确率 | ≥98% | 每个项目 |
| 标准件使用率 | ≥60% | 季度 |
| 图纸发放准时率 | ≥90% | 月度 |
| 仿真覆盖率 | ≥90%(关键部件) | 项目 |
