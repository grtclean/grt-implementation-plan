# 图纸编号规范

> **适用范围**: 研发设计部全员 / 所有工程图纸与文档的编号管理
> **更新频率**: 年度审查，有重大产品线变更时修订
> **审批流程**: PLM管理员制定 → 机械总工审核 → CTO批准

## 模板

### 一、图纸编号结构

```
GRT - XX - YY - ZZZ (- RR)

 │     │    │    │      │
 │     │    │    │      └── 可选：子版本序号 (01, 02, 03...)
 │     │    │    └──── 三位流水号 (001-999)
 │     │    └──────── 图纸类型代码 (2位)
 │     └────────── 产品线代码 (2位)
 └──────────── 公司前缀 (固定GRT)
```

### 五、版本管理规则

| 阶段 | 版本号 | 说明 |
|------|--------|------|
| 设计中(Draft) | Rev.— | 未发放，仅设计工程师可修改 |
| 首次发放 | Rev.A | 经DDR评审通过后发放 |
| 第一次修改 | Rev.B | ECO批准后修改发放 |
| 第二次修改 | Rev.C | ECO批准后修改发放 |
| ... | Rev.D ~ Rev.Z | 依次递增(跳过I/O/Q避免混淆) |
| 量产冻结 | Rev.01 | 转字母版为数字版，表示正式量产 |
| 量产修改 | Rev.02 | 量产后ECO修改 |

**跳过字母**: I (易与1混淆), O (易与0混淆), Q (易与O混淆)

## 使用说明

1. 所有新图纸编号通过PLM系统`/plm`自动分配，禁止手动编号
2. 编号一经分配不得废弃重用，作废图纸标记"VOID"
3. 图纸修改必须通过ECO流程，不得直接修改已发放图纸
4. 外来图纸(供应商/客户)单独归档，前缀加"EXT-"
5. 项目定制件可在产品线代码前加项目号(如GRT-FAW-RC-ME-801)
6. 本规范适用于SolidWorks、AutoCAD及EPLAN所有出图软件
7. 每年1月由PLM管理员审查编号使用情况，清理未使用的预留号段
