# 电气设计

## 概述

电气设计部负责GRT产品的控制系统设计、PLC编程、HMI开发、电气安全设计及EMC合规，确保设备的自动化控制可靠性和安全合规性。

## 负责人

- **Owner**: 电气设计总工
- **System Role**: bu_elec
- **汇报线**: 电气设计总工 → CTO

## 对应系统模块

- `/electrical-design` — 电气设计工作台
- `/design-engine` — 设计引擎（PLC代码生成/HMI生成）
- `/plm` — PLM电气图纸管理
- `/bom` — 电气BOM管理
