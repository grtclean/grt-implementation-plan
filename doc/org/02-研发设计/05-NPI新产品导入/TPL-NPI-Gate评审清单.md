# NPI Gate评审清单

> **适用范围**: NPI项目团队 / 各阶段Gate评审
> **更新频率**: 每个Gate评审时使用
> **审批流程**: NPI项目经理组织评审 → CTO主持Gate评审 → CEO签字(Gate 0/Gate 5)

## 模板

### NPI阶段总览

```
Gate 0          Gate 1         Gate 2         Gate 3        Gate 4         Gate 5
概念批准    →   EVT批准    →   DVT批准    →   PVT批准   →   MP批准    →   量产确认
  │              │              │              │             │              │
  ▼              ▼              ▼              ▼             ▼              ▼
Concept        EVT            DVT            PVT          MP Ramp       Closure
(2个月)      (5个月)        (3个月)        (2个月)       (1个月)       (持续)
概念设计    工程验证测试   设计验证测试    生产验证测试   量产爬坡      项目关闭
```

## 使用说明

1. Gate评审在系统`/rnd-npi`中发起，自动通知评审委员会
2. 每个Gate评审前2周需提交全部交付物到PLM
3. Gate评审会议时长：Gate 0/4/5为半天，Gate 1/2/3为2小时
4. "有条件通过"允许进入下一阶段，但遗留问题需在指定日期前闭环
5. "不通过"需回到当前阶段整改，整改后重新评审
6. "回退"意味回退到上一阶段重做(严重质量/技术问题)
7. 所有Gate评审记录保留10年(IATF 16949要求)
