### 一、V&V总体策略

| 维度 | 说明 |
|------|------|
| **验证(Verification)** | "我们是否正确地构建了产品？" — 设计输出是否满足设计输入(需求) |
| **确认(Validation)** | "我们是否构建了正确的产品？" — 产品是否满足用户需要和预期用途 |
| **测试阶段** | EVT(功能验证) → DVT(设计验证+可靠性) → PVT(生产验证) → FAT/SAT(客户验收) |
| **测试标准** | ISO 16232(清洁度), IEC 60204-1(电气安全), ISO 13849(机械安全), IEC 61000(EMC) |

## 使用说明

1. V&V计划在Gate 0批准后启动编制，Gate 1前完成
2. 每项测试需关联到PRD中的需求编号(追溯矩阵)
3. 测试设备使用前需确认校准状态有效
4. 测试结果实时录入系统`/rd-verification`
5. 不合格项需在5个工作日内完成根因分析(8D方法)
6. 测试报告存档在PLM系统`/plm`中，关联项目编号
7. 第三方测试(如CE/EMC)报告原件由质量部保管
