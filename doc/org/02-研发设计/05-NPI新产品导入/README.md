# NPI新产品导入

## 概述

NPI新产品导入组负责管理GRT新产品从概念到量产的全流程Gate评审，协调跨部门资源，确保新产品按质、按期、按预算完成开发并导入量产。

## 负责人

- **Owner**: NPI项目总监
- **System Role**: project_manager / cto
- **汇报线**: NPI项目总监 → CTO (虚线汇报CEO)

## 对应系统模块

- `/rnd-npi` — NPI新产品导入工作台
- `/rd-verification` — 研发验证管理
- `/stage-gate` — Stage-Gate评审
- `/plm` — PLM文档管理

## KPI指标

| 指标 | 目标值 | 频率 |
|------|--------|------|
| NPI成功率 | ≥80%(按期通过所有Gate) | 季度 |
| Gate评审一次通过率 | ≥75% | 每次Gate |
| NPI项目按期完成率 | ≥85% | 季度 |
| 量产良率(首月) | ≥90% | 每个NPI |
| NPI项目ROI | ≥200%(3年) | 每个NPI |
