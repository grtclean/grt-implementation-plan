# 研发设计

## 概述

研发设计部门负责GRT全系列产品的需求分析、机械设计、电气设计、PLM文档管理、新产品导入(NPI)及数字孪生仿真，涵盖工业清洗机器人、装配系统、半导体清洗设备三大产品线的全生命周期技术研发。

## 负责人

- **Owner**: CTO (首席技术官)
- **System Role**: cto / engineer
- **汇报线**: CTO → CEO

## 对应系统模块

- `/rd-verification` — 研发验证管理
- `/plm` — 产品生命周期管理
- `/rnd-npi` — NPI新产品导入工作台
- `/mechanical-design` — 机械设计工作台
- `/electrical-design` — 电气设计工作台
- `/digital-twin` — 数字孪生中心
- `/design-engine` — 设计引擎（HMI/PLC生成）
- `/bom` — BOM管理

## KPI指标

| 指标 | 目标值 | 频率 |
|------|--------|------|
| 研发投入占比 | ≥8%（占营收） | 年度 |
| NPI成功率 | ≥80%（按期通过率） | 季度 |
| 设计一次通过率 | ≥75%（评审一次过） | 月度 |
| 专利申请数 | ≥15件/年 | 年度 |
| ECO变更周期 | ≤10个工作日 | 月度 |
| 标准化零件使用率 | ≥60% | 季度 |
| 研发项目按期完成率 | ≥85% | 季度 |
| 仿真覆盖率 | ≥90%（关键部件） | 项目 |

## 组织架构

```
CTO
├── 需求分析组 (市场需求→技术规格转化)
├── 机械设计部 (结构设计/仿真/BOM)
│   ├── 清洗设备组
│   ├── 装配设备组
│   └── 通用机构组
├── 电气设计部 (控制系统/PLC/HMI)
│   ├── 自动化组
│   ├── 电气安全组
│   └── 软件组
├── PLM与文档管理组 (版本控制/ECO)
├── NPI新产品导入组 (Gate评审/量产导入)
└── 数字孪生与仿真组 (3D建模/仿真分析)
```
