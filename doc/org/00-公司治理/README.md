# 公司治理 Corporate Governance

## 概述

公司级治理框架，涵盖组织架构、战略规划、董事会治理、风险管理、合规认证和ESG社会责任。本分区为 GRT 机器人科技集团最高层级管理文档，指导全集团 5 大事业部和 8 大职能部门的运营方向与治理标准。

## 负责人

- **Owner**: CEO
- **System Role**: ceo
- **审批权限**: 董事会 / CEO
- **协同部门**: 战略规划部、法务合规部、财务部、人力资源部

## 治理架构

```
董事会
 └── CEO（首席执行官）
      ├── CTO（首席技术官）
      │    ├── 研发中心
      │    ├── IT与数字化
      │    └── 知识管理
      ├── COO（首席运营官）
      │    ├── 生产制造
      │    ├── 质量管理
      │    ├── 供应链管理
      │    └── 客户服务
      ├── CFO（首席财务官）
      │    ├── 财务部
      │    ├── 投资部
      │    └── 风险管理
      ├── 销售VP
      │    ├── 国内销售
      │    ├── 海外销售
      │    └── 市场营销
      └── HR VP
           ├── 招聘与人才
           ├── 绩效与薪酬
           └── 组织发展
```
