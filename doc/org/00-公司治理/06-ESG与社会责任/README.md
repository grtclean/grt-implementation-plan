# ESG 与社会责任 ESG & Corporate Social Responsibility

## 概述

公司ESG（环境、社会、治理）与企业社会责任管理文档。系统化管理公司在环境保护、社会贡献和公司治理方面的实践，持续提升ESG评级，满足客户和投资方对可持续发展的要求。

## 负责人

- **Owner**: CEO
- **System Role**: ceo
- **审批权限**: CEO / 董事会
- **协同部门**: 质量部（环境）、HR（社会）、法务/财务（治理）
