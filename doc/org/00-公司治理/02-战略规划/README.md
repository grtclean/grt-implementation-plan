# 战略规划 Strategic Planning

## 概述

公司战略规划管理文档，涵盖年度经营计划、OKR目标管理、SWOT分析和中长期战略路线图。战略规划以「五年战略 → 年度计划 → 季度OKR → 月度复盘」四级时间颗粒度驱动公司运营。

## 负责人

- **Owner**: CEO
- **System Role**: ceo
- **审批权限**: 董事会（五年战略） / CEO（年度计划、OKR）
- **协同部门**: 各BU总经理、CTO、COO、CFO
