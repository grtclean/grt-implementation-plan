# OKR 矩阵

> **适用范围**: 全集团四级OKR对齐管理（公司→BU→部门→个人）
> **更新频率**: 季度设定、月度检查、季度评分
> **审批流程**: L4个人OKR → 直接上级确认 → L3部门OKR → BU GM/总监确认 → L2 BU OKR → CEO确认 → L1公司OKR → 董事会备案

## OKR 管理规则

| 规则 | 说明 |
|------|------|
| 设定时间 | 每季度第一周完成OKR设定 |
| 对齐要求 | 下级OKR至少1个KR对齐上级OKR |
| OKR数量 | 每人/每层 3-5个O，每个O对应2-4个KR |
| 评分标准 | 0.0-1.0分（0.7-0.8为理想区间，≥1.0说明目标不够挑战） |
| 检查频率 | 月度check-in（上级1:1），季度OKR评审会 |
| 公开透明 | 所有OKR在系统中全员可见 |

## 使用说明

1. **设定流程**: L1先定 → L2对齐L1 → L3对齐L2 → L4对齐L3，自上而下+自下而上双向对齐
2. **对齐标记**: 每个O后面标注 `← 对齐 L(n-1)-O(x)` 表示对齐关系
3. **评分规则**: 季度末由直接上级评分，0.0-1.0区间，鼓励设定挑战性目标（0.7-0.8为优秀）
4. **调整机制**: 季度中如外部环境重大变化，可调整KR目标值（需上级审批），O原则上不变
5. **系统录入**: 所有OKR录入 /okr 模块，对齐关系在系统中可视化展示
6. **绩效关联**: OKR评分作为绩效评估的输入之一（权重约40%），但不是唯一依据
7. **公开透明**: 所有OKR全员可见，促进跨部门对齐和协作
