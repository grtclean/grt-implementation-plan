# 合规与认证 Compliance & Certifications

## 概述

公司合规管理与认证体系文档，涵盖IATF 16949汽车质量管理体系、ISO 9001质量管理体系、ISO 14001环境管理体系的审核、维护和持续改进。确保公司运营符合法律法规和行业标准要求，维护认证资质有效性。

## 负责人

- **Owner**: 质量总监
- **System Role**: quality_director
- **审批权限**: COO（审核计划）、CEO（管理评审）
- **协同部门**: 各事业部质量工程师、生产制造中心、采购供应链中心

## 认证体系概览

| 体系标准 | 认证范围 | 认证机构 | 有效期 | 审核类型 |
|---------|---------|---------|--------|---------|
| IATF 16949:2016 | 汽车行业机器人系统集成 | TUV SUD | 3年 | 年度监督+3年换证 |
| ISO 9001:2015 | 工业自动化设备设计制造 | SGS | 3年 | 年度监督+3年换证 |
| ISO 14001:2015 | 环境管理体系 | SGS | 3年 | 年度监督+3年换证 |
| CE认证 | 欧盟出口设备 | TUV | 按产品 | 产品型式试验 |

## 审核年历

| 月份 | 审核活动 | 责任人 |
|------|---------|--------|
| 1月 | 年度审核计划发布 | 质量总监 |
| 3月 | Q1内审（条款4-6） | QA经理 |
| 4月 | IATF 16949年度监督审核（外审） | 质量总监 |
| 6月 | Q2内审（条款7-8） | QA经理 |
| 7月 | ISO管理评审 | CEO/质量总监 |
| 9月 | Q3内审（条款9-10） | QA经理 |
| 10月 | ISO 14001年度监督审核（外审） | 质量总监 |
| 12月 | 年度审核总结，下年度计划编制 | 质量总监 |
