# 岗位说明书

> **适用范围**: 集团全体18个系统角色的标准岗位说明书模板
> **更新频率**: 年度更新 / 岗位职责重大变更时即时更新
> **审批流程**: HR BP拟定 → 部门负责人确认 → HR VP审批 → CEO备案（VP级以上）

## 模板

---

### 1. CEO 首席执行官

| 字段 | 内容 |
|------|------|
| **岗位名称** | 首席执行官 (Chief Executive Officer) |
| **岗位代码** | ceo |
| **所属部门** | 集团总部 |
| **汇报对象** | 董事会 |
| **下属人数** | 5人直接（CTO/COO/CFO/销售VP/HR VP）+ 5 BU GM |
| **职级层级** | L1 (Level 10) |

**主要职责**:
1. 制定公司中长期战略规划，领导年度经营计划的制定与执行
2. 主持公司日常经营管理，对董事会负责，确保经营目标达成
3. 统筹五大事业部业务协同，推动跨BU资源整合与市场拓展
4. 建设企业文化，推动组织变革与数字化转型
5. 代表公司对外开展重大商务活动、政府关系维护

**任职资格**:
- 学历: 本科及以上，MBA/EMBA优先
- 经验: 15年以上制造业/自动化行业经验，8年以上高管经验
- 能力: 战略思维、商业敏感度、团队领导力、跨文化管理能力
- 资质: 无特殊证书要求

**KPI指标**:
| 指标 | 权重 | 目标值 |
|------|------|--------|
| 年度营收达成率 | 30% | ≥90% |
| 净利润率 | 20% | ≥12% |
| 新市场/新客户拓展 | 15% | ≥3个新行业客户 |
| 员工满意度 | 10% | ≥4.0/5.0 |
| 战略项目里程碑达成 | 25% | ≥85% |

## 使用说明

1. **新增岗位**: 复制最接近的角色模板，修改岗位名称、职责和资格要求
2. **定制KPI**: 根据部门和个人情况调整KPI指标和权重，确保总权重=100%
3. **审批流程**: 岗位说明书变更需经 HR BP → 部门负责人 → HR VP 三级审批
4. **系统关联**: 岗位代码与系统 SYSTEM_ROLES 一一对应，新增岗位需同步更新 `shared/permissions.ts`
5. **版本控制**: 每次修订在文件头部注明版本号和修改记录
