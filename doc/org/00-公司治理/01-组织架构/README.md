# 组织架构 Organization Structure

## 概述

GRT 机器人科技集团组织架构管理文档，定义公司级、事业部级、部门级的组织结构、岗位设置和职责分工。组织架构采用「集团总部 + 5大事业部 + 8大职能中心」的矩阵式管理模式。

## 负责人

- **Owner**: CEO / HR VP
- **System Role**: ceo, vp_hr
- **审批权限**: CEO（架构变更需董事会审批）
- **维护人**: 人力资源部 组织发展组

## 组织管理原则

1. **扁平化**: 管理层级不超过5层（CEO→VP→总监→经理→员工）
2. **矩阵式**: 职能线（研发、质量等）+ 业务线（5个事业部）双线汇报
3. **授权清晰**: 每个决策点有且仅有一个最终审批人（A角色）
4. **编制管控**: 人员增编需经 HR VP 审核、CEO 审批
5. **动态调整**: 随业务发展每年回顾组织架构，重大变更即时更新
