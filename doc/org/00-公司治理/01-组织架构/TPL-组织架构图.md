# 组织架构图

> **适用范围**: 集团全体，用于展示公司整体组织架构、汇报关系和人员编制
> **更新频率**: 年度更新 / 重大组织变更时即时更新
> **审批流程**: 部门调整 → HR VP审核 → CEO审批 → 董事会备案（涉及VP级以上变更需董事会审批）

## 使用说明

1. **架构图更新**: 组织架构变更时，更新对应节点的人员和编制信息
2. **汇报关系**: 实线为行政汇报关系，虚线为业务/技术指导关系（矩阵式管理）
3. **编制管理**: 增编需提交《增编申请表》→ HR VP审核 → CEO审批
4. **命名规范**: 正式文件保存为 `YYYY-MM-DD-组织架构图-[版本号].md`
5. **系统同步**: 架构变更后需同步更新系统 /org 模块和 /employee-profile 汇报关系
