# 风险管理 Risk Management

## 概述

企业级风险管理文档，覆盖战略风险、运营风险、财务风险、合规风险和外部风险五大类别。通过系统化的风险识别、评估、应对和监控流程，保障公司持续稳健经营。

## 负责人

- **Owner**: CEO / CFO
- **System Role**: ceo, cfo
- **审批权限**: CEO（风险登记册）、董事会（重大风险应对方案）
- **协同部门**: 法务合规部、财务部、各事业部
