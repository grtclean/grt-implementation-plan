# 董事会与治理 Board & Governance

## 概述

董事会治理管理文档，涵盖董事会会议管理、决议跟踪、股东会议记录等公司治理核心事项。确保公司按照良好的治理准则运营，保障股东权益和公司长期发展。

## 负责人

- **Owner**: CEO / 董事会秘书
- **System Role**: ceo
- **审批权限**: 董事会主席
- **协同部门**: 法务部、财务部

## 治理架构

| 治理机构 | 组成 | 职责 | 会议频率 |
|---------|------|------|---------|
| 董事会 | 5-7名董事 | 战略决策、CEO任免、预算审批 | 季度 |
| 监事会 | 3名监事 | 财务监督、合规检查 | 半年 |
| 股东会 | 全体股东 | 重大事项决议、董事任免 | 年度 |
| 经营管理委员会 | CEO+C-Suite | 日常经营决策 | 月度 |
| 技术委员会 | CTO+技术专家 | 技术路线评审 | 季度 |
| 投资委员会 | CEO+CFO+董事 | 重大投资审批 | 按需 |
