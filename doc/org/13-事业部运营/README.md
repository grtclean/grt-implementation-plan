# 13-事业部运营

## 概述

GRT集团下设五大事业部，各事业部独立核算、自主经营，实行"总部赋能 + 事业部主战"的管理模式。本目录包含各事业部的运营管理模板和实例文档，覆盖经营计划、KPI记分卡、人力编制、预算管理、项目台账、月度报告和年度总结等核心管理维度。


## KPI指标体系

各BU统一采用7维度KPI框架（详见 `_BU-模板/TPL-BU-KPI记分卡.md`）：

| 维度 | 权重 | 核心指标 | 集团基线 |
|------|------|----------|---------|
| 财务 | 30% | 营收完成率、毛利率、回款率 | 营收完成率 ≥ 95% |
| 客户 | 15% | 客户满意度、新客户开发、复购率 | 满意度 ≥ 85分 |
| 项目 | 15% | 交付准时率、成本偏差、验收率 | 准时率 ≥ 85% |
| 质量 | 15% | 客户投诉率、一次合格率、COPQ | 合格率 ≥ 92% |
| 效率 | 10% | 人均产值、产能利用率、工时效率 | 利用率 ≥ 80% |
| 创新 | 10% | 新产品营收占比、工艺改进、专利 | 新品占比 ≥ 15% |
| 人才 | 5% | 离职率、培训完成率、关键岗位覆盖 | 离职率 ≤ 12% |
