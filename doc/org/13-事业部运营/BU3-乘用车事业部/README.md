# BU3-乘用车事业部

## 概述

乘用车事业部服务于中国主流乘用车OEM制造企业，提供乘用车零部件清洗线、总装前清洗设备、新能源三电（电池/电机/电控）清洗系统及柔性装配清洗解决方案。是GRT集团营收最大的事业部。

2026年经营目标为营收2.5亿元人民币，毛利率35%。核心增长引擎为新能源乘用车产线配套，新能源客户营收占比目标超过50%。

## 事业部特点

| 维度 | 内容 |
|------|------|
| 目标市场 | 中国乘用车OEM及新能源车企（含造车新势力） |
| 核心产品 | 电池壳清洗线、电驱清洗系统、涂装前处理、发动机/变速箱零件清洗线 |
| 竞争对手 | 安莱科、华意机械、上海润日（国内）、Ecoclean（进口高端） |
| 差异化优势 | 高节拍产线能力（60JPH）、新能源清洗全覆盖、柔性多车型适配 |
| 关键挑战 | 客户降本压力大、产能爬坡要求高、技术迭代快、竞争激烈 |
| 核心客户 | 比亚迪、吉利/极氪、长城汽车、广汽埃安、蔚来 |
