# BU2-商用车事业部

## 概述

商用车事业部专注于商用车（卡车、客车、特种车辆）OEM制造企业的清洗设备和自动化产线业务。服务于中国主流商用车制造商，提供发动机零部件清洗线、变速箱壳体清洗系统、涂装前处理清洗设备及整车总装清洗解决方案。

2026年经营目标为营收2.0亿元人民币，毛利率33%。重点方向为新能源商用车（电动卡车/氢能客车）动力总成清洗线的技术储备和市场拓展。

## 事业部特点

| 维度 | 内容 |
|------|------|
| 目标市场 | 中国商用车OEM厂商及Tier 1零部件供应商 |
| 核心产品 | 发动机零件清洗线、缸体/缸盖清洗机、变速箱清洗系统、涂装前处理设备 |
| 竞争对手 | 安莱科（国内）、华意（国内）、Ecoclean（进口替代） |
| 差异化优势 | 深耕商用车行业15年、大型重载清洗经验、快速响应、性价比 |
| 关键挑战 | 商用车行业周期性强、客户压价严重、新能源转型技术不确定 |
| 核心客户 | 一汽解放、东风商用、陕汽重卡、中国重汽、宇通客车 |
