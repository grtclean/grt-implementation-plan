# BU1-海外事业部

## 概述

海外事业部负责GRT集团的国际市场业务拓展，主要面向欧洲（德国、意大利、法国）、北美（美国、墨西哥）、日本和韩国市场。业务涵盖汽车清洗设备、工业自动化清洗系统的出口销售、项目交付及海外售后服务。

2026年经营目标为营收1.5亿元人民币，毛利率38%，重点拓展欧洲新能源汽车客户和日本市场。
