# _BU-模板 — 事业部运营管理模板库

## 概述

本目录为事业部运营管理的标准模板库，各事业部在初始化时拷贝本目录至 `BUx-事业部名/` 并填写具体内容。模板定义了统一的管理框架、KPI指标体系和报告格式，确保集团层面的横向可比性。

## 负责人

| 角色 | 姓名 | 职责 |
|------|------|------|
| 模板维护人 | 集团COO办公室 | 年度修订模板、收集各BU反馈 |
| 审批人 | 集团COO | 批准模板变更 |

## 对应系统模块

| 系统模块 | 路径 | 说明 |
|----------|------|------|
| BU绩效仪表盘 | `/bu-performance` | KPI记分卡的线上化 |
| 报告中心 | `/report-center` | 月度/年度报告的在线生成 |
| OKR引擎 | `/strategy` | 经营计划与OKR对齐 |

## 使用方法

### 新BU初始化

1. 拷贝 `_BU-模板/` 目录为 `BUx-[事业部名称]/`
2. 在各模板中将 `[BU名称]` 替换为事业部实际名称
3. 填写具体数据（目标、编制、预算等）
4. 由BU总经理审核后提交集团COO审批

### 年度更新

1. 每年Q4，集团COO办公室发布更新后的模板
2. 各BU基于新模板更新下一年度的经营文件
3. 保留历史版本（按年份归档）

## KPI框架说明

各BU统一使用7维度KPI体系，但各维度的具体指标和目标值可根据BU特点调整：

| 维度 | 权重 | 指标数量 | 调整规则 |
|------|------|---------|---------|
| 财务 | 30% | 3项 | 目标值由集团与BU协商确定 |
| 客户 | 15% | 3项 | 可增加行业特定指标 |
| 项目 | 15% | 3项 | 固定指标不可修改 |
| 质量 | 15% | 3项 | 可增加行业认证指标 |
| 效率 | 10% | 3项 | 目标值与行业基准对齐 |
| 创新 | 10% | 3项 | 可增加技术路线指标 |
| 人才 | 5% | 3项 | 固定指标不可修改 |

### 评分规则

- 完成率 ≥ 100% → 🟢 绿色（达标）
- 完成率 80%-99% → 🟡 黄色（预警）
- 完成率 < 80% → 🔴 红色（告警）

### 趋势标识

- ↑ 上升趋势（连续2月改善）
- → 持平趋势
- ↓ 下降趋势（连续2月恶化）

## 报告节奏

| 文档 | 频率 | 截止日 | 审批流程 |
|------|------|--------|---------|
| 月度经营报告 | 每月 | 次月5日 | BU总经理 → COO |
| KPI记分卡 | 每季 | 季末+10日 | BU总经理 → COO → CEO |
| 预算执行报告 | 每季 | 季末+15日 | BU财务 → 集团财务 → CFO |

| 年度总结 | 每年 | 1月31日 | BU总经理 → COO |
