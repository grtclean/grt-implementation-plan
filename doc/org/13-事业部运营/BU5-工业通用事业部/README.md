# BU5-工业通用事业部

## 概述

工业通用事业部服务于汽车以外的多元化工业清洗与自动化市场，涵盖食品饮料、制药、电子制造、金属加工、航空零件、轨道交通等行业。产品以标准化清洗设备为主，辅以行业定制化方案，追求快速交付和规模化复制。

2026年经营目标为营收1.0亿元人民币，毛利率30%。核心增长策略为标准化产品线推广、多行业渗透和售后服务收入提升。

## 事业部特点

| 维度 | 内容 |
|------|------|
| 目标市场 | 食品/制药/电子/金属加工/航空/轨道交通等通用工业 |
| 核心产品 | 标准超声波清洗机、喷淋清洗线、真空干燥设备、碳氢清洗机、水基清洗系统 |
| 竞争对手 | 洁力达（国内）、超声电子（国内）、Branson（进口）、宝利根（国内） |
| 差异化优势 | 标准化产品交付快（4-8周）、价格低、多行业经验、全国服务网络 |
| 关键挑战 | 客户分散单价低、行业跨度大、毛利率受标品竞争压制、品牌差异化弱 |
| 核心客户 | 伊利集团、恒瑞医药、立讯精密、中国中车、宝钢集团 |
