# BU4-半导体事业部

## 概述

半导体事业部专注于半导体晶圆制造的湿法清洗设备研发与交付，服务于国内主流晶圆代工厂和IDM企业。产品涵盖单片式清洗机、槽式清洗机、干燥设备及超纯水系统集成，设备工作环境为ISO Class 4（百级）及以上洁净室。

2026年经营目标为营收1.0亿元人民币，毛利率42%（集团最高毛利率BU）。核心增长驱动力为国产替代加速及14nm以下先进制程客户导入。

## 事业部特点

| 维度 | 内容 |
|------|------|
| 目标市场 | 中国半导体晶圆制造企业（Fab） |
| 核心产品 | 单片清洗机（Spin Processor）、槽式清洗机（Wet Bench）、IPA干燥系统、超纯水模块 |
| 竞争对手 | DNS（日本）、SEMES（韩国）、盛美半导体（国内）、至纯科技（国内） |
| 差异化优势 | 国产替代性价比、定制化能力、快速交付（vs进口12个月）、本地服务响应 |
| 关键挑战 | 技术门槛高（颗粒/金属杂质ppb级）、认证周期长（12-18个月）、半导体周期波动 |
| 核心客户 | 中芯国际、华虹半导体、长江存储、合肥晶合 |
