# 收入与回款

## 概述

管理GRT全公司的合同收入确认、发票开具、应收账款催收及账龄分析。2026年度营收目标8.5亿元，回款率目标≥90%，DSO目标≤90天。

## 负责人

- **Owner**: 应收应付经理
- **协同**: 销售部（合同签订）、项目部（里程碑确认）
- **审批**: CFO

## 对应系统模块

- `/finance` — 财务管理
- `/contract` — 合同管理
- `/bu-sales-target` — BU销售目标

## 收入确认流程

```
合同签订 → 里程碑完成确认 → 开票申请 → 发票开具
→ 寄送客户 → 回款跟踪 → 到账确认 → 核销
```

## 回款管理分级

| 账龄 | 管理级别 | 催收措施 |
|------|----------|----------|
| 当期(未到期) | 正常 | 到期前15天提醒 |
| 逾期1-30天 | 关注 | 邮件+电话催收 |
| 逾期31-60天 | 预警 | 上门拜访+销售介入 |
| 逾期61-90天 | 严重 | CFO介入+暂停发货 |
| 逾期90天以上 | 危机 | 法务介入+坏账评估 |
