# 合同台账

> **适用范围**: 全公司销售合同的金额、里程碑、开票及回款跟踪
> **更新频率**: 按需更新（合同签订/里程碑完成/开票/回款时）
> **审批流程**: 销售/项目经理更新 → 财务审核 → CFO监控

## 使用说明

1. 合同签订后3个工作日内录入台账
2. 每个里程碑完成后更新状态和日期
3. 开票和回款数据由财务实时更新
4. 合同金额变更须走合同变更审批流程
5. 质保金在质保期满且无质量问题后开票催收
6. 台账数据与`/contract`系统保持一致
