# 预算管理

## 概述

负责GRT全公司年度预算编制、月度跟踪、偏差分析及预算调整的全流程管理。预算体系覆盖公司→5个事业部→8个职能部门，采用"自上而下目标+自下而上明细"的双向编制方式。

## 负责人

- **Owner**: 预算管理经理
- **协同**: 各部门主管（提报）、财务分析师（跟踪）
- **审批**: CFO → CEO → 董事会（年度总预算）

## 对应系统模块

- `/finance` — 财务管理
- `/budget-overrun-approval` — 预算超支审批
- `/expense-forecast` — 费用预测

## 预算周期

```
10月: 下达来年预算编制通知+目标
11月: 各部门编制初稿+汇总
12月: CFO/CEO审核+董事会批准
1月: 预算执行+月度跟踪启动
每月: 预算执行月报+偏差分析
季度: 预算回顾+调整（如需要）
```
