# 预算偏差分析

> **适用范围**: 月度/季度预算偏差超过阈值时进行深度分析
> **更新频率**: 月度（偏差≥5%的科目）
> **审批流程**: 财务分析师编制 → 责任部门确认 → CFO审核

### 报告期: 2026年Q1（1-3月累计）

### 二、重点偏差深度分析

#### 偏差1: 工业通用BU营收不达标 (-330万，-10%)

| 分析维度 | 内容 |
|----------|------|
| 偏差描述 | 工业通用BU Q1营收预算3,300万，实际2,970万，差330万 |
| 根本原因 | 1. 客户A的2个项目验收推迟(合同额480万)，原因是客户场地改造延期 |
| | 2. 新客户开发进展慢，Q1仅签约2个新项目(计划4个) |
| 可控性 | 部分可控（签约可加速），部分不可控（客户验收取决于客户） |
| 全年影响 | 若Q2追回验收，全年影响可控；若持续延迟，全年可能缺口500万 |
| 纠正措施 | 1. 销售加速推进客户A验收(3月底完成) |
| | 2. 增加工业通用BU销售人员投入(从1人增至2人) |
| 责任人 | 工业通用BU总经理 + 销售总监 |
| 跟踪节点 | 4月5日前反馈纠正效果 |

#### 偏差2: 管理费用超支 (+60万，+5.3%)

| 分析维度 | 内容 |
|----------|------|
| 偏差描述 | 管理费用Q1预算1,130万，实际1,190万，超支60万 |
| 明细分析 | 审计咨询费+35万(年度审计集中Q1支付)，办公设备+15万(IT升级提前)，差旅+10万(海外出差增加) |
| 可控性 | 审计费不可控(全年分摊后合理)，IT升级可控(提前支出，后续减少) |
| 全年影响 | 全年预计管理费用在预算范围内，Q1偏高系时间性差异 |
| 纠正措施 | Q2起控制办公设备采购节奏，差旅审批加严 |
| 责任人 | 行政部 + 财务部 |

#### 偏差3: 销售费用偏低 (-130万，-9.4%)

| 分析维度 | 内容 |
|----------|------|
| 偏差描述 | 销售费用Q1预算1,380万，实际1,250万，节余130万 |
| 明细分析 | 市场推广费-60万(Q1展会取消1场)，招待费-40万(客户拜访减少)，差旅-30万 |
| 可控性 | 可控（投入不足可能影响后续营收） |
| 全年影响 | 需关注销售投入不足是否导致Q3-Q4订单下降 |
| 纠正措施 | 不建议持续节约，Q2需加大市场投入追赶 |
| 责任人 | 销售总监 |

## 使用说明

1. 偏差率超过±5%的科目须进行深度分析
2. 分析须区分"有利偏差"和"不利偏差"
3. 根因分析须区分"可控"和"不可控"因素
4. 每个不利偏差须有明确的纠正措施和责任人
5. 偏差报告在月度经营分析会前完成，供会议讨论
6. 连续3个月同向偏差的须启动预算调整流程
