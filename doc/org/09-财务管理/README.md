# 财务管理

## 概述

财务管理部门负责GRT全公司的预算管理、费用管控、成本分析、收入回款、薪资发放及财务报告编制，确保经营数据准确、资金安全高效，为管理决策提供可靠的财务支撑。2026年度营收目标8.5亿元，毛利率目标≥35%。

## 负责人

- **Owner**: 财务总监(CFO)
- **System Role**: cfo / finance_manager
- **汇报线**: CFO → CEO → 董事会

## 对应系统模块

- `/finance` — 财务综合管理
- `/expense-report` — 费用报销
- `/expense-comparison` — 费用对比分析
- `/expense-forecast` — 费用预测
- `/cost` — 成本管理
- `/cost-alert` — 成本预警
- `/bu-sales-target` — BU销售目标
- `/budget-overrun-approval` — 预算超支审批

## KPI指标

| 指标 | 目标值 | 频率 |
|------|--------|------|
| 毛利率 | ≥35% | 月度 |
| 净利率 | ≥12% | 月度 |
| 回款率 | ≥90% | 月度 |
| 预算偏差率 | ≤5% | 月度 |
| 应收账款周转天数(DSO) | ≤90天 | 月度 |
| 现金转换周期(CCC) | ≤120天 | 月度 |
| 费用报销处理周期 | ≤5个工作日 | 实时 |
| 月度结账时效 | ≤T+5 | 月度 |

## 组织架构

```
财务总监(CFO)
├── 预算管理部 (年度预算/月度跟踪/偏差分析)
├── 成本管理部 (项目成本/标准工时/成本优化)
├── 应收应付部 (回款跟踪/供应商付款/发票管理)
├── 费用管理组 (费用报销审核/费用标准)
├── 薪资管理组 (工资核算/社保公积金/个税)
└── 财务分析组 (经营分析/KPI仪表板/报表)
```
