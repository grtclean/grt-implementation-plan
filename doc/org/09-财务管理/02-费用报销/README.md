# 费用报销

## 概述

管理GRT全公司的费用报销政策制定、报销审批流程及部门费用监控。年度费用预算约3,200万元（不含人工成本），涵盖差旅、招待、办公、设备维护等主要类别。

## 负责人

- **Owner**: 费用管理主管
- **协同**: 各部门行政助理（初审）
- **审批**: 部门主管 → 财务审核 → CFO（超5万须CEO）

## 对应系统模块

- `/expense-report` — 费用报销
- `/expense-comparison` — 费用对比分析
- `/trip-request` — 出差申请

## 报销流程

```
发起报销 → 贴票+填单 → 部门主管审批 → 财务审核
→ 合规性检查 → CFO审批(金额≥1万) → 出纳付款 → 归档
处理时效: ≤5个工作日
```
