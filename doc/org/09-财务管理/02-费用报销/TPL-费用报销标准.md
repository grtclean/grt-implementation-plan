# 费用报销标准

> **适用范围**: 全公司员工费用报销的政策依据
> **更新频率**: 年度更新（每年1月生效）
> **审批流程**: 费用管理主管制定 → CFO审核 → CEO批准 → 全员公示

## 模板

### 一、差旅费标准

#### 住宿标准（元/天/间）

| 职级 | 一线城市 | 二线城市 | 三线及以下 | 海外(美元) |
|------|---------|---------|-----------|-----------|
| G8-G10(总监级) | 800 | 600 | 400 | 200 |
| G5-G7(经理/工程师) | 500 | 400 | 300 | 150 |
| G1-G4(专员/操作) | 350 | 280 | 200 | 120 |

> 一线城市: 北京/上海/广州/深圳/杭州；二线城市: 省会及计划单列市

#### 餐费补贴（元/天）

| 职级 | 国内 | 海外(美元) | 说明 |
|------|------|-----------|------|
| G8-G10 | 150 | 50 | 凭票报销或包干 |
| G5-G7 | 100 | 40 | 包干，无需贴票 |
| G1-G4 | 80 | 30 | 包干，无需贴票 |

#### 交通标准

| 出行方式 | G8-G10 | G5-G7 | G1-G4 |
|----------|--------|-------|-------|
| 飞机 | 经济舱(≥4h可商务) | 经济舱 | 经济舱 |
| 高铁/动车 | 一等座 | 二等座 | 二等座 |
| 火车(普通) | 软卧 | 硬卧 | 硬卧 |

| 租车 | 可(需审批) | 特殊情况可(需审批) | 不可 |

### 六、审批权限矩阵

| 报销金额 | 审批链 |
|----------|--------|
| ≤2,000元 | 部门主管 → 财务审核 |
| 2,001-10,000元 | 部门主管 → 部门总监 → 财务审核 |
| 10,001-50,000元 | 部门总监 → CFO → 财务审核 |
| ＞50,000元 | CFO → CEO → 财务审核 |

### 七、报销时限与禁止事项

| 规则 | 说明 |
|------|------|
| 报销时限 | 费用发生后30天内提交，超过60天不予报销 |
| 发票要求 | 增值税发票（电子/纸质均可），抬头须为公司全称 |
| 禁止报销 | 个人消费、娱乐场所、烟酒（招待除外）、罚款 |
| 关联交易 | 与报销人有利益关系的供应商消费不予报销 |
| 合规要求 | 所有报销须真实、合法、合规，虚假报销按严重违规处理 |

## 使用说明

1. 本标准自2026年1月1日起执行
2. 员工在GRT系统`/expense-report`模块提交报销
3. 超标准的须在报销单中说明特殊原因并获得上一级审批
4. 差旅前须在`/trip-request`模块提交出差申请
5. 招待费须事前审批，填写招待对象和目的
6. 财务部每月抽查10%的报销单据合规性
7. 标准调整由CFO提案，CEO审批后生效
