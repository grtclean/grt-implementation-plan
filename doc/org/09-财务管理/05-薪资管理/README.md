# 薪资管理

## 概述

负责GRT全公司132名员工的月度工资核算、个人所得税计算、社保公积金缴纳及工资发放，确保准确性和合规性。月度薪资总额约625万元。

## 负责人

- **Owner**: 薪资核算主管
- **协同**: HR部（人员变动/绩效数据）、各部门（考勤/加班）
- **审批**: 财务经理 → CFO

## 对应系统模块

- `/perf-salary` — 薪酬绩效一体化
- `/hr` — 人力资源管理

## 薪资核算流程

```
每月1-3日: 收集考勤+加班+请假数据
每月3-5日: HR提供人员变动+绩效数据
每月5-8日: 工资核算+个税计算
每月8-10日: CFO审批工资表
每月15日: 工资发放（银行代发）
每月25日: 工资条推送员工确认
```
