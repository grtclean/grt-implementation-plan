### 二、费率计算方法

```
标准工时费率 = (年度完全成本) / (年度可用工时)

年度完全成本 = 薪酬 + 福利 + 社保 + 培训 + 管理费分摊
年度可用工时 = (365 - 104周末 - 11法定 - 5年假 - 5培训) × 8h = 1,920h
有效工时系数 = 0.85 (扣除行政/会议/学习时间)
实际可计入工时 = 1,920 × 0.85 = 1,632h
```

#### 计算示例: 高级工程师(G6)

| 成本项 | 年度(万) |
|--------|---------|
| 基本工资+绩效 | 27.6 |
| 社保公积金(38.4%) | 10.6 |
| 福利补贴 | 2.5 |
| 培训分摊 | 0.5 |
| 管理费分摊(15%) | 4.1 |
| **完全成本** | **40.8** |
| 有效工时 | 1,632h |
| **标准费率** | **250元/h** |

## 使用说明

1. 标准工时费率为项目报价和成本核算的统一基准
2. 实际项目报价须使用报价乘数（不低于×1.15）
3. 工时费率每年1月更新，根据薪酬调整和社保基数变化
4. 外协费率为参考值，实际以采购询价为准
5. 非标工艺或特殊要求可在标准费率基础上上浮10-30%
6. 此表为内部成本数据，不可对外提供
