# 成本分析

## 概述

负责GRT项目全成本核算、标准工时费率维护、成本偏差分析及毛利率管理。通过精细化成本管理，确保项目毛利率≥35%，支撑公司盈利目标。

## 负责人

- **Owner**: 成本分析经理
- **协同**: 生产部（工时数据）、采购部（物料价格）、项目经理（项目预算）
- **审批**: CFO

## 对应系统模块

- `/cost` — 成本管理
- `/cost-alert` — 成本预警
- `/analytics` — 数据分析

## 成本结构

```
项目总成本
├── 直接成本 (75-80%)
│   ├── 直接材料 (40-50%): BOM物料+外购件
│   ├── 直接人工 (15-20%): 按工时×费率
│   └── 外协加工 (5-10%): 外包加工费
└── 间接成本 (20-25%)
    ├── 制造费用 (15-20%): 折旧/水电/场地
    └── 管理费用分摊 (5%): 按营收比例分摊
```
