# 项目成本核算

> **适用范围**: 每个项目完工后的全成本核算（也用于项目中期成本跟踪）
> **更新频率**: 项目里程碑节点 + 项目完工
> **审批流程**: 成本分析师核算 → 项目经理确认 → 成本分析经理审核 → CFO

## 使用说明

1. 项目立项时建立成本预算基线
2. 每个里程碑节点更新实际成本（至少季度更新）
3. 成本偏差超过10%的须项目经理书面说明
4. 项目完工后30天内完成最终成本核算
5. 核算结果用于：项目毛利分析、类似项目报价参考、绩效评估
6. 录入`/cost`系统存档，作为报价知识库
