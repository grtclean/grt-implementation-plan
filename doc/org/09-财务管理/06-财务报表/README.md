# 财务报表

## 概述

编制GRT月度/季度/年度经营分析报告、现金流预测及财务KPI仪表板，为管理层提供全面、及时、准确的经营决策数据支撑。

## 负责人

- **Owner**: 财务分析经理
- **协同**: 各业务部门（经营数据）
- **审批**: CFO → CEO → 董事会（年度报告）

## 对应系统模块

- `/analytics` — 数据分析
- `/vision-dashboard` — 可视化仪表板
- `/operations-dashboard` — 运营看板

## 报表体系

```
日报: 收付款日报（出纳）
周报: 回款进展+应付到期
月报: 经营分析+预算执行+KPI仪表板
季报: 季度经营报告+现金流预测更新
年报: 年度财务决算+审计报告
```
