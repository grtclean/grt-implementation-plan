# 市场营销

## 概述

市场营销部门负责GRT品牌建设、展会管理、数字营销及市场活动策划，为销售团队输送高质量线索，提升品牌在工业自动化及机器人领域的知名度。

## 负责人

- **Owner**: 市场营销经理
- **System Role**: sales_director
- **汇报线**: 市场营销经理 → 销售总监

## 对应系统模块

- `/marketing-hub` — 营销活动管理中心
- `/lead-import` — 线索导入与分配
- `/campaign` — 营销活动跟踪
- `/community` — 社区运营

## KPI指标

| 指标 | 目标值 | 频率 |
|------|--------|------|
| 年度有效线索数 | ≥500条 | 年度 |
| 线索→商机转化率 | ≥15% | 月度 |
| 品牌曝光量 | ≥1000万次 | 季度 |
| 展会ROI | ≥3:1 | 每次展会 |
| 官网月访问量 | ≥5万UV | 月度 |
| 内容营销发布量 | ≥20篇/月 | 月度 |
