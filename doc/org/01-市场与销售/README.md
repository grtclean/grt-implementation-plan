# 市场与销售

## 概述

市场与销售部门负责GRT机器人产品的市场推广、客户开发、商机管理及合同签约全流程，覆盖五大事业部（海外/商用车/乘用车/半导体/工业通用）的销售目标达成。

## 负责人

- **Owner**: 销售总监
- **System Role**: sales_director / bu_sales
- **汇报线**: 销售总监 → CEO

## 对应系统模块

- `/crm` — CRM客户关系管理工作台
- `/sales` — 销售仪表盘
- `/lead-analytics` — 线索分析
- `/lead-auto-follow` — 线索自动跟进
- `/customer-portal` — 客户门户
- `/customer-authorization` — 客户授权管理
- `/contract` — 合同管理
- `/marketing-hub` — 营销中心
- `/solution-engine` — 方案引擎

## KPI指标

| 指标 | 目标值 | 频率 |
|------|--------|------|
| 年度签单额 | ≥8亿元 | 年度 |
| 新客户数 | ≥30家 | 年度 |
| 客户满意度 (CSAT) | ≥90% | 季度 |
| 商机转化率 (Win Rate) | ≥45% | 月度 |
| 回款率 | ≥95% | 月度 |
| 报价响应时间 | ≤3个工作日 | 实时 |
| 客户流失率 | ≤5% | 年度 |
| 销售管道价值 (Pipeline) | ≥15亿元 | 月度 |

## 组织架构

```
销售总监
├── 市场营销部 (品牌推广/展会/数字营销)
├── 客户管理部 (客户开发/客户维护/客户成功)
├── 报价与合同部 (售前报价/合同管理)
├── 销售分析部 (数据分析/预测/KPI)
└── 售前技术部 (技术方案/竞品分析/Demo)
```
