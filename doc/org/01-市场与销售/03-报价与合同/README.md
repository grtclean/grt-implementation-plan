# 报价与合同

## 概述

报价与合同部门负责GRT产品的技术报价编制、商务谈判、合同签署及保密协议管理，确保报价准确性和合同条款合规性。

## 负责人

- **Owner**: 商务经理
- **System Role**: bu_sales
- **汇报线**: 商务经理 → 销售总监

## 对应系统模块

- `/contract` — 合同管理
- `/cost` — 成本核算
- `/solution-engine` — 方案引擎（报价生成）
- `/customer-authorization` — NDA与授权管理
- `/approval` — 审批流程

## KPI指标

| 指标 | 目标值 | 频率 |
|------|--------|------|
| 报价响应时间 | ≤3个工作日 | 实时 |
| 报价准确率 | ≥95% | 月度 |
| 合同签约周期 | ≤30天(从报价到签约) | 月度 |
| 毛利率 | ≥35% | 月度 |
| 合同纠纷数 | 0 | 年度 |
