# 销售分析

## 概述

销售分析部门负责销售数据的采集、分析与可视化，为销售团队提供KPI看板、区域分析、预测模型及客户洞察，支撑管理层决策。

## 负责人

- **Owner**: 销售分析经理
- **System Role**: sales_director
- **汇报线**: 销售分析经理 → 销售总监

## 对应系统模块

- `/sales` — 销售仪表盘
- `/lead-analytics` — 线索分析
- `/bu-performance` — BU业绩看板
- `/analytics` — 数据分析中心
- `/report-center` — 报表中心

## KPI指标

| 指标 | 目标值 | 频率 |
|------|--------|------|
| 销售预测准确率 | ≥80% | 季度 |
| 数据报表及时率 | 100% | 月度 |
| 管道健康度 (Pipeline/Target) | ≥3x | 月度 |
| 分析建议采纳率 | ≥60% | 季度 |
