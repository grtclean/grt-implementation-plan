# 客户流失分析

> **适用范围**: 客户管理部 + 销售分析部 / 季度客户流失诊断与挽回
> **更新频率**: 季度分析，流失事件发生时实时登记
> **审批流程**: 客户经理登记 → 客户管理经理审核 → 销售总监评审(T1/T2客户流失)

## 模板

| 流失类型 | 定义 | 预警触发 | 确认时间 |

| 完全流失 | 客户明确终止合作、转向竞品 | 客户书面/口头告知 | 即时 |
| 休眠流失 | 连续12个月无采购、无有效商机 | 系统自动标记 | 12个月 |
| 降级流失 | 采购额连续2年下降超过50% | 年度评估 | 年度 |
| 项目流失 | 在具体项目竞标中落选 | 丢单通知 | 项目结束 |

### 三、流失原因深度分析

#### 客户1：某日系OEM(广州) — 项目流失

| 分析维度 | 详情 |
|----------|------|
| **项目概况** | CVT变速箱壳体清洗线，预算350万，2025年Q4发标 |
| **竞品信息** | 科伊斯(韩国)中标，报价280万(比GRT低20%) |
| **根因分析** | 1. 价格差距过大(70万)；2. 客户日系背景，对韩国供应商接受度高；3. 科伊斯提供了3个月免费试运行 |
| **内部复盘** | 成本结构优化空间有限；方案差异化不足(清洗工艺趋同) |
| **挽回可能** | 低。科伊斯已签约进入执行，但可关注后续产线需求 |
| **经验教训** | 日系OEM价格敏感度高，需提前准备"经济版"方案选项 |

#### 客户2：某半导体封测厂 — 完全流失

| 分析维度 | 详情 |
|----------|------|
| **项目概况** | 先进封装基板清洗，年采购150万，合作2年 |
| **流失原因** | 客户转向Naura(北方华创)的自研清洗方案，内部化清洗工序 |
| **根因分析** | 1. 客户技术团队成长，具备自研能力；2. 内部化成本更低(长期)；3. GRT未及时识别客户自研趋势 |
| **挽回可能** | 中。可提供技术咨询或售后维保服务维持关系 |
| **经验教训** | 需定期评估客户技术自主度，提供"不可替代"的增值服务 |

#### 客户3：某农机制造商 — 休眠流失

| 分析维度 | 详情 |
|----------|------|
| **客户概况** | 2024年采购1台超声清洗机(45万)，此后无后续采购 |
| **流失原因** | 客户为单条产线，清洗设备已满足需求，无扩产计划 |
| **根因分析** | T4一次性客户，无复购需求是正常业务特征 |
| **挽回可能** | 低。除非客户扩产，否则无采购驱动力 |
| **经验教训** | T4客户流失在可控范围内，重点关注T1-T3 |

## 使用说明

1. 客户流失事件在CRM`/crm`中标记，填写"流失原因"必填字段
2. T1/T2客户流失必须在24小时内上报销售总监
3. 休眠流失由系统自动扫描标记，每月1日运行（连续12个月无订单/商机）
4. 流失分析报告每季度在管理层会议上汇报
5. 预警客户名单每月更新，推送给对应客户经理
6. 挽回成功案例需编写"挽回经验"文档，纳入销售培训材料
