# 客户管理

## 概述

客户管理部门负责GRT客户全生命周期管理，包括客户开发、分级维护、拜访跟进、商机推进及满意度监控，确保客户关系持续健康发展。

## 负责人

- **Owner**: 客户管理经理
- **System Role**: bu_sales
- **汇报线**: 客户管理经理 → 销售总监

## 对应系统模块

- `/crm` — CRM客户关系管理工作台
- `/lead-analytics` — 线索分析仪表盘
- `/lead-auto-follow` — 线索自动跟进规则
- `/customer-portal` — 客户自助门户
- `/customer-authorization` — 客户授权与NDA管理

## KPI指标

| 指标 | 目标值 | 频率 |
|------|--------|------|
| 客户总数 | ≥200家活跃客户 | 月度 |
| 新客户开发 | ≥30家/年 | 年度 |
| 客户满意度 (CSAT) | ≥90% | 季度 |
| 客户流失率 | ≤5% | 年度 |
| 商机转化率 | ≥45% | 月度 |
| 客户拜访完成率 | ≥85% | 月度 |
