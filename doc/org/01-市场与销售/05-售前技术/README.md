# 售前技术

## 概述

售前技术部门负责客户需求技术分析、定制化方案设计、竞品研究及技术Demo演示，为销售团队提供技术支撑，确保技术方案的专业性和竞争力。

## 负责人

- **Owner**: 售前技术总监
- **System Role**: bu_sales / engineer
- **汇报线**: 售前技术总监 → 销售总监 (虚线汇报CTO)

## 对应系统模块

- `/solution-engine` — 方案引擎
- `/digital-twin` — 数字孪生Demo
- `/plm` — PLM文档库（竞品资料）
- `/knowledge-base` — 知识库

## KPI指标

| 指标 | 目标值 | 频率 |
|------|--------|------|
| 方案交付及时率 | ≥90% | 月度 |
| 方案→签约转化率 | ≥50% | 季度 |
| 竞标胜率 | ≥55% | 季度 |
| 客户方案满意度 | ≥85% | 季度 |
| Demo成功率 | ≥95% | 每次 |
