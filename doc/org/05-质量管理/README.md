# 05-质量管理

## 概述

质量管理部门是GRT产品质量的守门人，负责构建和维护符合IATF 16949标准的质量管理体系。部门覆盖IATF核心工具（FMEA、控制计划、PPAP、MSA、SPC）、来料检验（IQC）、过程质量控制、出厂检验（OQC）、客户投诉与CAPA、审核与认证以及安全规程七大板块。GRT于2024年通过IATF 16949认证，质量管理体系覆盖工业清洗机器人和半导体清洗设备两大产品线。

## KPI指标

| KPI指标 | 目标值 | 计算公式 | 统计周期 | 数据来源 |
|---------|--------|----------|----------|----------|
| 客户投诉率 | ≤0.5% | 投诉次数÷交付项目数×100% | 月度 | CRM/质量系统 |
| 内审不合格项数 | ≤3项/次 | 单次内审不合格项总数 | 每次审核 | 审核报告 |
| COPQ（质量成本） | ≤2%营业额 | (返工+报废+投诉处理+检验)÷营业额×100% | 月度 | 财务+质量 |
| 来料合格率 | ≥98% | 合格批次÷总检验批次×100% | 月度 | IQC系统 |
| 一次合格率（FPY） | ≥95% | 首次检验合格数÷总检验数×100% | 月度 | MES |
| 8D报告关闭及时率 | ≥90% | 按时关闭数÷总8D数×100% | 月度 | CAPA系统 |
| 供应商质量评级A/B比例 | ≥80% | A+B级供应商数÷总供应商数×100% | 季度 | 供应商管理 |
| FAT一次通过率 | ≥95% | 一次通过项目÷总FAT项目×100% | 季度 | FAT记录 |
| 管理评审决议执行率 | 100% | 已执行决议÷总决议数×100% | 半年 | 管理评审 |
