### 一、控制限计算

#### 公式

```
X-bar图：
  CL = X̿ (总平均值)
  UCL = X̿ + A₂ × R̄
  LCL = X̿ - A₂ × R̄

R图：
  CL = R̄ (平均极差)
  UCL = D₄ × R̄
  LCL = D₃ × R̄

n=4时系数：A₂=0.729, D₃=0, D₄=2.282
```

### 二、过程能力指数

```
Cp = (USL - LSL) / (6σ) = (68 - 62) / (6 × σ̂)
   其中 σ̂ = R̄/d₂ = 1.08/2.059 = 0.5246
   Cp = 6 / (6 × 0.5246) = 1.906

Cpk = min[(USL - X̿)/(3σ̂), (X̿ - LSL)/(3σ̂)]
    = min[(68-65.02)/(3×0.5246), (65.02-62)/(3×0.5246)]
    = min[1.894, 1.919]
    = 1.894
```

| 指标 | 计算值 | 判定标准 | 判定 |
|------|--------|---------|------|
| **Cp** | **1.906** | ≥1.33可接受, ≥1.67优秀 | 优秀 |
| **Cpk** | **1.894** | ≥1.33可接受, ≥1.67优秀 | 优秀 |
| **Pp（初始）** | 1.85 | ≥1.67 | 达标 |
| **Ppk（初始）** | 1.82 | ≥1.67 | 达标 |

## 使用说明

1. **数据采集**：MES系统实时录入扭矩数据，SPC图自动更新
2. **实时监控**：`/spc`看板实时展示控制图，异常自动弹窗报警
3. **异常处理**：触发判异规则时立即停止生产，启动反应计划，记录异常原因
4. **控制限更新**：积累25个以上子组且过程受控后确定正式控制限；重大变更后重新计算
5. **Cpk监控**：PPAP阶段Cpk≥1.67（初始能力），量产阶段Cpk≥1.33
6. **持续改善**：Cpk<1.33的特性纳入改善项目，目标提升至≥1.67
