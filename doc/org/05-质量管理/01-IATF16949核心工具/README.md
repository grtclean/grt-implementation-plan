# 01-IATF 16949 核心工具

## 概述

IATF 16949核心工具是汽车行业质量管理的基石，GRT在工业清洗机器人产品线全面应用五大核心工具：FMEA（失效模式与影响分析）、控制计划（CP）、PPAP（生产件批准程序）、MSA（测量系统分析）和SPC（统计过程控制）。此外，8D问题解决法作为核心问题解决工具在客户投诉和内部质量问题中广泛使用。
