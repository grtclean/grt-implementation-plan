### D4 — 根本原因分析

#### 鱼骨图分析

```
                        压力下降
                           |
    ┌──────────┬──────────┼──────────┬──────────┐
    人         机         料         法         环
    |          |          |          |          |
  操作规范   泵磨损    密封件质量   装配工艺   温度环境
  培训不足   轴承间隙   材质老化   扭矩不当   散热不良
```

#### 5-Why分析

| 层次 | 问题 | 分析 |
|------|------|------|
| Why-1 | 为什么压力下降？ | 高压泵密封件在高温下泄漏 |
| Why-2 | 为什么密封件在高温下泄漏？ | 密封件材质（NBR）耐温上限60°C，实际运行温度达62°C |
| Why-3 | 为什么运行温度超过60°C？ | 泵连续运行>4h时热平衡温度高于预期 |
| Why-4 | 为什么热平衡温度高于预期？ | 散热系统设计基于间歇运行（每2h停10min），客户要求连续8h |
| **Why-5** | **为什么散热设计不匹配？** | **需求评审时未识别"连续运行8h"要求，设计按间歇工况计算** |

#### 根本原因确认

| 根本原因 | 验证方法 | 验证结果 |
|----------|---------|---------|
| 密封件材质(NBR)不耐高温 | 60°C环境下密封件压缩永久变形测试 | 60°C/4h后压缩变形>15%（标准<10%） |
| 散热能力不足 | 热仿真分析连续8h工况 | 热平衡温度62°C，超NBR耐温上限 |
| 需求遗漏 | 追溯合同评审记录 | 合同注明"连续运行8h"，但DFR未传递至设计输入 |
