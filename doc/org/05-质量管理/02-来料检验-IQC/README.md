# 02-来料检验（IQC）

## 概述

来料检验（Incoming Quality Control）是GRT供应链质量的第一道防线，负责对所有采购物料在入库前进行质量检验。检验标准依据GB/T 2828.1抽样标准和物料分类制定，覆盖尺寸、外观、功能、材质证书等检验项目。GRT有约120家活跃供应商，月均处理300+批次来料检验。
