# TPL-安全操作规程

> **适用范围**：全体生产人员、外包人员、访客
> **更新频率**：年度审查，法规变更或事故后即时修订
> **审批流程**：安全工程师编制 → 生产总监审核 → 总经理批准

### 一、通用安全规则

| 序号 | 规则 | 要求 |
|------|------|------|
| 1 | 个人防护装备(PPE) | 进入车间必须穿戴：安全鞋、工作服、护目镜（打磨/焊接区域加面罩） |
| 2 | 安全培训 | 新员工入职3天安全培训合格后方可上岗；年度安全培训全员参加 |
| 3 | 危险区域标识 | 机器人工作区红色围栏、高压区域警示灯、化学品区黄色标线 |
| 4 | 禁止行为 | 严禁酒后上岗、疲劳作业、未经授权操作设备、跨越安全围栏 |
| 5 | 紧急出口 | 熟悉最近紧急出口位置，保持通道畅通 |
| 6 | 报告义务 | 发现安全隐患立即报告，不得隐瞒 |

### 二、机械防护规程

| 序号 | 场景 | 安全要求 | 防护措施 |
|------|------|---------|---------|
| 1 | CNC加工中心 | 运行时安全门必须关闭 | 安全门联锁（开门→主轴停止） |
| 2 | 焊接机器人 | 焊接区域禁止进入 | 安全围栏+光幕，触发即停 |
| 3 | 行车吊装 | 吊装区域禁止站人 | 专人指挥、吊装前清场 |
| 4 | 高压清洗泵 | 运行时禁止靠近喷嘴 | 防护罩+安全距离标识(>2m) |
| 5 | 旋转工作台 | 运行中禁止触碰工件 | 安全围栏+急停按钮 |
| 6 | 传送带 | 禁止在运行中清理 | 防护罩+急停拉绳 |

### 三、上锁挂牌(LOTO)程序

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 通知 | 通知所有相关人员即将进行LOTO |
| 2 | 关机 | 按正常程序关闭设备 |
| 3 | 隔离 | 断开电源开关/气源阀/液压阀 |
| 4 | 上锁 | 在隔离点挂上个人安全锁（一人一锁） |
| 5 | 挂牌 | 悬挂"禁止操作"警示牌，注明姓名、日期、原因 |
| 6 | 验证 | 尝试启动设备确认已完全隔离 |
| 7 | 释放残余能量 | 释放液压/气压残余能量，等待温度降低 |
| 完工后 | 解锁 | 确认安全后由上锁人本人解锁（禁止他人代解） |

| LOTO适用场景 | 示例 |
|-------------|------|
| 设备维修 | CNC更换主轴、清洗泵更换密封件 |
| 清洁/润滑 | 传送带内部清洁、导轨注脂 |
| 故障排除 | 电气柜检修、液压管路修复 |
| 模具更换 | 夹具更换、治具调整 |

### 四、化学品安全

| 化学品类别 | 涉及化学品 | 危险等级 | PPE要求 | 应急措施 |
|-----------|-----------|---------|---------|---------|
| 强酸 | HF、H₂SO₄、HCl | 高 | 防酸服+面罩+耐酸手套 | 大量清水冲洗15min，HF用葡萄糖酸钙 |
| 强碱 | NH₄OH(氨水) | 高 | 防化服+面罩+手套 | 大量清水冲洗15min |
| 有机溶剂 | IPA(异丙醇) | 中 | 防爆型+防溶剂手套 | 通风、远离火源 |
| 胶粘剂 | Loctite 243 | 低 | 手套+通风 | 皮肤接触用丙酮擦除 |
| 润滑脂/油 | Mobilux、润滑油 | 低 | 手套 | 肥皂水清洗 |

| 化学品存储要求 |
|-------------|
| 分类存放（酸碱隔离、有机溶剂单独防爆柜） |
| 配置MSDS文件，现场可查 |
| 二次容器防泄漏，配备吸附棉 |
| 使用量限于当班用量，多余退回 |
| 废液统一收集，委托有资质单位处理 |

## 使用说明

1. **培训要求**：所有人员进入车间前必须接受安全培训并签字确认
2. **违规处理**：首次违规口头警告+重新培训；二次书面警告+扣绩效；三次辞退
3. **安全巡查**：安全员每天巡查2次（上午/下午），填写巡查记录
4. **应急演练**：每半年1次消防演练，每年1次化学品泄漏应急演练
5. **变更管理**：新设备/新工艺投入前必须进行安全风险评估
6. **访客管理**：访客由陪同人员全程陪同，佩戴访客PPE套件
