# 07-安全规程

## 概述

安全规程管理覆盖GRT生产运营中的人身安全和设备安全，包括安全操作规程（涵盖机械防护、上锁挂牌LOTO、化学品处理、PPE要求）以及安全事故报告和调查机制。GRT车间涉及高压水射流（40MPa）、工业机器人、行车吊装、化学品（酸碱、有机溶剂）等多类危险源，安全管理是生产运营的底线。

## 负责人

| 角色 | 姓名 | 职责 |
|------|------|------|
| 安全工程师 | 郑刚 | 安全规程制定、事故调查、培训 |
| 各车间安全员 | 各班组长兼任 | 日常安全巡查、隐患上报 |
