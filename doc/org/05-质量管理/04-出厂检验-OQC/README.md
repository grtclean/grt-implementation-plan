# 04-出厂检验（OQC）

## 概述

出厂检验（Outgoing Quality Control）是产品交付客户前的最后一道质量关口，涵盖成品检验、产品合格证签发和FAT（Factory Acceptance Test，工厂验收测试）三大环节。GRT产品为定制化设备，FAT是与客户共同执行的关键验收节点，直接决定产品能否发货和收款。
