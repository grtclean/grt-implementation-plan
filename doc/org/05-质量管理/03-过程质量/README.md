# 03-过程质量

## 概述

过程质量控制是制造过程中的实时质量保障，通过质量门（Quality Gate）设置关键检查点，确保每个阶段的输出满足要求后才能流转到下一阶段。同时通过NCR（不合格品报告）管理不合格品的处置，以及清洁度检测确保清洗类产品的核心质量特性。
