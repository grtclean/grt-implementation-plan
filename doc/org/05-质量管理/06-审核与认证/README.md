# 06-审核与认证

## 概述

审核与认证管理是GRT质量管理体系持续有效运行的保障机制。包括IATF 16949年度内审、管理评审、供应商审核和外部认证审核。GRT于2024年通过IATF 16949:2016认证，需每年接受监督审核，每3年换证审核。内部审核覆盖所有IATF条款，确保体系符合性和有效性。
