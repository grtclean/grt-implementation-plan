# TPL-内审计划

> **适用范围**：全公司各部门
> **更新频率**：年度编制
> **审批流程**：体系工程师编制 → 质量总监批准 → 管理层知会

---

## 模板

### 基本信息

| 字段 | 内容 |
|------|------|
| 审核年度 | 2026年 |
| 审核依据 | IATF 16949:2016 + ISO 9001:2015 |
| 审核目标 | 验证QMS有效性、识别改善机会、为外审做准备 |
| 编制人 | 陈静 |

### 审核原则

| 原则 | 说明 |
|------|------|
| 独立性 | 审核员不得审核自己负责的部门 |
| 覆盖性 | 年度内审覆盖IATF 16949全部条款 |
| 过程方法 | 以过程为导向，关注过程的有效性 |
| 风险导向 | 重点关注上次审核发现项、客户投诉相关过程 |

## 使用说明

1. **计划通知**：审核前2周发出审核通知，告知被审核部门审核范围和时间
2. **审核准备**：被审核部门需准备相关记录、文件、数据
3. **不符合项**：发现不符合项在现场即时沟通，审核后3天内发出正式报告
4. **整改时限**：一般不符合项30天内关闭；严重不符合项15天内关闭
5. **管理评审输入**：内审结果作为管理评审输入之一
6. **外审准备**：第4次内审（9月）需在外审（通常11-12月）前完成所有整改
