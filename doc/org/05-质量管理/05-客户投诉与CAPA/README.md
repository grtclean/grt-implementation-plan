# 05-客户投诉与CAPA

## 概述

客户投诉与CAPA（纠正与预防措施）管理是GRT质量改善的闭环机制。所有客户投诉通过标准化流程进行接收、分类、调查、响应和关闭，严重投诉触发8D问题解决流程。CAPA系统不仅用于客户投诉，也用于内部NCR、审核发现和预防性改善，确保问题根除且不再复发。
