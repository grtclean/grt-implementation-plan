# 01-公司级KPI

## 概述

公司级 KPI 是 GRT 年度经营目标的量化体现，由 CEO 和董事会共同制定，覆盖财务、客户、项目、质量、效率、创新、人才七大维度，共 28 项核心指标。

### 制定流程

1. CEO 提出年度经营目标草案（12 月）
2. CFO/COO/CTO/HR 各维度负责人细化指标定义和目标值
3. 董事会审批确认（1 月）
4. 分解到 BU 级和部门级（1 月底）
5. 季度回顾和调整

### 跟踪周期

- **实时看板**：财务/项目/生产关键指标实时更新
- **月度回顾**：全部 28 项指标月度汇总
- **季度分析**：深度分析趋势和偏差
- **年度盘点**：全面复盘达成情况
