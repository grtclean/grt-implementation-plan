# 14-KPI与报表中心

## 概述

KPI与报表中心是 GRT 经营管理的核心度量体系，建立从公司级到个人级的五层 KPI 架构，覆盖财务、客户、项目、质量、效率、创新、人才七大维度，驱动数据化经营决策。

配套的报表体系提供周报、月报、季度经营分析、年度总结四种周期性报告模板，确保各层级管理者获得及时、准确、全面的经营数据。

## KPI 框架

### 五层架构

```
L1 公司级 KPI ──── CEO/董事会 ──── 年度经营目标 (7 维度 × 28 指标)
    │
L2 BU 级 KPI ──── BU GM ──── 5 BU 分解目标
    │
L3 部门级 KPI ─── 部门总监 ──── 销售/研发/生产/质量/供应链/服务/HR/财务
    │
L4 项目级 KPI ─── 项目经理 ──── 单项目综合评分 (交付/成本/质量/满意度)
    │
L5 个人级 KPI ─── 全员 ──── 个人绩效卡 + OKR
```

### 七大维度

| 维度 | 英文 | 核心指标数 | 数据来源 |
|------|------|-----------|----------|
| 财务 | Financial | 4 | ERP + 财务系统 |
| 客户 | Customer | 3 | CRM + 客户服务 |
| 项目 | Project | 3 | POS + 项目管理 |
| 质量 | Quality | 3 | 质量管理 + 供应链 |
| 效率 | Efficiency | 3 | 生产 + HR |
| 创新 | Innovation | 3 | 研发 + NPI |
| 人才 | Talent | 3 | HR + 培训 |
