# TPL-供应链KPI

> **适用范围**：供应链部门（采购、仓储、物流）
> **更新频率**：每月跟踪，采购节降每季度盘点
> **审批流程**：供应链总监设定 → COO 审批

## 使用说明

1. **采购节降**：每季度统计节降成果，分同质比价和设计降本两类
2. **库存周转**：每月分析慢流库存，>180天呆滞物料列入处置清单
3. **供应商评级**：每半年进行供应商综合评级(QCDS)，结果影响份额分配
4. **系统数据**：数据从 `/supply-chain`, `/procurement`, `/warehouse` 自动采集
