# TPL-财务KPI

> **适用范围**：财务部全员
> **更新频率**：每月跟踪，现金流每周
> **审批流程**：CFO 设定 → CEO 审批

## 使用说明

1. **现金流周报**：每周五出现金流报表，关注资金安全
2. **预算控制**：各部门费用超预算 10% 需 CFO 审批
3. **应收管理**：>90天应收自动标红，安排专人催收
4. **系统数据**：数据从 ERP 财务模块 + `/expense-report` + `/cost` 采集
