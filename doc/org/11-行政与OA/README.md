# 11-行政与OA

## 概述

行政与OA部门负责GRT机器人公司的日常行政事务管理，包括审批流程、会议管理、固定资产与IT设备管理、访客管理等。通过OA系统实现审批流程数字化，提升组织运行效率。目前管理约350名员工的日常行政需求，覆盖苏州总部及5个事业部办公场所。

## KPI指标

| KPI | 目标 | 计算方式 | 数据来源 | 考核周期 |
|-----|------|----------|----------|----------|
| 审批平均时长 | ≤24小时 | 从提交到最终审批的平均时间 | OA系统 | 月度 |
| 审批超时率 | ≤5% | 超过规定时限的审批/总审批×100% | OA系统 | 月度 |
| 会议室利用率 | ≥70% | 实际使用时段/可用时段×100% | 会议预约系统 | 月度 |
| 固定资产利用率 | ≥85% | 在用资产/总资产×100% | 资产台账 | 季度 |
| IT设备完好率 | ≥98% | 正常运行设备/总设备×100% | IT运维系统 | 月度 |
| 访客接待满意度 | ≥90% | 访客满意评价/总评价×100% | 访客反馈 | 季度 |
