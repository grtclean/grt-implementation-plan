# 02-会议管理

## 概述

会议管理负责GRT公司所有正式会议的组织、记录和跟踪。通过智能会议系统实现会议预约、纪要生成、任务跟踪的数字化闭环。公司共有8个会议室（6个小型4-8人、1个中型20人、1个大型50人/多功能厅），支持视频会议（Teams/钉钉）和现场会议。周例会、月度经营会、季度复盘等固定会议按标准议程运行。
