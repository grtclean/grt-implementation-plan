# 03-资产管理

## 概述

资产管理负责GRT公司所有固定资产和IT设备的全生命周期管理：采购入库、领用分配、维护保养、盘点清查、报废处置。固定资产包括生产设备、测试设备、办公家具、车辆等；IT设备包括服务器、笔记本电脑、显示器、打印机、网络设备等。当前管理固定资产约580项，IT设备约420台。

## KPI指标

| KPI | 目标 | 说明 |
|-----|------|------|
| 固定资产利用率 | ≥85% | 在用资产/总资产 |
| IT设备完好率 | ≥98% | 正常运行/总设备 |
| 资产盘点准确率 | ≥99% | 年度盘点一致率 |
| 设备报废及时率 | ≥90% | 达报废标准后3个月内完成处置 |
