# 04-访客管理

## 概述

访客管理负责GRT公司所有来访人员的预约、登记、接待和安全管理。访客类型包括：客户参观、供应商拜访、政府检查、审计人员、面试候选人、快递/维修人员等。由于GRT涉及半导体洁净室、化学品区域、知识产权敏感区域，对不同类型访客实施差异化安全管控。

## KPI指标

| KPI | 目标 | 说明 |
|-----|------|------|
| 访客登记率 | 100% | 所有进入公司的外部人员必须登记 |
| 预约访客准时接待率 | ≥95% | 预约访客到达后5分钟内有人接待 |
| NDA签署率 | 100% | 进入研发/生产区域的访客必须签署NDA |
| 接待满意度 | ≥90% | VIP客户回访满意度 |
