# TPL-审批权限矩阵

> **适用范围**: 公司全员所有审批事项
> **更新频率**: 年度更新 / 组织架构变更时更新
> **审批流程**: 行政总监制定 → CEO批准 → 全员公示

---

## 模板

### 一、采购审批权限

| 金额区间 | 审批链 | 时限 |
|----------|--------|------|
| ≤1万元 | 申请人 → 部门经理 → 采购专员执行 | 2个工作日 |
| 1万-5万元 | 申请人 → 部门经理 → 采购经理 → 采购总监 | 3个工作日 |
| 5万-20万元 | 申请人 → 部门经理 → 采购经理 → 采购总监 → VP(运营) | 5个工作日 |
| 20万-50万元 | 申请人 → 部门经理 → 采购总监 → VP(运营) → CFO会签 → CEO | 7个工作日 |
| \>50万元 | 申请人 → 部门经理 → 采购总监 → VP → CFO → CEO → 董事会备案 | 10个工作日 |

### 二、费用报销审批权限

| 金额区间 | 审批链 | 时限 |
|----------|--------|------|
| ≤2,000元 | 申请人 → 部门经理 → 财务审核 | 2个工作日 |
| 2,000-10,000元 | 申请人 → 部门经理 → 总监 → 财务审核 | 3个工作日 |
| 10,000-50,000元 | 申请人 → 部门经理 → 总监 → VP → 财务审核 | 5个工作日 |
| \>50,000元 | 申请人 → 部门经理 → 总监 → VP → CFO → CEO | 7个工作日 |

### 三、人事审批权限

| 审批事项 | 审批链 | 时限 |
|----------|--------|------|
| 请假(≤3天) | 申请人 → 直属上级 → HR备案 | 1个工作日 |
| 请假(4-7天) | 申请人 → 直属上级 → 部门总监 → HR备案 | 2个工作日 |
| 请假(>7天) | 申请人 → 直属上级 → 部门总监 → VP → HR备案 | 3个工作日 |
| 加班申请 | 申请人 → 直属上级 → HR备案 | 当日 |
| 招聘需求 | 部门经理 → 总监 → HR经理 → (≥P7)VP | 5个工作日 |
| 转正申请 | 直属上级评价 → 部门经理 → HR经理 | 5个工作日 |
| 离职审批 | 申请人 → 直属上级 → 部门总监 → HR经理 → (≥P7)VP | 3个工作日 |
| 调薪 | 直属上级提名 → 部门总监 → HR总监 → (≥20%)VP → (≥30%)CEO | 10个工作日 |

### 四、项目审批权限

| 审批事项 | 审批链 | 时限 |
|----------|--------|------|
| 项目立项(≤50万) | 项目经理 → BU总监 → VP(运营) | 5个工作日 |
| 项目立项(>50万) | 项目经理 → BU总监 → VP → CFO会签 → CEO | 10个工作日 |
| 项目变更(进度/范围) | 项目经理 → BU总监 → PMO审核 | 3个工作日 |
| 项目变更(预算+10%) | 项目经理 → BU总监 → VP → CFO | 5个工作日 |
| 项目结项 | 项目经理 → BU总监 → 质量经理会签 → VP | 5个工作日 |

### 五、出差审批权限

| 出差类型 | 审批链 | 时限 |
|----------|--------|------|
| 国内出差(≤3天) | 申请人 → 直属上级 | 1个工作日 |
| 国内出差(>3天) | 申请人 → 直属上级 → 部门总监 | 2个工作日 |
| 海外出差 | 申请人 → 部门总监 → VP → 行政(签证协助) | 5个工作日 |

### 六、IT与行政审批权限

| 审批事项 | 审批链 | 时限 |
|----------|--------|------|
| 系统账号开通 | 申请人 → 直属上级 → IT管理员 | 1个工作日 |
| 系统权限变更 | 申请人 → 直属上级 → 数据所有者 → IT管理员 | 2个工作日 |
| 设备申请(≤5,000) | 申请人 → 部门经理 → IT主管 | 3个工作日 |
| 设备申请(>5,000) | 申请人 → 部门经理 → IT主管 → 行政总监 | 5个工作日 |
| 会议室预约(>20人) | 申请人 → 部门经理 → 行政 | 1个工作日 |
| 客户接待申请 | 申请人 → 部门经理 → 行政经理 | 2个工作日 |

### 权限矩阵总览

| 审批角色 | 采购(单笔) | 费用报销(单笔) | 人事 | 项目(预算) |
|----------|-----------|---------------|------|-----------|
| 部门经理 | ≤1万 | ≤2,000 | ≤3天假 | — |
| 总监 | ≤5万 | ≤10,000 | ≤7天假/招聘 | ≤50万立项 |
| VP | ≤20万 | ≤50,000 | >7天假/≥P7入离 | 立项/变更 |
| CFO | 会签(>20万) | >50,000 | 调薪会签 | 预算会签 |
| CEO | >20万 | >50,000 | ≥30%调薪 | >50万立项 |

### 特殊规则

| 规则 | 说明 |
|------|------|
| 自审限制 | 审批人不能审批自己提交的申请 |
| 代理审批 | 审批人出差/请假时须指定代理人 |
| 超时升级 | 审批超48h未处理自动升级至上级 |
| 紧急审批 | 标记"紧急"的审批走快速通道(4h时限) |
| 财务会签 | 所有≥20万元的支出须CFO会签 |
| 回退重审 | 任一节点退回后，申请人修改后需重新走完整审批链 |

## 使用说明

1. **权限依据**：本矩阵为公司最高审批权限文件，所有审批以此为准
2. **系统配置**：OA系统(`/oa`)中已按本矩阵配置审批规则，自动路由
3. **金额叠加**：同一项目/同一供应商的拆分采购视为合并金额审批
4. **年度审查**：每年1月由行政总监组织审查审批权限是否需要调整
5. **紧急通道**：生产停线/安全事故等紧急情况可先执行后补审（24h内补单）
6. **留痕要求**：所有审批记录永久保存，支持审计追溯
