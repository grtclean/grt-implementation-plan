# 01-审批流程

## 概述

审批流程管理是GRT公司内部管控的核心环节，通过OA系统实现所有审批的在线化、标准化和可追溯。审批类型覆盖采购、费用报销、人事、项目、出差等12大类，根据金额、类型和紧急程度自动路由到对应审批人。系统支持钉钉/企业微信移动端审批，确保审批不因出差或会议而延误。

## KPI指标

| KPI | 目标 | 说明 |
|-----|------|------|
| 审批平均时长 | ≤24h | 从提交到最终审批 |
| 审批超时率 | ≤5% | 超48h未处理的审批 |
| 线上化率 | 100% | 所有审批通过OA系统 |
| 退回率 | ≤10% | 审批被退回/总审批 |
