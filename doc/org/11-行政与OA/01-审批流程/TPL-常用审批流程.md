# TPL-常用审批流程

> **适用范围**: 公司全员日常审批事务
> **更新频率**: 流程变更时更新
> **审批流程**: 行政总监维护 → VP审核（重大流程变更）

---

## 模板

### 一、请假审批流程

```
申请人发起
  │ 填写：请假类型/起止日期/天数/事由/工作交接人
  ▼
直属上级审批
  │ ≤3天：审批完成 → HR备案
  ▼ >3天
部门总监审批
  │ ≤7天：审批完成 → HR备案
  ▼ >7天
VP审批
  │ 审批完成 → HR备案
  ▼
HR系统自动扣减年假/事假额度
```

| 请假类型 | 说明 | 需附件 |
|----------|------|--------|
| 年假 | 每年5-15天(按司龄) | 无 |
| 事假 | 扣除当日工资 | 无 |
| 病假 | ≥3天须医院证明 | 诊断证明 |
| 婚假 | 3天(法定)+7天(公司福利) | 结婚证 |
| 产假/陪产假 | 按国家规定 | 准生证明 |
| 丧假 | 1-3天(按亲属关系) | 无 |

### 二、费用报销审批流程

```
申请人发起
  │ 填写：费用类型/金额/事由/发票信息
  │ 附件：发票照片/行程单/合同
  ▼
直属上级审批
  │ ≤2,000元：→ 财务审核 → 打款
  ▼ >2,000元
部门总监审批
  │ ≤10,000元：→ 财务审核 → 打款
  ▼ >10,000元
VP审批
  │ ≤50,000元：→ 财务审核 → 打款
  ▼ >50,000元
CFO审批 → CEO审批 → 财务审核 → 打款
```

| 费用类型 | 报销标准 | 发票要求 |
|----------|----------|----------|
| 差旅-交通 | 高铁二等座/经济舱(总监以上商务舱) | 行程单/电子客票 |
| 差旅-住宿 | 一线城市≤500/晚，其他≤350/晚 | 酒店发票 |
| 差旅-餐饮 | 100元/天(补贴制，无需发票) | — |
| 交通补贴 | 市内出租/网约车据实报销 | 发票/行程单 |
| 通讯补贴 | 经理以上300元/月 | 无需发票 |
| 培训费 | 按培训审批金额 | 培训机构发票 |
| 招待费 | 须注明客户/事由 | 餐饮/礼品发票 |

### 三、出差审批流程

```
申请人发起
  │ 填写：出差地点/日期/事由/预算/同行人
  ▼
直属上级审批
  │ 国内≤3天：审批完成
  ▼ 国内>3天 或 海外
部门总监审批
  │ 国内>3天：审批完成
  ▼ 海外
VP审批 → 行政(签证/机票协助) → 出差
```

### 四、加班审批流程

```
申请人发起（须提前申请，紧急情况可事后补单）
  │ 填写：加班日期/时长/事由/预计成果
  ▼
直属上级审批
  │ 工作日加班：审批完成 → HR记录
  ▼ 周末/节假日加班
部门经理审批 → HR记录
  │
  ▼ 选择补偿方式
  ├── 调休（1:1换算）
  └── 加班工资（按劳动法标准）
```

### 五、招聘审批流程

```
部门经理发起
  │ 填写：岗位/人数/薪资范围/要求/到岗日期
  ▼
部门总监审批
  ▼
HR经理审核（人力编制+预算确认）
  │ ≤P6：审批完成 → HR发布岗位
  ▼ ≥P7（高级岗位）
VP审批 → HR发布岗位
```

### 六、合同审批流程

```
业务部门发起
  │ 填写：合同类型/对方/金额/期限
  │ 附件：合同正文/技术附件
  ▼
部门经理审批
  ▼
法务审核（条款合规性）
  ▼
财务审核（付款条件/预算）
  │ ≤5万：→ 部门总监签字 → 用印
  ▼ >5万
  │ ≤20万：→ VP签字 → 用印
  ▼ >20万
CEO签字 → 用印
```

### 七、IT权限审批流程

```
申请人发起
  │ 填写：系统名称/权限类型/业务理由
  ▼
直属上级审批
  ▼
数据所有者审批（该系统/数据的业务负责人）
  ▼
IT管理员执行 → 通知申请人
```

### 八、访客接待审批流程

```
接待人发起
  │ 填写：访客信息/来访事由/接待级别
  ▼
部门经理审批
  │ 一般访客：→ 前台登记
  ▼ VIP客户/政府
行政经理审批 → 安排接待方案 → 前台登记
```

## 使用说明

1. **线上优先**：所有审批必须通过OA系统(`/oa`)在线发起，纸质审批仅限系统故障时
2. **移动审批**：审批人可通过钉钉/企业微信移动端审批，不受办公地点限制
3. **超时升级**：审批超48h未处理自动升级至审批人的上级，并发送提醒通知
4. **代理机制**：审批人请假/出差前须在系统中设置审批代理人
5. **退回说明**：退回审批须填写退回原因，方便申请人修改后重新提交
6. **紧急通道**：标记"紧急"的审批所有节点时限减半，系统加推通知
7. **合规审计**：所有审批记录保存至少5年，支持内审和外审查阅
