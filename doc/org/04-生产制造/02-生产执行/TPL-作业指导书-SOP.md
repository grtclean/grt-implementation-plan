### 操作步骤

#### 步骤1：准备工作（预计时间：15min）

| 项目 | 内容 |
|------|------|
| 动作 | 1.1 查看工单，确认产品型号和序列号<br>1.2 按物料清单领取工具和零部件<br>1.3 检查行车吊具状态，确认额定载荷<br>1.4 清洁底座安装面，去除毛刺和杂物 |
| 质量检查 | 核对机械臂序列号与工单一致；检查底座安装面平面度≤0.1mm |
| 安全要求 | 佩戴PPE（手套、安全鞋、护目镜） |

#### 步骤2：回转支承安装（预计时间：30min）

| 项目 | 内容 |
|------|------|
| 动作 | 2.1 将回转支承放置于底座安装面，对齐定位销<br>2.2 均匀涂抹润滑脂于滚道<br>2.3 依照对角线顺序预紧12颗M10螺栓（第一遍30N·m）<br>2.4 按对角线顺序终紧至65N·m<br>2.5 在每颗螺栓上涂抹Loctite 243锁固胶 |
| 质量检查 | 扭矩复检（抽检4颗，偏差≤±5%）；回转间隙≤0.05mm；手动旋转无卡滞 |
| 安全要求 | 使用校准扭矩扳手，禁止使用加力杆 |

#### 步骤3：机械臂吊装（预计时间：20min）

| 项目 | 内容 |
|------|------|
| 动作 | 3.1 使用行车将机械臂吊起至底座上方300mm<br>3.2 缓慢下降，对齐回转支承法兰面<br>3.3 插入定位销，确认配合到位<br>3.4 安装连接螺栓（M12×50，8颗），预紧至40N·m |
| 质量检查 | 定位销全部插入到位（目视检查标记线）；吊装过程无碰撞 |
| 安全要求 | ⚠ 吊装区域禁止站人；指定专人指挥行车 |

#### 步骤4：螺栓终紧（预计时间：15min）

| 项目 | 内容 |
|------|------|
| 动作 | 4.1 对角线顺序终紧M12螺栓至85N·m<br>4.2 涂抹扭矩标记油漆<br>4.3 拍照记录扭矩标记 |
| 质量检查 | 100%扭矩复检；标记线完整无偏移 |
| 安全要求 | 使用校准扭矩扳手 |

#### 步骤5：液压管路连接（预计时间：25min）

| 项目 | 内容 |
|------|------|
| 动作 | 5.1 确认液压系统压力为零（读压力表）<br>5.2 连接进油管（P口）和回油管（T口）<br>5.3 安装液压快换接头，拧紧至手感+90°<br>5.4 检查O型密封圈状态，损坏则更换 |
| 质量检查 | 管路标识与接口对应正确；接头无松动；O型圈无切割损伤 |
| 安全要求 | ⚠ 操作前确认压力为零；接头安装时远离面部 |

#### 步骤6：电气线缆连接（预计时间：20min）

| 项目 | 内容 |
|------|------|
| 动作 | 6.1 穿线缆通过拖链，按线号对应端子<br>6.2 连接编码器线缆（航空插头）<br>6.3 连接电磁阀线束（24V直流）<br>6.4 线缆整理并固定（扎带间距150mm） |
| 质量检查 | 线缆编号核对正确；航空插头锁扣到位；线缆无挤压磨损 |
| 安全要求 | 确认电源断开（挂牌上锁）；线缆弯曲半径>5倍线径 |

#### 步骤7：功能测试（预计时间：30min）

| 项目 | 内容 |
|------|------|
| 动作 | 7.1 手动模式低速运行各轴±5°<br>7.2 检查各轴运动方向与程序一致<br>7.3 液压系统升压至10MPa，保压5min<br>7.4 检查各接头无泄漏 |
| 质量检查 | 各轴运动顺畅无异响；液压保压5min压降≤0.2MPa；无渗油 |
| 安全要求 | 测试时启用安全围栏；急停按钮测试正常 |

#### 步骤8：完工检查（预计时间：15min）

| 项目 | 内容 |
|------|------|
| 动作 | 8.1 填写自检表并拍照<br>8.2 清洁工位，工具归位<br>8.3 多余零件退库<br>8.4 MES系统报工 |
| 质量检查 | 自检表所有项目"合格"；无多余零件遗留；工具齐全 |
| 安全要求 | 设备置于安全状态（断电、泄压） |

## 使用说明

1. **查阅方式**：操作工通过MES工位终端扫码工单自动加载对应SOP
2. **版本控制**：SOP版本变更时旧版自动作废，MES只展示最新有效版本
3. **培训要求**：新工序SOP发布后，相关操作工需完成培训并通过考核
4. **偏离管理**：如实际操作需偏离SOP，须填写工艺偏离申请并获得工艺工程师批准
5. **持续改进**：操作工可通过MES提交改善建议，工艺工程师评审后纳入SOP修订
6. **保密等级**：半导体线SOP涉及客户工艺参数的，标记为"机密"级别
