# 02-生产执行

## 概述

生产执行模块涵盖车间作业全流程管理，从SOP标准化作业指导、工序自检、交接班管理到异常处理。GRT以项目制生产为主，每台设备工艺路线不同，SOP需按产品型号和工序分级管理。车间通过MES终端实现无纸化作业：操作工扫码开工、拍照记录、自检提交、异常上报，全过程数字化留痕。
