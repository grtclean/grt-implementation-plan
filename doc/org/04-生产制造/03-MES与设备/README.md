# 03-MES与设备

## 概述

MES（制造执行系统）与设备管理是GRT智能制造的数字化基座。MES系统实现从工单下发、扫码开工、过程数据采集到报工完成的全流程数字化管理；设备管理覆盖设备点检、预防性维护（PM）、OEE效率监控三大核心功能。当前GRT车间部署了38台核心设备（含CNC加工中心、焊接机器人、清洗泵组、半导体清洗腔等），通过IoT网关实现实时数据采集，数据刷新频率5秒/次。
