# 04-物料与库存

## 概述

物料与库存管理负责生产物料从采购到消耗的全链条管控，涵盖安全库存设定、物料领取、库存盘点三大核心流程。GRT产品BOM复杂（单台设备平均3000+物料项），且包含大量定制件和长周期进口件，物料齐套管理直接影响生产进度。库存管理采用ABC分类法，A类物料（占库存金额70%的关键件）实行重点管控。
