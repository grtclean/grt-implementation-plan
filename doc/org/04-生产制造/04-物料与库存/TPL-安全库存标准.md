### 二、安全库存计算公式

```
安全库存 = Z × σ_dLT

其中：
Z = 服务水平对应的Z值（A类99%→Z=2.33，B类95%→Z=1.65，C类90%→Z=1.28）
σ_dLT = 需求在提前期内的标准差 = √(LT × σ_d² + d² × σ_LT²)
d = 日均需求量
σ_d = 需求标准差
LT = 采购提前期（天）
σ_LT = 提前期标准差

补货点 = 日均需求 × 采购提前期 + 安全库存
```

## 使用说明

1. **审查周期**：每季度审查安全库存参数，消耗异常时即时调整
2. **系统联动**：安全库存参数维护在`/smart-inventory`模块，低于补货点自动触发采购申请
3. **预警通知**：红色预警推送至物料主管+采购经理+生产总监；橙色推送至物料计划员
4. **新物料**：首次使用的物料按B类管理，3个月后根据实际消耗数据重新定级
5. **呆滞处理**：6个月无消耗物料列入呆滞清单，评估处置方案
6. **进口件策略**：Lead time>45天的进口件，额外增加15天安全天数
