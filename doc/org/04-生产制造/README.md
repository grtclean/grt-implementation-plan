# 04-生产制造

## 概述

生产制造部门是GRT核心价值创造中心，负责工业清洗机器人、装配系统及半导体清洗设备的全流程制造。部门覆盖生产计划排程、车间执行、MES系统管理、物料库存、工人技能管理、生产报表以及机器人与清洗工艺专项管理七大板块。当前产线包括3条机器人总装线、2条半导体清洗设备线及1条柔性装配线，年产能约200台套设备。

## KPI指标

| KPI指标 | 目标值 | 计算公式 | 统计周期 | 数据来源 |
|---------|--------|----------|----------|----------|
| OEE（设备综合效率） | ≥75% | 可用率×性能率×合格率 | 日/周/月 | MES系统 |
| 交期准时率 | ≥90% | 按时交付订单数÷总订单数×100% | 月度 | ERP+MES |
| 一次合格率（FPY） | ≥95% | 首次检验合格数÷总检验数×100% | 日/月 | 质量模块 |
| 产能利用率 | ≥85% | 实际产出工时÷可用产出工时×100% | 周/月 | MES系统 |
| 设备故障停机率 | ≤5% | 故障停机时间÷计划生产时间×100% | 月度 | MES+设备 |
| 人均产出 | ≥1.5台/人/月 | 当月产出台数÷直接生产人数 | 月度 | MES+HR |
| 物料齐套率 | ≥95% | 按时齐套工单数÷总工单数×100% | 周度 | ERP |
| 安全事故率 | 0 | 当月安全事故次数 | 月度 | 安全系统 |
| 制造成本偏差 | ≤±3% | (实际成本-标准成本)÷标准成本×100% | 月度 | ERP |
