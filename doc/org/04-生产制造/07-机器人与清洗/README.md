# 07-机器人与清洗

## 概述

机器人与清洗模块是GRT的核心技术领域，涵盖工业清洗机器人工艺参数管理、机器人程序配置以及半导体清洗合规管理。GRT产品线包括高压水射流清洗机器人（汽车零部件行业）、超声波清洗系统和半导体晶圆清洗设备（Class 100/10洁净室），工艺参数直接影响清洗质量和客户验收。半导体清洗设备需满足ISO 14644-1洁净室标准及客户特定的颗粒度要求。
