### 六、程序伪代码

```
PROGRAM: CLEAN_EA211_V1.3

-- 初始化
CALL HOME_POSITION
WAIT DI[1]=ON  -- 等待工件到位
WAIT DI[2]=ON  -- 等待夹具锁紧
WAIT DI[3]=ON  -- 等待安全门关闭
WAIT DI[6]=ON  -- 等待双手启动

-- 阶段0：接近
MOVE JOINT TO P_STANDBY SPEED=50%
MOVE JOINT TO P_APPROACH SPEED=30%

-- 阶段1：预洗
SET DO[2]=ON       -- 高压泵启动
WAIT AI[1]>=2.5MPa -- 等待压力建立
SET DO[4]=ON       -- 扫描喷嘴开
SET DO[5]=ON       -- 工件旋转开
FOR i=1 TO 12
  MOVE LINEAR TO P_PREWASH[i] SPEED=200mm/s
END
SET DO[4]=OFF
SET DO[5]=OFF

-- 阶段2：主洗定点
CALL SET_PRESSURE(30MPa)  -- 升压至30MPa
SET DO[3]=ON              -- 定点喷嘴开
FOR i=1 TO 48
  MOVE LINEAR TO P_SPOT[i] SPEED=50mm/s
  DELAY 3.0s              -- 驻留3秒
END
SET DO[3]=OFF

-- 阶段3：主洗扫描
CALL SET_PRESSURE(25MPa)
SET DO[4]=ON
FOR i=1 TO 36
  MOVE LINEAR TO P_SCAN[i] SPEED=200mm/s
END
SET DO[4]=OFF

-- 阶段4：漂洗（切换纯水）
CALL SWITCH_TO_RINSE
FOR cycle=1 TO 2
  FOR i=1 TO 12
    MOVE LINEAR TO P_PREWASH[i] SPEED=200mm/s
  END
END

-- 阶段5：撤退
SET DO[2]=OFF  -- 高压泵停止
MOVE JOINT TO P_APPROACH SPEED=30%
MOVE JOINT TO P_STANDBY SPEED=50%
MOVE JOINT TO HOME SPEED=50%
SET DO[6]=ON   -- 清洗完成信号
```

## 使用说明

1. **离线仿真**：新程序必须先在RoboGuide中完成仿真，验证无干涉后方可下载至实机
2. **慢速试运行**：首次运行速度限制在10%，逐步提升至100%
3. **安全验证**：安全区域设定由安全工程师独立验证，记录存档
4. **版本管理**：程序版本在MES系统登记，机器人控制器中保留最近3个版本
5. **备份策略**：每次修改前自动备份至服务器，修改后标注变更内容
6. **参数锁定**：正式投产后，操作工无权修改程序参数（需工程师权限密码）
