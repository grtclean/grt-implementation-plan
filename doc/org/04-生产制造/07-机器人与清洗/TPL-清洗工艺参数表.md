### 一、清洗工序流程

```
工件上料 → 预洗（低压冲洗） → 主洗1（高压定点） → 主洗2（高压扫描） → 漂洗（纯水） → 防锈处理 → 吹扫 → 真空干燥 → 下料检测
```

## 使用说明

1. **参数锁定**：关键参数（压力、温度、浓度）在PLC中设定上下限报警，超限自动停机
2. **首件验证**：每个项目首件必须通过清洁度检测后方可批量清洗
3. **参数记录**：MES系统实时记录所有清洗参数，支持追溯任意工件的清洗条件
4. **变更管控**：参数变更需经过工艺验证（至少5件测试）后方可正式变更
5. **客户定制**：不同客户可能有更严格的清洁度要求，以客户标准为准
6. **化学品安全**：清洗液配制和更换需遵守MSDS规定，佩戴化学品防护装备
