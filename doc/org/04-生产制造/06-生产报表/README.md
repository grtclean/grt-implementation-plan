# 06-生产报表

## 概述

生产报表体系是生产管理的数据支撑，涵盖日报、月报和专项对账报表。日报聚焦当日产出和异常，月报提供趋势分析和KPI总结，三方工时对账解决MES报工、考勤系统和薪资核算之间的数据一致性问题。GRT通过MES系统自动采集生产数据，最大限度减少人工填报，确保数据准确性和时效性。
