# 01-生产计划与排程

## 概述

生产计划与排程是生产制造的龙头环节，负责将销售订单和项目需求转化为可执行的生产计划。GRT采用项目制生产模式（非批量流水线），每台设备均为定制化配置，排产需综合考虑项目交期、物料齐套、设备可用性、工人技能匹配及产能约束。当前使用APS（高级计划排程）模块实现智能排产，支持多约束条件下的甘特图可视化排程。

## 核心流程

1. 销售确认订单 → 项目立项 → 生成MPS需求
2. MRP运算 → 物料齐套检查 → 采购/领料计划
3. APS排程 → 甘特图确认 → 日排程下发
4. 车间执行 → MES报工 → 进度反馈 → 排程调整
