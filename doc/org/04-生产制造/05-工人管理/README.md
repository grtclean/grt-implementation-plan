# 05-工人管理

## 概述

工人管理模块覆盖生产一线人员的技能评估、绩效考核和上岗资格认证三大核心职能。GRT拥有约80名直接生产人员，分布在机械装配、电气调试、焊接、半导体工艺、清洗工艺等多个工种。由于产品定制化程度高，工人多技能化（一人多岗）是产能弹性的关键。技能矩阵管理支撑灵活排产，绩效评估驱动持续改善，上岗资格认证确保质量和安全合规。
